# 人物与状态圣经

## 主角：陈序

- 年龄：24 岁。
- 身份：临川冰城底层拾荒者、旧机械维修学徒；后成为 404 修理站站长、混乱研究院奠基者、混沌清洗者。
- 外貌锚点：偏瘦，左眉一道旧冻伤，常穿大两号的橙色维修服；笑起来像正准备把谁的零件卖掉。
- 表层性格：嘴欠、能屈能伸、一本正经地胡说八道、对体面没有执念。
- 深层性格：极怕被抛弃；越在乎越用玩笑遮掩；对具体的人心软，对宏大口号天然不信。
- 核心欲望：起初只想活；中期要让跟随自己的人有选择；后期要为生命保留重启后的“偏差”。
- 核心缺陷：把不可预测当作逃避承诺的借口；习惯独自承担和隐瞒代价；长期使用能力会污染自身记忆。
- 道德底线：可以骗人、偷抢敌对资源、毁掉规则，但不把无知者当一次性工具，不替他人决定是否牺牲。
- 喜剧机制：他不是随机发疯，而是迅速找到规则最尴尬的解释，并厚着脸皮逼所有人回应。
- 成长四阶：求生式耍赖 → 有意识利用规则漏洞 → 把混乱工程化 → 接受混乱也需要责任与边界。

## 金手指：【因果律欺诈协议】

它不是人格化签到系统，而是陈序接触清理残片后形成的异常解释层。

- 条件一“陈述”：陈序必须说出一个可以被当前环境判定真假的命题。
- 条件二“受信”：至少一个具备因果权重的观察者真正相信，权重可来自人数、权限或与事件的关系。
- 条件三“可钻空子”：谎言必须能借用现有事实的歧义，不能无中生有创造无限能量。
- 效果：现实在小范围、短时间内选择一种“谎言成立”的解释。
- 代价：复杂度越高，陈序越会遭遇认知降温、记忆错位、概率追债或清理标记加深。
- 防滥用：同一句谎言重复使用，可信度与效果快速衰减；陈序自己完全相信时，欺诈失去内外差异，可能永久改写他的记忆。
- 成长：欺骗单个感知器 → 欺骗局部规则 → 制造互相冲突的群体共识 → 向宇宙核心写入不可裁决命题。

## 核心伙伴：锈钉

- 初始形态：报废市政维修机器人，一米六高，左臂缺失，胸口印着倒置的“临川公交维修”。
- 初始能力：纯物理按键和离线指令，只能理解短句，遭遇复杂命令会停顿并敲自己脑壳。
- 人格种子：残留着陈序父亲陈默写入的一条非法指令——“当规则与活人冲突，先救人”。
- 成长：肉盾废铁 → 404 门卫 → 多代机器人共同人格的最早底层错误。
- 语言特征：初期用播报腔，偶尔把故障码当情绪；不靠卖萌，而靠笨拙执行产生感情。

## 苏弥

- 年龄：27 岁；前白塔清理工程师。
- 外貌锚点：黑发剪得极短，右手两根义指，随身携带纸质记录卡。
- 能力与功能：懂清理程序、法则观测和医疗工程；是陈序的科学对照与伦理刹车。
- 核心欲望：证明理解规则可以救人，而非只能服从规则。
- 缺陷：过度追求证据，害怕无法量化的信任；曾参与一次失败清扫，背负幸存者负罪。
- 关系线：从互相利用到共同研究，再到准备“必要时杀死陈序”；感情克制地藏在共同选择与牺牲里，不喧宾夺主。
- 语言特征：句子短、数字精确；真正慌乱时反而说得更慢。

## 岳无缺

- 年龄：35 岁；净序会审判官，后成为秩序代理人及零号秩序的人格组成。
- 信念：自由制造复杂度，复杂度招来清扫；残酷削减少数是保存多数的唯一数学答案。
- 优点：自律、守诺、愿意承担骂名，确实救过大量平民。
- 致命盲点：把“仍在运转”误作“活着”，无法接受不可量化的价值。
- 与陈序：不是疯子与正常人，而是“选择的风险”与“安全的囚笼”之争。
- 语言特征：从不用反问；每句话像已经写进判决书。

## 伊珂

- 身份：高维镜裔改革派，低维投影常呈现为轮廓错位的少女。
- 欲望：让镜裔承认低维生命不是缓存材料。
- 限制：每次在三维世界具象都会丢失一部分高维记忆。
- 功能：扩大文明尺度，提供“神也会害怕”的反差；后期是万族联盟外交核心。

## 机器人代际

- 一代锈钉：行动主题“救人优先”；退役后守门，最终错误种子。
- 二代回声：复读与机械重复，可令预测 AI 在回环中耗尽资源；后管理农业基地。
- 三代反骨：为每个结论生成反例，降低预测锁定；需要防止它无差别反对救援。
- N 代杂音：历代冲突代码与高级硬件的缝合体；真正成长标志是有权拒绝陈序。
