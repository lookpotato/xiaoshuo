## 本章交织节点

- 起点：第98章末，门外回执夹锁住写有陈序名字的维修单，门内旧维修印按下半寸。
- 人物线：陈序想阻止名字成为本人签收；苏弥想证明印章与本人动作可以拆开；锈钉想找回被门内调用的旧编号；岳无缺想让维修站在可追责范围内停战。
- 汇合：四条线都在“旧维修印是否能够替代本人确认”上发生作用，但没有任何人物自动知道其他人的内心。
- 留下的未决：旧维修印的来源、完整权限和门内声音是否为陈默，继续留到后续章节。

## 汇总原则

最终正文采用陈序第三人称限知：能直接看见的写动作，能根据痕迹推断的写猜测，看不见的私线只留下结果或异常，不用“与此同时”替读者全知播报。
