# 交织图

1. 陈序用残轮短压轨道，逼母机停料；苏弥看见新轨道边缘的白霜被压出指印，反过来要求他别把送料物当诱饵，结果两人把止退夹从“一次回压”改成“半次回弹”，暂时打开了安全出口。
2. 苏弥用坏义指压住第二咬合点，陈序为保护她改拉黑烟一号的残轮，导致机体后退半寸；锈钉趁这个结果把机械臂插入轨底，送料物被拖离收件位，却也把它的声音放大到门外。
3. 锈钉听见送料物喊“别替我收”，误把对方当成活人；苏弥用白塔校正线照出送料物其实是一只带旧录音的维修扳手，陈序没有立即丢弃，三人由“救人”转为“先保留证据、拒绝代签”。
4. 陈序用半块记录卡遮住白板上的“收件人”，苏弥让校正线烧掉卡角，锈钉则把扳手拖出门外；三人的相互牵制使旧印只写出“送达，未收”，母机新轨道继续向更深处接轨。
