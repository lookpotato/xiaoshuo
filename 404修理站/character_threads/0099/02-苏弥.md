# 苏弥私线

- 起点：左掌裂伤、右手义指将停，正守着母机检修板。
- 私人目标：让换向只改变输出方向，不把她的记录并入旧维修印；她要证明理解规则能救人而非替人牺牲。
- 知道与不知道：知道第三格是回收工位，知道会吸走最近责任记录；不知道旧印来源和门内人的身份。
- 误解与阻力：倾向认为没有证据就不能行动；陈序逞强、白塔冲撞和母机三根拉杆阻碍她。
- 底线与行动：把记录卡压在拉杆间，拒绝陈序扶她，随后主动压到第二格。
- 代价与变化：右手最后一根义指停住，左掌伤口加深；获得“输出可导出、回收不可内转”的实物证据。
- 离场后：折断记录卡保存无印证据，继续约束陈序不替人承担；门内动静仍是未解风险。
