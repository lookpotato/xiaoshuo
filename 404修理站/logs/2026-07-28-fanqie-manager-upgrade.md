# 2026-07-28 番茄小说管理器升级

## 目标

- 将根目录“小说管理器”统一重命名为“番茄小说管理器”。
- 让全新 Codex 会话不依赖旧聊天记录，也能恢复批量写作与番茄发布。
- 把第19章、第20章实际成功的发布流程和浏览器中断恢复经验固化为机器入口。

## 变更

- 主程序由 `novel_manager.py` 重命名为 `fanqie_novel_manager.py`。
- 新增 `session --book cosmic-404`：输出项目、状态、批量待处理章节、必读文件、
  写作发布闭环、成功门槛、故障分级和结束命令。
- 新增 `pending --book cosmic-404`：从 `batch_schedule_*.json` 汇总逐章待处理状态，
  避免只看 `chapter_state.json` 的最后一章状态而遗漏较早草稿。
- `notes` 同步显示批量待处理章节。
- 项目结构校验与发布完成校验解耦：尚待发布是可恢复任务，不再阻止 `claim`；
  但 `finish --result success` 仍会严格拒绝草稿或未上传状态。
- README、每日自动化提示和番茄 UI 规程全部切换到新名称与新入口。

## 固化的成功细节

- 已有草稿必须沿用草稿 URL；重新打开回到编辑页表示发布设置未最终提交。
- 每次浏览器调用只做一个有副作用动作，随后另起只读检查。
- 固定流程为：下一步 → 错别字提示提交 → 仅基础检测 → AI=是 → 定时发布。
- 日期和时间必须点击可见选择器；最终回读日期、时间、AI checked、定时开关。
- “确认发布”只点击一次；结果未知时先检查当前 URL 和章节管理列表，不重复提交。
- 按章节号与完整标题唯一匹配列表行，同时读取状态和发布时间。
- 只有待发布、审核中或已发布才算成功；成功后立即回写章节状态、批量排期和日志。
