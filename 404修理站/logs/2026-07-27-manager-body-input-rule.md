# 2026-07-27 总管理器正文输入规则修正

- 项目：404修理站
- 原因：用户指出固定上传流程仍不够详细，疑似正文没有正确输入，因此未能进入下一阶段。
- 修正：`novel_manager.py notes --book cosmic-404` 新增正文输入专项流程。
- 关键规则：章节号、标题、正文必须串行输入；正文粘贴后必须核对首段、末段、平台字数和本地字数。
- 停止条件：正文为空、首尾不匹配、平台字数为 0、仍显示提示词或字数明显偏离时，不得点击“下一步”；重贴一次仍失败则记录 `failed_retryable`。
- 同步文件：`fanqie_ui_workflow.md` 和 `automation_prompt.md` 已加入同样的正文输入硬校验。
