# 第89章 更换对象不能靠旁观

正式收件槽的锁死声停在耳边，第二条热管却没有停。

白裂纹虽然不再往两边爬，管壁里的红光仍一下一下鼓动。三台白塔机甲横在北墙外，校正光压住支架。陈序站在黑烟一号踏板上，左腕麻到肩窝，右履带又掉一片铁屑。

“更换对象待定。”锈钉从门后播报，“请维修站在回程前提交替换收件人。未提交，默认沿用当前收件人。”

苏弥的右手义指垂在身侧，最后一根能回弹的指头已经彻底停了。她抬头看陈序：“它把‘待定’说成了‘默认’。”

“公文里最喜欢的偷懒。”陈序跳下踏板，“先把没人签过的字，算到签过的人头上。”

门外有人喊：“换陈站长！他本来就是站长！”

另一个声音顶回去：“陈站长要是坏了，谁修热管？”

“不会修不影响收件。”锈钉认真纠正，“当前要求是本人确认、承担一次更换代价。”

人群安静下来，所有目光都落在苏弥僵硬的右手上。

陈序看见：校正光仍压着热管，拖到下一次回程前供暖会断；收件槽只要求“更换”，替苏弥报名仍是代收。

“苏弥，你想换谁？”他问。

“不是我想。”她盯着墙外的白光，“是它想让我们抢一个倒霉的人。”

热管猛地响了一声。第一台白塔机甲抬起机械臂，抓住支架向外一拧。白裂纹没扩张，支架却开始弯。北墙下的人往后挤，抱桶老人差点踩到孩子的鞋。

陈序转身抓起磁轨钉枪。那件短粗的废土工具上次用过后，固定架还沾着冷硬的泥。他先对苏弥说：“它的用途是把钢钉打进中距离的结构，钉住支架或履带；必须让固定架落地承反冲，不然枪和人一起翻。”

“我记得。”苏弥说，“别拿它替我承担。”

“这次拿它钉白塔，不钉你的名字。”

陈序把钉枪的双脚架压进冻土，右膝不敢顶力，只用左脚踩住横杆。第一发钢钉擦着热管飞出，钉进白塔机甲的机械臂肘部。钉枪反冲把他掀得后仰，固定架在地上拖出两道沟，黑烟一号及时用肩甲顶住他的后背，右履带又落下一小片铁屑。

白塔机甲被钉住半边，另一台立刻抬臂补位。它们没有等陈序重新装钉，校正光转过墙头，直照黑烟一号驾驶舱。

“第二发只能救支架，不能救你。”苏弥说。

陈序没有拉她。他把钉枪横放到她左手够得着的位置，又把一个空弹匣踢到她脚边：“你装不装，由你本人决定。装上以后，替我看准第二台的支架，不替任何人签收。”

苏弥看着那把枪，嘴唇动了一下：“你现在很会把东西放远。”

“离手越远，锅越难自己滚回来。”

她用左手拿起弹匣。就在这时，黑烟一号后方传来湿重的刮擦声。同动作猎犬从排水沟里爬出，左前爪还折在断轴孔里，却已经复制了陈序刚才压架、后仰的动作。它扑向钉枪的位置，想把这个动作再做一遍。

苏弥抬头：“它要复制你。”

“那就给它一个不能完成的动作。”

陈序猛地松开左脚，故意让黑烟一号往右歪。右履带不能连续强转，机体只靠门槛和肩甲撑住，没有完成标准后仰。猎犬照着半个动作扑来，前爪落空，胸口撞进废牵引机的轮槽。

苏弥趁它卡住，把弹匣推入钉枪。她没有瞄准猎犬，而是瞄准第二台白塔机甲刚换上的支撑腿。

“陈序，固定架会把反冲传回地面。”

“所以我踩着，你开。”

“你右膝不能承重。”

“我左脚能。坏一条腿，总比让热管替我们断一条街强。”

她没有替他反驳。苏弥把左肘抵在黑烟一号的驾驶舱边，扣下扳机。

钢钉轰出，贯穿白塔机甲支撑腿旁的旧承力梁。第二台机甲的校正光立刻歪向天空，光束擦过北墙上沿，冻住的水汽像一层碎盐落下来。第一台机甲的机械臂被钢钉拽住，三台机甲的队列因此错开半步。

热管里的红光骤然变暗。

北墙下有人喊：“停了！”

“不是修好了。”苏弥喘着气，“只是压力没再压进裂纹。”

她说完，正式收件槽侧面的回执孔忽然吐出一片白纸。纸片没有落到她手上，而是沿地面滑到陈序脚边。

“请提交更换对象：陈序。”

人群里立刻有人吸气。抱桶老人第一个摇头：“他刚才钉住了白塔，算他自己愿意。”

“我没说愿意。”陈序捡起白纸，指尖冻得发麻，“我只说钉枪不替苏弥签字。”

苏弥的左手伸到一半，又硬生生停住。她看着那张纸：“别撕。撕了可能算拒绝，按它的说法，拒绝也会留下记录。”

“你什么时候开始替纸操心了？”

“从它能把人的沉默写成同意开始。”

这句话让陈序的笑收了回去。他看向北墙下的人：“谁看见我开枪了？”

所有人都举起了手。

“谁听见我说我愿意承担更换？”

没有人举手。

锈钉播报：“观察证据一致。行动与本人确认不一致。”

“那就把事实送回去。”陈序把白纸塞进正式收件槽下方，却没有碰确认栓，“我本人确认：我刚才承担的是磁轨钉枪的反冲和黑烟一号的结构损耗，不是苏弥的更换代价。苏弥本人没有确认把更换对象改成我。”

槽口没有夹紧。纸面上的黑痕先是抖了两下，随后裂成两行：

“行动记录成立。”

“更换对象仍待定。”

白塔机甲被钉住的机械臂挣断旧梁。反冲沿钉枪传来，苏弥左肘被震开，陈序左腕麻意冲到指尖。热管白裂纹又亮一线，却没有继续扩开；他们保住支架，也没把陈序的名字塞进苏弥的代价里。

门后传来岳无缺的声音：“更换不是旁观者投票。维修站若不提交本人，下一次回程时，旧收件人继续承担。”

陈序抬头：“你在门里面看得挺清楚。”

“我只陈述规则。”

“规则说谁最想让我替苏弥签字了吗？”

岳无缺没有回答。三台白塔机甲同时后退一步，给北墙留下仅容黑烟一号通过的缝。缝外另一条热管亮起，红光沿冰面指向维修站。

苏弥握住自己僵硬的右手腕：“它们不是撤退，是把下一次回程的路清出来。”

陈序看了眼脚边白纸。纸上的最后一行慢慢浮出新的字：

“下次回程前，必须有一名本人站进更换位置。”

锈钉补充：“评论命名接口开放：自送自收、锅的回旋镖、本人签收不包修、锅别回头。请提交第三个更损的工单名。”

北墙下没人笑。所有人都看着那条通往维修站的红光。

陈序把白纸折成三折，塞进自己口袋：“行。下一次不让旁观者挑人。”

苏弥看他：“那让谁挑？”

陈序踩住黑烟一号摇晃的履带，朝那条红光抬了抬下巴。

“让想换人的那个人，先自己走到槽里。”

黑孔深处没有回声。正式收件槽却在苏弥身后轻轻响了一声，像已经听见了一个尚未报出名字的人。
