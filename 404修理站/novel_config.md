# 小说项目配置

## 作品信息

- 作品名：404修理站
- 备选宣传名：404修理站：专修宇宙漏洞
- 类型：科幻末世 / 废土机甲 / 脑洞系统 / 黑色幽默
- 目标读者：偏爱快节奏升级、反套路智斗、废土建造与机甲养成的男性向读者
- 目标总字数：约 400 万字
- 预计规模：12 卷，约 1500 章，单章 2400—3000 字
- 更新频率：每日 2 章；严格按“写完一章→校验→上传一章”顺序连续执行两次
- 当前阶段：新书筹备与开篇验证

## 核心卖点

当宇宙把生命判定为病毒，所有文明都在努力变得更强、更完美。只有陈序发现：越完美，死得越快。于是他驾驶一台断网、漏油、靠拉杆操纵的废铁机甲，把胡说八道变成因果武器，把故障机器人养成文明，让负责格式化宇宙的清理程序第一次弹出错误提示：目标无法解析。

## 自动化授权边界

- 允许读取本书目录与根目录 `shared/` 中的写作规范。
- 允许生成、校验并保存新章节到 `drafts/` 与 `chapters/`。
- 仅在本书 `publish_config.md` 已绑定独立番茄地址后允许打开后台。
- `submit_publish: false` 时只存番茄草稿；改为 true 才允许提交。
- 登录失效、验证码、风控、政策警告、新确认框或书名不匹配时立即停止并记日志。
- 严禁使用“测试本小说”的书号或发布链接。
- 每日目标为 2 章，禁止先写完两章再一起上传；前一章未获得番茄明确成功信号时，
  不得开始生成后一章。

## 创作红线

- 不靠反派降智制造胜利。
- 不把网络热梗原句当主要笑料；笑点必须源于人物和局势。
- 不让系统无成本满足愿望；每次现实篡改都需满足可信度、作用域和反噬规则。
- 不连续三章只讲设定、不连续两章没有可见推进。
- 不在正文出现 AI、提示词、自动化、读者、作者等元创作信息。
