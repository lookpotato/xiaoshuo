# 小说项目配置

## 作品信息

- 作品名：404修理站
- 备选宣传名：404修理站：专修宇宙漏洞
- 类型：科幻末世 / 废土机甲 / 脑洞系统 / 黑色幽默
- 目标读者：偏爱快节奏升级、黑色幽默、人物互损、围观吃瓜、废土建造与机甲养成的男性向读者；规则智斗只做爽点支撑
- 目标总字数：约 400 万字
- 预计规模：12 卷，约 1500 章，单章常规 2800—3400 字；涉及新规则、多人协作或连续推理时可写到 3800 字，复杂事件允许拆成多章，每章优先保证情绪小闭环与阅读趣味
- 更新频率：每日 2 章；严格按“写完一章→校验→上传一章”顺序连续执行两次
- 当前阶段：新书筹备与开篇验证

## 核心卖点

当宇宙把生命判定为病毒，所有文明都在努力变得更强、更完美。只有陈序发现：越完美，死得越快。于是他驾驶一台断网、漏油、靠拉杆操纵的废铁机甲，把胡说八道变成因果武器，把故障机器人养成文明，让负责格式化宇宙的清理程序第一次弹出错误提示：目标无法解析。

## 自动化授权边界

- 允许读取本书目录与根目录 `shared/` 中的写作规范。
- 允许生成、校验并保存新章节到 `drafts/` 与 `chapters/`。
- 仅在本书 `publish_config.md` 已绑定独立番茄地址后允许打开后台。
- `submit_publish: false` 时只存番茄草稿；改为 true 才允许提交。
- 登录失效、验证码、风控、政策警告、新确认框或书名不匹配时立即停止并记日志。
- 严禁使用“测试本小说”的书号或发布链接。
- 常规发布目标为每日 2 章；支持按用户明确指示批量生成、批量上传和提前定时排期。
- 批量排期默认首章设为中午 12:00；同日第二章使用平台允许的最近可用时段。
- 用户可临时指定某日加更数量或时间；加更只覆盖指定日期，不自动改变后续每日 2 章的常规排期。
- 非批量模式仍按“写一章、校验一章、上传一章”顺序执行；批量模式必须逐章校验连续性后才可进入统一上传阶段。

## 创作红线

- 不靠反派降智制造胜利。
- 允许主动吸收近期网络梗的情绪结构与节奏，再改写成维修、工单、售后、临时工和机器误解产生的世界内笑料；不照搬完整热句，不让现实平台黑话破坏世界感。
- 不让系统无成本满足愿望；每次现实篡改都需满足可信度、作用域和反噬规则。
- 不连续三章只讲设定、不连续两章没有可见推进。
- 不把关键推理台阶留给读者自行补全；可以隐藏幕后真相，但不能隐藏人物为什么这样判断、这样做会解决什么、失败会失去什么。
- 不把推理解密当章节主菜。复杂调查宁可拆成多章，每章也必须有主情绪、可吃的瓜、人物互动和当章小兑现。
- 允许旁白或陈序适量打破次元壁，直接称呼“读者老爷”等并邀请吐槽或站队；每次必须短、好笑且不承担关键解释。
- 正文不得出现 AI、Codex、提示词、自动化、后台、字数或生成过程；不得借次元壁互动索要点赞、打赏、催更或评论。
