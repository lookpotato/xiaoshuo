# 《潮汐造物铺》第一卷路线（暂定）

## 第一卷：第一件卖出去的东西

1. 林澄回到旧港，发现舅舅留下的造物铺欠租，三个月内不做出可持续收入就要退租。
2. 街坊交来一张手绘潮汐表，想把它做成游客纪念品；林澄拒绝直接印图，先查清绘图人的署名、使用场景和潮汐信息来源。
3. 她与老印工、年轻插画师和小批量加工店合作，把它做成“潮线书签尺”：可夹书、可量页边、背面有清楚标注的潮位刻度和街区故事。
4. 第一批样品暴露出刻度太小、边缘刮手、印色遇水脱落等问题；团队用真实读者试用和退换反馈返工，不把瑕疵包装成手作特色。
5. 文旅公司提出一次性买断图样与街区故事。团队争取保留署名、授权期限和按件分成，代价是错过快速回款。
6. 第一批小单售罄但利润不足以维持店铺；顾客主动带来下一段故事，打开第二件产品的需求。

## 产品线约束

- 每件商品先在剧情中解决人物或街区的具体问题，然后才进入现实产品开发。
- 逐步展示材料、尺寸、工艺、成本、包装、质量缺陷、用户测试和真实销量；没有试验的数据不得写成结论。
- 第一卷从低成本、非食品、非电子、非化妆品的纸品/书桌小物起步，避免把小说测试绑在高监管品类上。
- 读者可以只享受故事，不需要购买任何东西才能理解剧情。
