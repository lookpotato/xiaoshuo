# 文风与产品化边界

- 叙事先写人物行动、关系和代价；产品只在故事需要时出现。
- 不写成产品说明书、融资路演或连续带货文案。正文不出现购买链接、限时促销和对读者的推销。
- 产品开发通过现场试用、返工、谈判和订单结果呈现；角色可以判断错，商品也可以卖不动。
- 制作细节具体到读者看得懂的程度，不堆专业参数。参数必须符合已建立的设定，不凭空宣称销量、成本和安全结论。
- 每件产品都要同时改变至少一项：人物关系、经营现金流、街区利益或人物对旧事的理解。
- 轻奇幻不替代日常劳动和因果；潮声只增加悬念，不直接解决生产难题。

## 《潮汐造物铺》对白执行规则

- 对白先服务关系，再交代信息。提纲里的授权、报价、用途等条件不得整组念出来；每个角色只说此刻最想守住的一件事，剩下的通过追问、打断、动作和后续谈判逐步露出。
- 林澄说话短、稳，习惯先问清楚再答应；她一紧张会把话说得像工作记录，但被人指出后会停下来改口。
- 梁姨熟人腔重，先损一句再办事，钱和时间说得直，不替别人担保。她会省掉主语、把话说半截，手上的动作和报价比解释更有分量。
- 许知遥年轻但不轻浮，防备陌生人拿她的图占便宜；她会抢话、改口、用反问挡回去，偶尔带一点网络口头语，但不把个人经历总结成宣言。
- 每场对白至少保留一处没接住、改口、被打断或答非所问。读者应能遮住人名分辨梁姨和许知遥，不能让所有人都用完整、对称、同长度的句子。
