# 房东（电话中）｜第 1 章人物私线

- 起点状态：造物铺欠租，店铺空置；此前林澄联系过他，询问能否接下铺面。
- 当前地点与行动：不在林澄所在场景中；接听林澄来电，说明此前给出的三个月窗口按她接手日计算。
- 独立目标：确认店铺未来三个月的责任归属，避免新旧账混在一起、空置状态无限延长。
- 误解：起初以为林澄还在试探能不能把期限往后挪；她实际是要把开始日期和旧欠租记准确。
- 阻力：店铺仍欠租；他愿意给一个有边界的经营窗口，但不承担林澄的生意风险。
- 底线：不把试营窗口说成免租、免旧账或保证续租。
- 行动：逐项答复开始日期、旧账和三个月后再谈的边界。
- 代价：空铺可以再留三个月，收租与重新出租都要延后；仍未承诺后续续约。
- 本场后变化：林澄得到了明确口径；房东确认她要在窗口内自行决定经营结果。
- 下一步：按约看三个月后的经营情况，再决定是否续租。
- 关系卡：房东与林澄是熟悉但不亲密的本地租赁关系；房东掌握铺面期限，林澄掌握是否接手。她用“陈叔”维持熟人礼貌，房东直呼“林澄”并强调边界。双方都知道旧铺与欠租，不需重述来历；林澄不想显得在讨额外宽限，房东不想被理解成免账或保续租。
