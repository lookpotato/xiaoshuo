# 第12章人物状态回写

**时钟**：故事第6天放学后至23:47后；十一楼增至十二楼。以下以候选正文为准，未写出的私线不算已发生。

## 田小雨

- **结尾时间地点**：第6天23:47后，旅舍原房，陪睡着的可可；从窗缝看见十二楼，收到唐曼的十一楼水迹与停上行消息。
- **身体与资源**：无新增伤。原房房卡可刷，蓝包在房内，房费至第7天早晨；六零三有新横木，仍无床垫，靠墙板敞着且潮。
- **知识**：亲见可可读出“田可可”门牌、自选不进屋；知道十二楼已出现和十一楼有水，不知门牌缘由、水源及夜间探查细节。
- **关系、承诺、秘密**：兑现先问唐曼再陪可可看的承诺；承认昨夜见照片、今早进屋，以及曾想过入住会省事；答应不会让可可一个人搬进去。未编造门牌缘由。
- **下一步**：按写在凭条背面的提醒，第7天早上问房；留在旅舍照看可可，等待上层通行消息。床垫、潮处、前两晚票和一周退租仍待追办，正文尚未写她本章再去催问。
- **读者未见／主角未知**：十二楼“旧诊室储物间”标牌、周寻看见的接线盒状态和楼内下行安排，读者在现场段落见到，田小雨未获告知；私线预设的后续追办和专业核查尚未发生。

## 田可可

- **结尾时间地点**：第6天23:47后，旅舍原房睡着。
- **身体与资源**：上楼走得慢，未写伤；有书包、楼层图、校服和次早要交的本子，母亲持原房房卡。
- **知识**：亲眼读到自己的十一楼门牌，看清平台和退路；只听母亲说屋里有小床，未进屋。知道母亲昨夜看过照片、今早进屋，六零三床垫最早第7天到。睡着时未获知十二楼出现、水迹或封控。
- **关系、承诺、秘密**：追问是否被安排独住，得到母亲不会如此的答复；自己决定“我看到了。不进去了。”对隐瞒的委屈已有当面对话，是否释怀未写。
- **下一步**：在旅舍准备次日上学；何时得知险情未写。
- **读者未见**：私线设想的下一次画图与内心结论未进入正文。

## 唐曼

- **结尾时间地点**：第6天23:47后，在六号楼夜间值守与楼梯处置现场；最后精确站位未写。
- **身体与资源**：无伤情；用登记本、对讲机、电话及周寻的工作灯调度通行。
- **知识**：亲见母女完成门外短看、十二楼接出、入口牌“旧诊室储物间”，以及十一楼左门槛外的水往踏步走。仍须核对梯内人员，水源未明。
- **关系、承诺、秘密**：傍晚准田小雨、田可可随周寻并由自己殿后，只到门外，不开门；出水后划掉临时路线、停上行，叫母女留旅舍，并把水势告知二零二。未承诺新层安全或可住；储物间牌未见正文告知田小雨。
- **下一步**：继续核对楼梯内人员，按已要求的位置报告与干侧照明安排下行；水源与下方电件风险仍须查明。
- **读者未见／主角未知**：专业处置、完整人数、交班结果未写；田小雨只获电话和水迹短信。

## 周寻

- **结尾时间地点**：第6天23:47后，十一楼附近干燥一侧持灯照下行者；此后动向未写。
- **身体与资源**：无伤；工作灯先借慢行邻居、陪母女上楼，回桌充电后夜里取回；工具包有钳子，未动未知管路或线路。
- **知识**：查旧线者尚未回复，二楼公灯仍黑；见十二楼储物间牌和十一楼水迹，近处接线盒干燥，下方电件看不到；明说不知水从哪儿来。
- **关系、承诺、秘密**：刘桂芳要求旧线有信没信都告知，目前仍无准信。他未替未知水电作安全保证。
- **下一步**：在干侧维持照明和受控下行，等查旧线者回信，并按刘桂芳的要求告知有信或无信；水源与下方电件仍待核实。
- **读者未见**：私线的电量检查、备用手电、专业人员到场均未坐实。

## 刘桂芳

- **结尾时间地点**：第6天23:47后，在二零二及隔壁门口，接唐曼电话并开免提给邻居听。
- **身体与资源**：无伤；有自用手电，二楼公灯仍黑。
- **知识**：知道母女看完十一楼、仍可回已付款旅舍；旧线未回信，慢行邻居取药已归。夜里听说水从十一楼下行、二楼当时未湿；不知门内小床或储物间牌。
- **关系、承诺、秘密**：照门槛但尊重邻居不要搀扶；要求周寻无论有无旧线消息都告知；答应邻居水到二楼就敲门。未替母女决定住处。
- **下一步**：在二零二留意水势和邻居通行，等旧线回复；二零二旧表依据仍待核。
- **读者未见**：私线提到的陈姐底档追索本章未发生。

## 慢行邻居

- **结尾时间地点**：第6天23:47后，在二零二隔壁自己的门内听免提。
- **身体与资源**：腿行动不便，提物时避开疼的一侧；已取药，有药袋和手腕上的钥匙。二楼暗角仍需照脚的灯。
- **知识**：亲历公灯不亮；听唐曼说十一楼有水往下、二楼当时未湿。未见水源与十二楼入口。
- **关系、承诺、秘密**：要求刘桂芳别扶，需要换手会叫；夜里要求水到二楼就敲门。她先借灯通过，母女随后才获短看机会。
- **下一步**：在屋内等水势消息，按自己的腿力判断是否需要通行；水若到二楼须获敲门通知并重新安排照明。
- **读者未见**：私线设想的夜间下楼与排序尚未发生。
