# 刘桂芳｜第12章私线

- **故事日与时刻、地点／起点**：第6天放学后在二零二、二楼暗角与楼门附近；夜间仍以二零二为住处。第10章她已陪睡着的可可等田小雨看楼，第11章未出场；本章不能写成她已听田说过门牌或屋内布置。
- **个人目标与底线**：确保慢行邻居有光过暗角，也让二零二“仍有人住”的记录不再被断灯或短暂出门抹掉；可可若再路过，她帮忙但不替田决定住十一楼。
- **已知与未知**：知道二楼公共灯仍不能合闸、周寻承诺有查线准信会打来；知道可可母女近来住旅舍、六零三床仍在修。十一楼门牌若她听见，可知名字；不能自动知道儿童床或母女已经申请上楼。二零二原表“已退出”依据仍未核得。读者知道田已亲入十一楼，她未必知道。
- **误解、阻力与底线**：值守者可能为孩子看门而先拿走灯，慢行邻居却正在过梯。她不愿每次求灯都像抢人情；也怕别人把她替田照看可可说成她认可新层可住。
- **独立行动**：在二楼察看慢行邻居准备过梯，向楼门确认工作灯何时可借，先让对方自己试角度，必要时用手电照门槛而不拉人。若与田母女照面，只问她们今晚住处是否已落实，不追问门牌来由；听到已付款房卡后不再把孩子往二零二带。趁周寻送灯或夜间处置间隙追问公共旧线进展，要求“没有准信也直说”；23:47后若楼上水逼近楼梯，她按唐曼安排从二零二联络行动不便的邻居，不擅自上封控层。
- **代价、本场变化与下一步**：花自己的时间守邻居通行，旧线与二零二底档两件事仍压着；她把借灯从临时讨要推进到必须交接的次序。下一步等可核的修线、复测消息和陈姐的二零二底档依据，夜里留意邻居是否需下楼。
