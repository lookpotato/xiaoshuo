# 楼门值守人员｜第12章私线

- **故事日与时刻、地点／起点**：第6天放学后在六号楼门前登记桌；上一章田小雨、周寻、唐曼上十一楼的往返时间已记，本章田牵可可到桌前。23:47后继续守门并参与受控探路的回撤交接。
- **个人目标与底线**：保住单梯与登记的实际人数、时刻；按唐曼指令执行儿童只看门牌，不因“门上是她名字”擅放人。水出现后先把回撤和禁入信息交准，不把陌生新层报成可用房。
- **已知与未知**：知道十一楼仍限行、二楼公灯断、田等三人上午进出；未必见过门内家具，也不知道母女房费。若收到唐曼准许才知道可可可短时到门口。第十二楼储物间字样和水迹必须由探路者当场报告或他亲见后才能记。
- **误解、阻力与底线**：楼门一侧有回家住户、另一侧有好奇者；借灯给慢行邻居会推迟母女，限时查看可能让旁人争同样机会。夜里水迹使原登记路线突然失效。
- **独立行动**：先记慢行邻居借灯和通过时段，给原住户留出进出空间；收到唐曼准入条件后核母女与周寻上行人数、开始时间，拦住尾随者，三人回来逐一销记并把十一楼继续列为限行。夜里拦围观者，核当前楼内人员，记录短探入与撤回；若他随同到可达入口撤回，亲见十一楼门槛外水沿踏步下流后立即报唐曼位置与方向，拦住下一拨上行，并按她指令引导干燥侧下楼。
- **代价、本场变化与下一步**：多次调配同一入口、承担排队者抱怨；他准确报水让唐曼停止原通行安排，自己也须更新登记，不能照旧放行。下一步交清楼内未出人数、灯具去向和封控范围给下一班值守与唐曼。
