# 第10章人物交织表

主视角预定田小雨。第5天23:47是确定时刻，其余钟点为排场锚点，可随成稿微调；齐岩必须先于20:00完成东巷登记，再申请受控取包。以下均为成稿前设计，实际发生与否待正文确认，不提前回写人物状态。

| 时间、地点 | 交汇与相互改变 | 田小雨可见、可闻或可获告的结果 | 她看不见的行动、读者边界与后续 |
| --- | --- | --- | --- |
| 第5天下午，六零三与楼门 | 田要求先看潮横木、旧垫实物；板工拆开露出更宽湿痕，实量尺寸使蒋的“趁今天封板”改为备木和复查。蒋叫的清运司机须等楼门值守空出单梯窗口，整张旧垫才可下楼装车。 | 田在场看拆木、量尺、旧垫离房并可到楼门核装车；知道现成床位已不存在。她听板工只说施工范围，不听到“整屋可住”结论。 | 值守者与司机在楼门协调车辆、让行，不必全塞进六零三镜头；田若没到楼门，只能凭照片或蒋的回报得知装车，成稿须选一种可靠传递。拆掉的木头与潮处到第6天仍待替换、复查。 |
| 第5天下午放学前后，二零二、学校与旅舍 | 刘按约短时接可可，阻止她独自上六楼取书；田结束看工后亲自接过孩子，带去原旅舍。可可问明早书包从哪儿拿，使田先把上学与睡处定下来，再同蒋谈旧票。 | 田亲见与刘交接、可可的书包和蓝包；向可可说明今晚仍住原房，明早由旅舍出发。旅舍前台核钥匙与第6天早晨到期。 | 可可在学校整理作业、刘为接送调整傍晚安排，田在到场前不知具体细节；刘追二零二底档仍未有依据，公共照明仍断。 |
| 第5天下午至20:00前，东巷旅舍 | 齐岩把“短信上有房”变成亲自登记、领钥匙、进房；东巷前台据实际房态交钥匙并供陈姐核。齐岩的回电改变陈姐的记录：临时房已进，但北边旧屋衣物还在。 | 田若不在东巷，只能之后由齐岩、陈姐或唐曼明确转告结果；不能让田凭楼门一瞥知道房号、钥匙和电话内容。 | 这是主角镜头外的有效行动。读者若坚持田的单视角，只能经回电截图、钥匙、齐岩后来的话进入正文。房东换锁是否合法、何时取衣物仍未证实；陈姐继续追问房东，不预支回信。 |
| 第5天傍晚至夜初，六号楼楼门、二楼暗角至十楼 | 齐岩领房钥匙后还要自己的包；唐曼只给短时、单人陪同的取物窗口。周寻补工作灯、楼门值守错开清运与住户，陪同者带灯往返；齐岩下楼点包，不留下过夜。 | 田若在旅舍，只能后来听唐曼或齐岩说“包已拿到、十楼仍限行”，不能亲见十楼内动作，也不知包内所有物。 | 齐岩独自清点包与保留旧屋衣物清单，唐曼记出入时刻；这两件不自动进入田的知识。二楼借灯通行仍占用值守资源，新层未经承重、供电、消防核验。 |
| 第5天夜间，旅舍房与电话 | 蒋以“明早装木就退房”催定时间；田以床位已搬空、潮处未复查为据，只同意明早送可可上学后复看六零三，不接受自动退房。可可问自己的睡衣、作业与上学路线，让争论回到当夜生活。 | 田亲见可可在原房安顿、可核房钥匙有效；电话里能听到蒋自己的话，不能知他私下已否买到合尺寸木料。 | 蒋继续核木料、清运和旧票，若没有可核付款或供货记录，成稿不能说次日必装好。第6夜旅舍费用成为下一次交锋。 |
| 第5天23:47，六号楼外、楼门 | 第十一层在外轮廓真实接上；楼门值守清出入口、唐曼维持限行，周寻提供有电工作灯并报告二楼暗角仍黑。新层增加唐曼当夜的核看任务，也改变田对明早退房的判断。 | 田此刻仍在旅舍，先获唐曼来讯，不写成同时亲眼目睹增层；可可留旅舍。 | 探路值守者还没报门牌前，唐曼、周寻、田均不知名字；读者从七零一曾写田小雨可预感家庭压力，却不能由此推断楼的机制。 |
| 第5天23:47后，受控楼梯口至十一楼门前 | 探路值守者带灯短时查看并拍清“田可可”，原路退回；唐曼先核照片、时刻与位置，再把图给田。田请刘到旅舍陪可可，刘到后田才离开，去楼外目视核实新层。 | 田通过有来源的照片知道门牌姓名，通过自己目视知道楼体确增；她没亲摸十一楼门、没见屋内，也没有入住资格。她拒绝因门牌而让可可明早去新层或未经复查回六零三。 | 值守者亲见的接缝与门牌不等于整层安全；可可若尚未被告知便不知道门牌写她。唐曼需保存原图与出入记录，次日安排进一步核验。 |
| 第5天深夜，旅舍与第6天待办 | 田把可可睡衣留在旅舍、明确明早先送学再复看；蒋须回答可住床位和下一晚房费，陈姐继续追齐岩旧屋衣物，周寻继续追公共线，刘继续守二零二真实居住证据。 | 田只掌握自己作出的安排和收到的确认，不替别人宣布问题解决。 | 楼已是十一层并留存；孩子名字公开在受控门牌上，但原因未知，齐岩临时房与北边旧屋争议并存，六零三仍缺可睡床位。 |

## 汇总前硬检查

- **主角离场仍会行动**：齐岩先到东巷领钥匙并回陈姐电话；陈姐追房东衣物；唐曼排取包与核门牌；刘接可可并守照脚灯。各线有目标、选择和未完后果。
- **主角看不见的有效行动**：齐岩实际进房、取包清点与陈姐继续追旧屋，均不能由田小雨的旁白全知播报；只能用钥匙、回电、出入记录或当事人转告进入正文。
- **两线真实互改**：田的实物要求打断蒋封板和退房时间表；板工实量又使田不许明早自动回住；齐岩领钥匙才使唐曼同意安排限时取包；可可的上学问题使田先定夜宿再谈旧账。
- **知识与误解保留**：田可知道十一楼门牌照片，却不知楼为何写可可；可可未被告知前不知名字上门；蒋可希望明早装木，却尚不能证明床能睡；齐岩不因旅舍入住丢失旧屋衣物要求；唐曼只核通行与门牌，不宣布新层可住。
- **各自下一步**：田送学后复看与谈下一晚，蒋带合尺寸木料及费用答复，可可上学等母亲结果，齐岩从旅舍追旧屋衣物，陈姐催取物时间，唐曼守十一楼限行，周寻追公共线，刘追二零二底档；板工待料复查、前台按实际房态办次日、值守留记录。
