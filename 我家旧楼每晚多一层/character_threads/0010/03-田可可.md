# 田可可｜第10章私线

- **故事日与时刻、地点／起点**：第5天放学前在学校，放学后由田小雨接去原旅舍房；23:47时仍在旅舍。上一章母亲语音告知今晚仍住原房，睡衣在蓝包里。
- **个人目标与底线**：明早带齐要交的作业、按时上学，今晚有熟悉的床；不被带去试潮床或未经核验的十一楼，也不成为成年人钱账的见证工具。
- **已知与未知**：知道六零三床位潮湿、室内线已处理但仍没回住，自己那本练习册皱角；不知道板工拆开后湿痕大小、旧垫车费、齐岩取包或十一楼门牌。读者在章末可先于她看到门牌与母亲的反应；若田尚未告诉她，她仍只知道明早照常上学。
- **误解与阻力**：听见“坏木拆了”可能以为可以把蓝包带回家；母亲必须说明现在连旧垫都不在，换木、复查和床位还缺。她想拿自己的书，不想再被大人反复说“明天再看”。
- **独立行动**：放学后核书包里干作业与单装的皱角册，到旅舍把睡衣找出来；追问明早从哪儿出发、六零三的床怎样了。听田说今晚留原房后，把第二天的书放在小桌靠门一侧，避免早晨再回潮屋取。若听见大人夜里谈十一楼，只提出与自己生活有关的问题，不自行下楼或登楼探看。
- **代价、变化与下一步**：继续搬书与睡衣、没有自己的床；她得到当晚具体去处，却没有回家的日期。第6天照常上学，等母亲复看结果再知道是否继续续房。
