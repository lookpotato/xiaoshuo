# 陈姐｜第10章私线

- **故事日与时刻、地点／起点**：第5天下午在街道联络渠道与六号楼附近；20:00前接齐岩从东巷旅舍的回电，随后继续联络其北边旧屋房东。
- **个人目标与底线**：把齐岩“有登记短信”核成实际钥匙和房门，把旧屋衣物取回留成下一件待办；不以临时住宿注销原租住事实，不替唐曼决定新层能否进入。
- **已知与未知**：知道前台曾确认八点前登记、第一晚街道经费结，知道齐岩自述屋内衣服有一半未取；房东回信详情是否已经转到她手机，正文未展示，须本章由齐岩重发或当面核。她不知道齐岩已入住，直到本人回电与前台登记互相印证；读者在此之前也只见他拉箱离楼。
- **误解与阻力**：自己发出的短信可能被旁人当作安置已完成；房东“另约”没有日期，衣物需要取却不属旅舍前台能解决。还要处理二零二底档待核，不能把不同住户的记录串在一起。
- **独立行动**：在八点前接齐岩电话，问房号、钥匙是否拿到、能否进房，向前台核登记与第一晚费用；提醒临时房续住另核。请齐岩列出北边旧屋衣物与急需物，核房东回信后再联系房东约取物窗口，若当晚只得到“另约”便照实告知，不许一个虚假的明早开门时间。将十楼包的请求转唐曼安排通行，不把其写成新层入住。
- **代价、变化与下一步**：一夜房费落实后仍有续住和旧屋交涉，电话与记录叠加；齐岩从“可能有房”变成已进临时房的人，但不是已结案租客。第6天继续追房东明确取衣物时间与后续住宿经费；二零二原表依据另追。
