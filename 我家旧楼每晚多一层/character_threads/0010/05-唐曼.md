# 唐曼｜第10章私线

- **故事日与时刻、地点／起点**：第5天下午至23:47后，六号楼楼门值守处、受控楼梯口。十楼仍限行，二楼公共照明断；齐岩下午只拿登记短信向东巷去。
- **个人目标与底线**：让齐岩真正有房可住且短时取包，楼门单梯始终能让人下行；新十一楼出现后取得可核门牌与楼体记录。不宣布十楼、十一楼可长期住，不带可可上新层，不凭门牌给人产权或入住命令。
- **已知与未知**：知道齐岩旧屋门打不开、东巷房留到20:00、包留十楼；但他实际领钥匙须其回报或陈姐确认。知道九楼至十楼仅曾走通一次、二楼暗角仍黑；十一楼内部在23:47前不存在于她的现场知识。读者读计划知道会写田可可，她不能预先知道。
- **误解与阻力**：住户可能把齐岩准上楼取物听作“十楼放开”，新层又会吸引围观；同一盏工作灯还要给慢行住户照脚，清运旧垫会占梯宽。她须逐趟错开，不让两个方向的人在窄段相撞。
- **独立行动**：先核齐岩是否确已拿到房钥匙，再在清运与居民上下楼的空档，安排一人带灯陪齐岩短时取包、另一人守楼门，记进出和所取物，口头重申取物不等于入住。23:47见外轮廓增层后，清楼门与二楼暗角，限十一楼人员；派已配灯值守者只到可退回的位置核门牌、拍照并回报，不让田小雨追上去。将姓名照片给田看，让她自行到楼外核楼体，同时记录来源、时刻与禁止进入范围。
- **代价、变化与下一步**：夜间排班、灯电和单梯窗口更紧，面对田母女急迫追问；十一楼姓名成为她需保护和核实的记录，不是处理结论。第6天继续限行并请求专业查验，向田明确能复看的六零三与不能进的十一楼分属不同问题。
