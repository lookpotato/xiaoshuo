# 第16章人物状态回写

依据第16章候选正文。承接第15章末的第8天放学后，章尾前楼下有人喊晚饭；未跨23:47，最高仍为十三层。以下只把正文写出的行动和传话记为事实；写前私线未兑现的部分标为“读者未见”。

## 周寻

- **结尾时间地点**：第8天傍晚，仍在六零三原床脚旁，与蒋福安蹲着看新水痕浸到干纸；具体钟点未写。
- **身体与资源**：带工具包和手机；与蒋搬开床架、把仍封膜的床垫放在挪到屋中的床架上，调整椅子、被褥和门口通道。手机留有铅笔线、湿边、旧床脚印的照片；一张擦过墙脚的湿纸折入工具包侧袋，另一小截干纸留在原床脚处并在章尾洇湿。没有写他受伤或付款。
- **知识**：亲见旧记号线外的新湿边、墙脚擦后再渗水、干纸洇湿；试过门可开到底、单人能进出，见楼道没有堆床垫。第15章已从田小雨消息知道她试开当晚房卡，本章又听她电话确认；看到蒋按确认、核转账记录，听田说“到了”。潮源、整栋楼安全及六零三可入住结论均未知。
- **关系与承诺**：兑现对蒋“过去看看”的答应，帮忙安置床垫；当面对蒋说“今晚不能让人睡这儿”“别往回推了”，没有替复查人背书，也没有代田小雨表态。蒋问照片时给他看了现场照片。
- **秘密／读者未见**：周寻未到旅舍，只从电话听田与可可的片段，不知道她账户画面或是否已订下一晚。私线拟定的把返潮位置与时间交给查源人员、催蒋今晚开墙，正文均未发生。
- **下一步**：保存照片和试湿痕迹，等待或推动蒋决定怎样查明墙脚水源；继续避免把暂存床垫说成房间可住。

## 蒋福安

- **结尾时间地点**：第8天傍晚，六零三原床脚旁，扶着已挪开的床脚看纸被新水痕洇湿。
- **身体与资源**：亲手搬床架和床垫，椅子收向桌边；新床垫仍封膜，横放在移到屋中的床架上，与潮墙分开，未铺成可睡的床。第8晚旅舍费此前已付；本章又按田报的金额转出下一晚房费，核过收款姓名和金额，田在电话中确认到账。门可开到底，楼道没有床垫。未写受伤或退货。
- **知识**：亲见旧床脚后湿边越过铅笔线，周寻给他看照片；章尾又亲见擦过的墙脚渗水、干纸洇湿。他先向周寻问“她卡不是开了吗”，听周寻答“开了”，随后在电话里听田亲口确认门能开；不应写成第15章末就已知试卡成功。知道田收到了转账，但不知她是否续订成功。潮源仍未明。
- **关系与承诺**：放弃将床垫推回原靠墙床位；亲自打给田小雨，告知墙后仍湿并说“今晚先别回来住”，答应转下一晚费用且已实际转出。田说由她自己续房，他答应；与周寻一起保留湿迹证据，未要求周寻给入住保证。
- **秘密／读者未见**：他独处时如何盘算、是否问过退货、是否已约维修人员，正文未见。私线拟定的对第9晚以后的持续承担、今晚打开潮处查源，尚未成为正文承诺或行动。
- **下一步**：决定如何请人查明正在返潮的墙脚，并在房间不能交住期间继续与田商量住宿；床垫只能暂存在当前干处。

## 田小雨

- **身体与资源**：持有已试开第8晚旅舍房门的房卡这一前章事实；本章获蒋转来的下一晚房费，电话中说“到了。我来续”。正文没有写她完成续订或拿到下一晚有效房卡。
