# 查线人员｜第 7 章私线

- **故事日与时刻、地点／起点**：第 4 天上午到六号楼二楼公共灯座、一楼公共照明闸位；由现场安排请来的有相应资格的查线人员，姓名与单位未在既有正文确定。
- **个人目标**：判断烧损段能否在安全查修与复测前送电，给住户一条可信的后续路径。
- **已知与未知**：到场前只可从交接得知昨夜冒烟、消防隔离、旧公共照明断开；周寻第 3 天傍晚何时见黑痕、当时做了什么，须当面听他补全。不知道九楼电源，也不负责六零三湿线的施工判断。读者已见九楼独亮，但不能以此推导任何接线图。
- **误解、阻力与底线**：住户急着复灯，老胡更想借九楼光；现场肉眼可见的灯座坏处不足以证明线路其余段安全。不能凭换灯座、试合闸或新楼层亮灯宣布可恢复。
- **独立行动**：先核隔离与断闸状态、照片时间、现场焦损及需进一步检查的旧线段，向周寻追问黑痕与冒烟之间的时间差。明确告知烧损段需要更换并复测，今天不能仅换灯座就合旧闸；把九楼仍亮记作独立观察，供电来源留待另查。对唐曼和住户说清“暂不能亮”与何种检查完成后再评估，而不许诺具体复电日。
- **代价、本场变化与下一步**：给出的限制会招来催促，需留下查修范围和复测要求；下一步安排或移交公共线更换、复测，查九楼供电须另循合适程序，不能由一次二楼查线代答。
