# 田小雨｜第15章私线

- **故事日与时刻、地点／起点**：第8天早晨旅舍新房与柜台，随后送可可上学；办妥后电话联系周寻。第7天的卡到今早，蓝包和母女用品仍在旅舍，六零三墙潮、床垫未交付，十一楼湿房禁入。
- **个人目标与底线**：取得今晚真正有房、有付款、有可用卡的去处，让可可放学知道进哪扇门；不拿六零三或十一楼的未完成状态替代这件事，也不把蒋昨夜的口头答复当付款。
- **已知与未知、可能误解**：知道蒋答应昨夜回复后续房费但正文未见回复；前台掌握房态，她须到柜台核。夜里只从旅舍窗见十三楼新窗，不知道祖孙现场争执或十三楼窄道、实测和邻楼反应；读者随后从周寻场景获得的勘查知识不能转给她。
- **阻力、独立行动与交汇**：先向前台问今日可入住房间和期限，再向蒋要求先解决可可今日去处；蒋想等六零三维修消息时，把当前卡期与孩子放学的时间摆到面前。等他实际付清一晚、前台核到账后，与可可试开有效房卡，记清房号与期限。其后只打电话向周寻报“已付款、可可放学去哪间”，不讲自己未获知的十三楼细节。
- **代价与变化、下一步**：又消耗一个早晨办卡、送学，得到的仍只是一晚，旧票与退租未结；母女今天有可返回的门。下一步继续问六零三潮源、床垫交付和再下一晚费用，不把一晚付款当长期解决。
