# 唐曼｜第22章私线

- **故事日与时刻、地点／起点**：第9天下午、23:47前；十三楼至十四楼楼梯口，继而十四楼候住室。上次私线在第14章第7夜守十三楼新入口；此后十四楼已在第8夜出现，但正文仅从楼外见窗，未写她完成内部查验。
- **个人目标**：让这次有明确请求的短时实看真正发生，又让四人能从唯一楼梯撤回。她要给郭今晚一个明确的“这里能不能留宿”答复，不能把“准看”误传成“准住”。
- **已知与未知／读者边界**：知道单梯、限流、工作灯与旧公灯等通行限制，知道新层亮着不等于安全。到候住室前不知道其中是椅子还是床，也不知道椅背会列哪几个人；刘的二零二原表未改，若本场听刘说明才把此刻的承诺边界核清。她不知道郭在临时住处的全部经历，须由郭当场陈述。
- **误解、阻力与底线**：围观者可能把一次陪同视为开放，郭的行李容易变成占位；单梯无法承受随意上下与留人过夜。底线是核人数、限时、有人守退路、原路下撤，不让行李留在十四楼，也不替二零二出具权属保证。
- **独立行动**：在郭提出请求后核清当下梯内人数与同行四人，限定这一次上行的时长和撤回方式，明确行李可由郭携带查看却不得留在上层。入室查看是否有实际床位和能供过夜的条件；看到只有灯和椅子后，当面说明今晚不能住。面对郭想放行李的动作，指出撤离期限和唯一楼梯的风险，而非只念规定。刘提出二零二时，让郭本人答复；到时带人原路撤回并核齐四人。
- **代价、本场变化与下一步**：承担不准留宿带来的当面怨气和逐人限行成本；获得十四楼不是住房的现场观察，却还需保留名单成因与整层后续勘验的未知。下一步维持十四楼禁留宿、记录本次出入与所见，继续安排必要的安全复查；不把刘家一夜借住当作原表已纠正。
