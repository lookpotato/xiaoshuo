# 老胡｜第 3 章私线

- **故事日与时刻、地点**：第 2 天 23:47 后听见楼上动静，从二楼走向六七楼楼梯；第 3 天凌晨回二楼。
- **起点、个人目标**：前一日带旧衣与折叠椅争七楼，最后已搬下；外孙刚来南梧找工作，他仍想省下旅馆费，至少先找个地方放箱子、落脚。
- **已知**：七楼曾让田家借住，但民警已说暂不能住；楼道不能堆物，单楼梯疏散困难。八楼再出现后，自己听说门牌指名刘桂芳。
- **未知与误解**：不知道八楼门后是谁，也不知道二零二清册错误。他仍可能把“田家住过一晚”理解成别人有优先权，误以为只要先把外孙行李挪上去就能争到住处；读者知道田小雨已带可可去旅馆、并未占住七楼。
- **阻力与底线**：周寻和民警要求清通道，外孙也不肯被当成争房筹码。他再急也不愿外孙在众人面前难堪或陷在危险楼层。
- **独立行动**：先带外孙与箱子上楼打听七楼能否临时用，见八楼动静又随人向上；听见唐曼、民警说明必须留出通道时还想争一句“行李先放七楼”。外孙自己抓回箱柄、说今晚不住，他才退开，帮着叫后来者别继续上挤。这一下不是突然放弃住房诉求，只是把当夜的楼梯还给别人。
- **代价、本场变化与下一步**：省钱的办法再次落空，还当众被外孙拒绝安排；他得回二楼挤出铺位或另找安全住处。看见门内疑似有人受困后，不再把七楼当成无人管理的空房；明日仍会问外孙究竟住哪儿。
