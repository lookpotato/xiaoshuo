# 刘桂芳｜第 3 章私线

- **故事日与时刻、地点**：第 2 天 23:47 后从二零二赶往八楼平台；第 3 天凌晨回二零二开门核验，随后停在被清空的楼梯安全位置向八楼喊话。
- **起点、个人目标**：她仍住二零二、保管公共设施钥匙，前一日才提醒周寻找人查逃生。听说八楼门牌写她名字，她想亲眼看清，也想知道内门后是否有人；在发现清册错误后，她更要让现场人员承认二零二是自己每天进出的家。
- **已知**：旧楼原只有六层，七楼出现且此前不能随意住；自己有二零二钥匙、日常物件和近期缴费凭据；旧照片里有拆除的消防梯。上到平台后，她亲见自己的名字及绿漆内门，听见锁声，却听不到回答。
- **未知与误解**：不知门后身份、处境，八楼门牌也不授予她房屋所有权；起先担心一离开八楼，旁人会把锁声归为空响、把那扇门连同她的名字一起封掉。读者知道二零二仍有生活痕迹，但在她打开门前不知道待执行清册竟将其写成“已退出”。她保留的旧收条及其来历是自己的旧事，本章不主动交出或解释。
- **阻力与底线**：唐曼要求限流，民警阻止贴近未知内门；清册又把她现在的家写没。她不接受别人据八楼门牌替她决定搬家，也不愿以私闯新层换一次求证。
- **独立行动**：在周寻报警后自行带钥匙上楼，只到八楼平台看门；被请下楼时先追问谁会继续守锁声。看见“二零二已退出”后，她决定暂离八楼，带唐曼和民警回二楼，亲手开门，用仍热的饭、惯用物件与缴费凭据证明当夜实际居住。核验后她在允许的位置向八楼喊话，试图让门后人应声。
- **代价、本场变化与下一步**：当众暴露住处、生活细节和清册异议，且在最想守门时离开八楼。她保住了二零二住户参与现场决定的资格，却没查明门后人。喊话后听见急步、重物跌倒和锁声中止，她遵守不得自行上楼，准备向民警与救援人员提供她认得的旧式门细节，但先说清哪些只是记忆而非现场确认。
