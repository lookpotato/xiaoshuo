# 第 3 章人物私线名册

## 角色名单

- 周寻：主要视角与锁声首个目击者，留证、报警并为现场留出单楼梯通道。
- 刘桂芳：二零二实际住户和八楼门牌所指之人，亲眼看门后选择回家证明自己的住址。
- 唐曼：到场的房屋安全巡查员，限制新旧楼梯交接处人数并核对实际住户。
- 现场民警：接报到场的秩序与疑似受困处置人员，隔开围观者、见证核验并联系救援。
- 老胡：二楼住户，仍想为来找工作的外孙争取可住的地方，最后让出楼梯。
- 老胡外孙：带行李来投靠外公的求职者，拒绝在众人面前被安排进未知的七楼，自己把箱子带回二楼。

本章从故事第 2 天 23:47 后续接，到第 3 天凌晨结束；未经过新的 23:47，最高仍为八楼。田小雨母女在旅馆，王叔与蒋福安本章不安排现场行动。围观住户只作现场群体，不另设能改变局面的具名人物。
