# 老胡外孙｜第 3 章私线

- **故事日与时刻、地点**：第 2 天夜里带箱子到六号楼二楼投靠外公；23:47 后被带到六七楼之间，第 3 天凌晨自行把箱子带回二楼。
- **起点、个人目标**：来南梧找工作，需要今晚能睡、明天能出门的落脚点，不愿被外公当众拿自己和田家、刘桂芳比较。
- **已知**：外公家狭窄，附近旅馆贵；七楼有人借住过，但现在被提醒暂不可入住。亲见楼梯挤满人、八楼门内有不明锁声。
- **未知与误解**：不知道七八楼怎么出现、七楼水电是否安全、八楼门后是谁，也不知道二零二清册差错。他可能以为外公已替他问妥七楼，直到现场听见并没有人能给他开入住的口子。
- **阻力与底线**：行李和旁人的眼光让他难堪；他可以接受临时打地铺，却不愿未经允许住进门牌写着别人名字的新层。
- **独立行动**：起先提箱跟着外公上楼，没有立即反驳；当外公仍要把箱子搁七楼，他把箱柄从外公手里接回来，说明今晚先回二楼，自己下楼。这一选择使老胡不得不停止在楼梯上争位置，跟着让道。
- **代价、本场变化与下一步**：放弃可能省钱又宽敞的一间房，今夜要挤在外公屋里，明天还得找住处和工作。他没有替外公解决花费，却给自己的去处划了边界。
