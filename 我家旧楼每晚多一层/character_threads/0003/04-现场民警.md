# 现场民警｜第 3 章私线

- **故事日与时刻、地点**：第 2 天 23:47 后接周寻再次报警；第 3 天凌晨在六至八楼楼梯、八楼平台与二零二门口处置。
- **起点、个人目标**：承接前一日的报警记录，确认新增八楼及门后是否有人需要帮助，同时让单楼梯保持可进可出的通道。
- **已知**：前一日民警已核实七楼、要求暂不入住并转街道和房屋安全部门；本次有周寻拍摄的时间与门牌、现场可听见的锁声。二零二开门核验后，亲见刘桂芳确实居住的迹象。
- **未知与误解**：不知道绿门后人的身份、伤情与门锁状况；清册状态不能代替现场寻找。此前若按“空层”处理的惯性看问题，锁声和二零二的核验会迫使他改用疑似有人受困的判断。
- **阻力与底线**：住户想上前探看，梯宽有限；他不能凭声音认人，也不能让未受训住户为证实身份自行开门。保持救援通路，及时升级处置。
- **独立行动**：先将围观者劝退，记录周寻所见，隔开刘桂芳与绿漆内门，对门内喊话而未获回答；留意门内锁声持续和中断时刻。与唐曼到二零二核验当夜居住事实，回到楼梯位置后在刘桂芳喊话及跌倒声出现时立即联系消防、说明疑似有人受困和单楼梯限制，维持现场秩序。
- **代价、本场变化与下一步**：原本可按异常楼层看守等待进一步勘查的节奏被打断，必须立即按可能有人受伤推进救援；补记谁在何处听到跌倒声，准备向到场消防交接，而非等清册核查完成。
