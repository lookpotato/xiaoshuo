# 第 3 章人物交织表

主视角为周寻。时间均为故事时间；以下时刻是编排锚点，可随正式场景的动作时长微调，但须保持第 2 天 23:47 后接续并在第 3 天凌晨结束。

| 时间、场所 | 人物行动与交汇 | 周寻可见／可闻的结果 | 周寻未见或尚未知的结果；后续影响 |
| --- | --- | --- | --- |
| 第 2 天 23:48—23:52，七八楼交界 | 周寻拍新台阶、门牌和时间，再次报警，说明门内锁声；刘桂芳带钥匙从二零二赶来。 | 门牌确写刘桂芳，锁声持续；刘桂芳看见名字后仍要亲自上平台。 | 刘桂芳先想的是自己在二楼的家和旧楼道，不只是八楼能否入住；周寻尚不知清册错误。 |
| 第 2 天 23:52—第 3 天 00:02，八楼平台及下方楼梯 | 刘桂芳坚持只走到能看清门的位置；周寻请其余人退至六楼。老胡带外孙与箱子上来，想问七楼能否先放行李。 | 新层是可触碰的过道；绿漆内门后有拧锁声却无人应答。楼梯一挤，刘桂芳与其他人都难以下行。 | 外孙不想被公开安排住处，此时仍沉默；他的决定稍后改变老胡的计划。 |
| 第 3 天 00:02—00:12，八楼平台 | 民警到场隔开围观者，对内门喊话、记录锁声和周寻目击；刘桂芳被请离开平台。 | 声源在内门一侧，身份仍未确认；八楼转为看守的疑似滞留现场。 | 民警已把通道与人身风险并列处理，不能凭门牌认定门后是刘桂芳或某个熟人。 |
| 第 3 天 00:12—00:22，六至八楼交界 | 唐曼到场测记交接处、限流，并拿待执行清册核实际住户。刘桂芳发现二零二列“已退出”，先争辩自己仍住那里，再提出回家开门给他们看。 | 周寻能听见清册冲突、刘桂芳的决定，也能看见她暂离八楼；他留下保持楼梯畅通。 | 清册的来源与更改人仍未知。唐曼不能据一纸记录清场，开始对现场清点负责。 |
| 第 3 天 00:22—00:32，二零二 | 刘桂芳亲手开门，唐曼与民警查看仍热的饭、日常物件和近期缴费凭据；唐曼注明当夜实际居住，转为逐户敲门并联系街道核原表。 | 周寻若守楼梯，只能听到事后当事人的简短交代、看到二零二可正常开门；不能代替他们描述房内未见细节。 | 刘桂芳为证明家仍是家，公开了自己的生活和凭据；街道原表未被电话或记录当夜“改好”。这份错记会继续发酵。 |
| 第 3 天 00:25—00:35，二楼至六楼楼梯 | 老胡还想把箱子放七楼；外孙接过箱柄决定先回二楼，老胡让道并劝后来者别挤上来。 | 箱子退出通道，民警与救援人员的上楼路可用；周寻没有替他们分房。 | 外孙今夜住处仍窄，老胡明日还会继续找房；周寻未必听全两人的私下争执。 |
| 第 3 天 00:35 后，清空的楼梯与八楼内门 | 刘桂芳按要求留在安全位置，隔楼梯向门内喊话；门后急促脚步、沉重跌倒声接续传来，拧锁声停止。民警立即联系消防，唐曼提供通道数据并维持限流，周寻报出声源和时间。 | 众人听见同一声响；从围观看门改为疑似有人受困的救援现场。 | 门后身份和伤情仍未知；下一章须及时完成现实救援判断，刘桂芳需要决定是否说出自己记得的旧门细节。 |

**互相改变计划**：刘桂芳的开门提议使唐曼放弃照清册点人的捷径；唐曼的限流又迫使刘桂芳暂离八楼。外孙主动带箱子下楼，使老胡停止争放行李，也让民警有可用的上楼通道。周寻不在二零二屋内的核验和唐曼联系街道，属于有效但不能由他的内心镜头直接播报的行动。
