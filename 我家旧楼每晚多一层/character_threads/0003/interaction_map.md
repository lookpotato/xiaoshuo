# 第 3 章人物交织

1. 第二夜八楼出现。周寻录影、报警、隔门呼喊，不往楼群转发刘桂芳名字；接警员要求他退离门口、防止聚集，民警因新增楼层再次到场。刘在二楼尚不知影像已留存。
2. 周寻先核刘的二楼门，再给她看照片。刘拿起钥匙想亲眼上楼，周寻阻拦使她误以为熟人也要替她作决定；她改为等工作人员到场而不是独闯。
3. 唐曼先隔人群，再允许刘在限定人数内查看。民警与唐曼叫门无人应答，找到响声对应的旧内门；刘自行收手不碰锁，唐曼仍保留门后未知的判断。周寻只能提供镜头内事实。
4. 次晨街道工作人员为核在住户带来清册，原先并非专为八楼而来。刘发现二零一被标退出，拒绝让周寻代答，实名提出异议；工作人员收影像并给回执。唐曼因此把下午催核对纳入自己的行动。
5. 离场后仍发酵：清册经办人尚未在镜头内回应，主角不知道错记来源；刘带着回执回二楼，唐曼要复勘八楼，街道工作人员需在明早发通知前核原表。
