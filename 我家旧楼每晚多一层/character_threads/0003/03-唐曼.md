# 唐曼｜第 3 章私线

- **故事日与时刻、地点**：第 3 天凌晨接通知到柳北里六号；先在六至八楼楼梯交界勘看，再到二楼二零二核验，最后在楼梯安全位置组织下一步处置。
- **起点、个人目标**：作为街道聘用的房屋安全巡查员，携带下周待执行迁居清册到场。她要确认实际住户和单楼梯通行状况，控制新旧楼梯交接处人数，留下能交接的现场记录。
- **已知**：接报楼体再增一层且八楼有锁声；旧楼本是六层、单楼梯。清册把二零二列为“已退出”，但这只是待核的行政材料；从现场可测见交接尺寸、可见内门与狭窄通道。
- **未知与误解**：起初不知道刘桂芳仍在二零二生活，也不知道清册何时、由谁、据什么依据改成已退出；无法靠一次量尺判断整栋楼长期可住，不能推断绿门后身份或结构承载力。读者比她早知道刘桂芳住二楼，但直到她出示清册才知道记录冲突。
- **阻力与底线**：围观者想上楼、刘桂芳想贴门，门后却可能有人；若照表清场会漏掉实际住户。她不以巡查员身份替民警执法，也不签“可安全长期入住”的结论。
- **独立行动**：到场先量并记新旧台阶交接、建议把围观者退到下方，和民警分清通道与看守位置。出示清册逐户核对时发现刘桂芳与“已退出”矛盾；接受她回二零二现场开门的提议，查看实际居住迹象与凭据，在记录中标注当夜二零二有人居住、原表待查，转为逐户敲门清点，并联系街道核原表。她可以留在二楼见证核验，周寻留在楼梯，这段行动不必全由主视角目击。
- **代价、本场变化与下一步**：她必须承担当夜用现场事实修正清点范围的责任，额外逐户核对、联系街道，不能凭原表省事。门内跌倒声出现后，立即和民警判断限流与救援入口；由民警联系消防，她提供通道测量和人数信息，继续守住不让围观者挤回楼梯。
