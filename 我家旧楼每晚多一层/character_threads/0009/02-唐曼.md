# 唐曼｜第9章私线

- **故事日与时刻、地点／起点**：第4天23:47后在楼门值守桌旁，刚派一人带灯上楼探路、另一人守门；第5天仍处理新层限行。
- **个人目标**：取得十楼门、九楼接缝、二楼暗角的可走路线，让齐岩有序下行，阻止围观尾随；他失去旧屋后仍把住处问题交到可执行的临时住宿联络。
- **已知与未知**：知道十楼窗后人自称站稳、看得见门，未知姓名、伤情、来路和屋内实况；九楼亮、旧公共照明断，不等于新旧层承载、电路、逃生已核。齐岩收到房东通知一事须本人说出，她不能由门牌推知。
- **误解、阻力与底线**：有人会把“人下来没事”当作允许回去睡；单楼梯既要让接应者上去又要保持出口。她不让周寻独自摸上新层，不给产权或可入住结论，不用阻拦替代陈姐落实可进门住处。
- **独立行动**：要求探路者按九楼口、接缝、十楼门、返程顺序回报，问齐岩姓名、是否受伤和能否走；分配一上一下的灯与守门位置，分段引导下楼并登记时间。听齐岩问可否回十楼时，说明目前只为接人通行、未核住用；次日他带行李求住，先保留楼门通道，再请陈姐现场确认有钥匙可领的临时房间，要求齐岩作现实选择。
- **代价、变化及下一步**：值守人手和工作灯被占用，围观管控延长；从“窗里待接者”转成“已无旧屋可进者”的处置压力。下一步保留实测和出入记录，申请新层供电、承载、逃生核验，继续守限行。
