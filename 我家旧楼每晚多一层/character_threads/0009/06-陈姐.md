# 陈姐｜第9章私线

- **故事日与时刻、地点／起点**：第4天深夜不预设她就在六号楼；接到现场通知后，通过电话或到场接手齐岩的临时落脚联络。第5天可在街道、旅舍和楼门之间处理。
- **个人目标**：把“十楼有人下来”核成姓名、联系电话、今夜可进门的去处；次日旧屋进不去时，给齐岩一个房号、费用承担与领钥匙办法均已确认的现实选项。
- **已知与未知**：此前只知二零二原表依据仍待查、郭冬梅的临时旅舍安排；十楼情况须唐曼或值守者通知后才知道。齐岩旧钥匙打不开门须听本人陈述、看照片或当面核，不能仅凭门牌或读者所知预认定其已无房。换锁是否合法、租约如何处理未知。
- **误解、阻力与底线**：曾能用东巷旅舍解决一晚，容易以为发个地址就够；齐岩需要实际可领钥匙且不先垫无法承担的费用。她不以行政短信代替房间确认，不因临时落脚注销旧租住争议，也不替唐曼给新层放行。
- **独立行动**：当夜接电话，核齐岩是否能先返回原屋或须即时安排，留下可回拨方式；次日收到换锁证据后联系可接收的临时房，问清房号、前台值守、所需证件、领钥匙时刻和费用承担，将确认消息直接给齐岩看，并在楼门当面等他答复或提出不能接受的具体原因。二零二底档仍另线追，不将齐岩地址写入刘桂芳记录。
- **代价、变化及下一步**：夜间和次日增加一户真实住宿协调，临时房经费与续住都要继续核；下一步确认齐岩是否实际进门，再查其原租住事实及后续安置。
