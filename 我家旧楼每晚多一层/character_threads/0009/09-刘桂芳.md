# 刘桂芳｜第9章私线

- **故事日与时刻、地点／起点**：第4天23:47后与慢行邻居在杂货铺檐下，刚给楼门腾出通道；之后须回二楼二零二。
- **个人目标**：让邻居能看清二楼踏步、自己回二零二，继续保留实际居住的证据，不因一次夜间避让又被记成“退出”。
- **已知与未知**：亲见十楼亮窗、听窗后人求路，知道旧公共照明闸仍断且唐曼借工作灯；不知道十楼门内路径、齐岩身份和原屋纠纷。读者知道收条原件已交郭冬梅，刘只持照片；陈姐尚未拿到二零二原表依据。
- **误解、阻力与底线**：想帮忙却不应抢唯一工作灯上楼；周寻迟断闸的信任问题仍在。不能要求邻居趁救人时摸黑回去，不能把新层灯当旧梯复电。
- **独立行动**：在檐下让人和出口，拿自己的手电给邻居照等候处、核其是否愿等工作灯返回；当齐岩经过暗角后再陪邻居上二楼，以照脚的角度送到门槛。次日若见陈姐，追问二零二底档，不因新层事件放弃旧账。
- **代价、变化及下一步**：晚睡、仍借光上下楼；她与周寻可以在交灯时说事，但不因合作就自动和解。下一步守二零二居住凭据，等公共线查修消息。
