# 蒋福安｜第9章私线

- **故事日与时刻、地点／起点**：第5天10:00带六零三室内受损支路施工单到原房；上一日已直付一晚旅舍，前两晚票据和一周退租未结。
- **个人目标**：尽快封板、恢复收租、停止逐晚付旅舍费，少承担整套床具更换。
- **已知与未知**：亲见床垫底面深色潮痕、横木湿暗并掉木屑，听师傅说木头湿着不能封、二楼公共线不在施工范围；不知道今早干到什么程度，须当场复看，也不知道田会不会同意回住。读者知道田宁可多折腾也不让可可睡潮床，他只能从她当面决定和孩子用品推断。
- **误解、阻力与底线**：把换线单往前推，想让“线路已处理”顶替床具问题；床垫与横木的实体状况、田的拒住、旅舍留房时间使他无法只讲施工。不再提搬九楼晾晒，不擅自封潮部位，不以已付昨晚房费抵掉旧账。
- **独立行动**：带原施工单，提出可以尽快让板工封板；被田掀起的床垫和周寻限定的施工范围打断后，现场看潮木、约拆换床具的具体联系人与时间，向旅舍核当晚房价及留房方式，按双方可查的方式承担实际续住费。收到前两晚票据后逐笔确认，不把一周退租口头抹平。
- **代价、变化及下一步**：得支付新床具、施工与外宿，六零三继续空着；关系从催租户回住转为受她逐项核对。下一步兑现拆换及付款凭证，再谈封板与回住。
