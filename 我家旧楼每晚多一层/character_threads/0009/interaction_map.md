# 第9章人物交织表

主视角预定周寻。时刻中除已定的第4天23:47和第5天10:00外，其余为本章拟用的顺序锚点，成稿可微调但不能跨过第5天23:47。私线行动是供成稿选择的计划，未写成正文前不回写为既成事实。

| 第4天23:47后，九楼口、楼门 | 探路值守人员先停在九楼口，报清新旧台阶接缝、十楼门和返回方向；唐曼据此决定只派必要人员接齐岩。齐岩回应姓名、身体状况后才离开窗边。 | 周在值守桌旁可听报告和齐岩的喊话，看不到房内床桌或探路者脚下细节；正文若要写这些，只能引用明确的口头回报，不能改成周亲见。 | 探路者首次踩到的新台阶与可退位置仅由他直接确认；齐岩知道房东催退，却此时尚不知旧锁将换。楼门值守挡尾随者，保证接人通路。 |
| 第4天深夜，十楼门至九楼平台 | 齐岩自己从窗边走到门，探路者以灯和口令限定步速；若他急着问能否回房睡，唐曼将“接人下楼”与“许可入住”分开说。 | 周若仍在楼下只能听分段回报；接到九楼交接时才亲见齐岩和实际步态。读者可从回报知道房、门、平台相接，但不获得整层合格结论。 | 齐岩可能误把亮房当退路；值守者并不知道他的旧租屋压力，不能替他回答。 |
| 第4天深夜，二楼暗角至楼门 | 周寻把工作灯的光留在踏步边，探路者交接后齐岩自己走出楼门。楼门值守阻止拍摄者占出口；刘桂芳和慢行邻居等接人这趟过去，才用灯返二楼。 | 周亲见齐岩下行最后一段、能否无伤站稳；可听他本人说旧租处仍有钥匙、接到腾屋催告。 | 慢行邻居亲自试灯角和腿力，改变刘桂芳想立刻送她回楼的安排。她们回家不等于公共照明修好；灯须再归值守处充电。 |
| 第4天夜至第5天早，楼门、联络渠道 | 唐曼告知陈姐新层接出活人；陈姐留齐岩可回拨方式，核他当夜是否仍能回原处。齐岩暂去核实旧屋，不接受十楼可住的暗示。 | 周只从通话或当事人告知知道陈姐接手；齐岩实际进过哪扇旧门，若周未随行不得由旁白断言。 | 陈姐在周视线外查可用临时房及前台条件，但不得先向齐岩许一个尚未确认的床位。旧屋换锁尚未在现场核实。 |
| 第5天10:00，六零三 | 蒋福安拿室内支路施工单试探封板与回住；田小雨掀床垫、指湿横木和未封潮木，要求先解决可可今晚睡处。周寻说明自己见到的施工范围，田据此拒绝当晚回住。 | 周在场可见潮处、听双方确定拆换联系人、时间与当晚续住支付办法；他不能替检测人员说整屋安全。 | 蒋原想结束逐晚付费，改为承担床具拆换和实际续房费；田把前两晚垫票与一周退租另列。付款是否到账须经旅舍或田确认，不能把蒋按手机算完成。 |
| 第5天10:00后、午前，齐岩旧租屋门前 | 齐岩请周寻陪同看旧锁，亲手试旧钥匙，门确实打不开；周只能见钥匙和门的现状，不能判定换锁是否合法。齐岩用照片和联系记录要求陈姐给实际落脚处。 | 周若同行，读者在主视角亲眼见证旧钥匙失效；这与十楼门牌的预警相接，却不解释楼如何得知。 | 齐岩手机里的催退消息与行李来处，以本人愿出示部分为准；陈姐从他发来的证据和本人陈述核需求，不假装在门前亲见。 |
| 第5天放学联络前后，田与可可的电话／消息 | 可可追问今晚书包与作业放哪，迫使田小雨在旧账争议之外先确认旅舍房与接送；她自己收好干作业和皱角册。 | 周若听见田的回复，只知道她对孩子说出的安排；看不到可可在学校或旅舍的独立动作。 | 可可不知道十点全部争论及十楼齐岩处境；她的下一步是按母亲确认的去处做作业。 |
| 第5天放学后、六号楼门 | 齐岩带行李回来，要求去昨夜走出的亮房；唐曼维持新层限行，陈姐现场确认临时房的房号、费用和领钥匙办法，把现实选择摆给他。 | 周可亲见行李、听见齐岩诉求和陈姐的可核答复；若齐岩仍迟疑，不由周代答。 | 齐岩是否实际领钥匙、旧租屋争议和十楼后续核验进入下一章；陈姐须追房间实际入住，唐曼须从防围观升级为处理真实无处可回者的出入风险。 |

## 汇总前硬检查

- **主角离场仍会行动**：田小雨会拒绝潮床、追蒋的付款；齐岩会试旧锁；陈姐会核可领钥匙的房；慢行邻居会自己决定何时借灯回家。
- **主角看不见的有效行动**：陈姐向前台核房与钥匙；可可整理作业并追问放学去处。两者只能经电话、消息或后果进入周寻视角。
- **相互改变**：探路者的实报改变唐曼接人路径；齐岩的失居改变陈姐的住宿工作和唐曼的值守对象；田掀开的潮床使蒋放弃只凭换线单封板；可可的问题使田先定今晚床位；慢行邻居的照脚要求改变灯具返还顺序。
- **不得提前泄露**：齐岩下楼时仍以为旧钥匙可用；田小雨不知道十楼人的旧租约；唐曼只知短时能走，未获得入住许可所需的工程结论；周寻不凭他人私线说出锁已换或旅舍已收款。
- **各自下一步**：周跟公共线和六零三拆换，唐守新层限制，齐岩选临时房并核旧租约，田核住宿和床具，蒋实际付款施工，陈姐追进门确认，值守者留记录，刘追二零二底档，邻居续借灯，可可照放学安排做作业。
