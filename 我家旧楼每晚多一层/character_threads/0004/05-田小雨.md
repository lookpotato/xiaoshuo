# 田小雨｜第 4 章私线

- **故事日与时刻、地点**：第 3 天清晨由旅馆带可可回六号楼取物，六零三门口与蒋福安交涉；随后送可可并去医院当班。具体班次以本章可写时间为准，不把她写成整夜在救援现场。
- **起点与个人目标**：六零三管子止漏但湿板、电线和床垫还在，母女昨晚已住旅馆。她今天首先要知道今晚能不能回六零三、旅馆要续几晚，才好安排孩子和上班；床垫与书包损失随答复再提。
- **已知**：民警提醒七楼暂不住，她已带可可离开；蒋福安承诺退一周租金并修板、换线，但还没有可入住的验收结果。她从邻居那里可以听说八楼有人被救，不能凭传闻知道郭冬梅的经历或二零二收条。
- **未知、误解与底线**：拆板后的实际损坏范围未明，换线人员何时完成也未定；她不以七楼灯亮作为带可可回去的保证，不把旅馆费无限期默默垫下去。她可能先以为蒋仍只会说“会修”，看到他写下费用和分工才肯按暂住安排上班。
- **独立行动与阻力**：带着可可的湿书包到六零三，先问今晚可否住；听见湿线不能送电，要求蒋福安写明拆板由谁付、谁联系换线和何时回话，并留下旅馆续住支出记录。她让可可自己把要带去学校的干书、替换物挑出来，决定今晚继续住旅馆，随后赶去上班，而非停在楼里围观八楼。
- **代价、变化与下一步**：继续支付或垫付旅馆、赶班与照料孩子两头受挤，床垫损失暂未定；换来可追问的书面分工。下一步等蒋的换线安排和拆板结果，核旅馆与床垫费用，决定何时能安全回六零三。
