# 第 4 章交织记录

1. **二零一，现场核实。** 刘桂芳守门并让街道工作人员进屋；工作人员看到生活痕迹，记“在住待核”，承诺明早按二零一送通知。周寻在场但没有替她发言。旧清册来源仍未知，刘桂芳只能暂时守住本轮送达。
2. **二楼至八楼，限流。** 唐曼只放必要的人上楼，老胡表面退让，暗中仍准备把椅子带上去；周寻看见椅子并出声制止，却没阻止老胡后来擅自搬动。这一行动不按周寻的安排走。
3. **八楼旧门。** 唐曼喊话、开门、试门口地面；周寻观察锁和屋内可见处；刘桂芳看见确实有空屋。无人应答与无人露面只排除眼前有人，不能解释钥匙或证明可住。
4. **椅子撞上刘桂芳的选择。** 老胡想先为外孙占地，唐曼要求清出楼梯，老胡转而向刘桂芳要让房的说法。刘桂芳公开拒认八楼，又亲手帮他搬椅；过路住户贴墙等待，使老胡亲眼见到椅子占道。两位老邻居的关系因此变冷。
5. **二楼门口，未完的今晚。** 工作人员继续处理送达；外孙带行李到场，才知道八楼不能住。老胡的失约被摆到外孙面前；刘桂芳重新开门，下一步是要不要帮忙找真实住处。外孙来楼的路程未被周寻看到，主视角只看到他进楼后的反应。
