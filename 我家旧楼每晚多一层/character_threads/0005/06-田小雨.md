# 田小雨｜第 5 章私线

- **故事日与时刻、地点**：第 3 天午后或下班前通过电话追六零三维修；傍晚在六零三门口或旅舍与蒋福安联系，夜里带可可住旅馆，不在六号楼九楼围观。
- **起点与个人目标**：母女昨晚住旅馆，六零三湿板未见拆完、湿线停用。她要先确认今晚去哪儿、何时有人换线，再谈床垫；需要能向医院排班和可可解释的具体安排。
- **已知与未知**：蒋福安早晨写下拆板清运由他付、今天联系换线人员，一周租金退还只是先前承诺，旅馆费与床垫未结；七楼暂不准住。她只听说郭被救送医，不知道二零二收条交还，也不知道九楼会出现。读者见过她要求书面承诺，却尚未见拆板完成。
- **误解、阻力与底线**：她怕“板拆完”又被说成“屋能住”；换线人员的到场时间、复电条件仍不定。她不让可可睡潮房，不把七零一当蒋的替代住房，也不为赶班接受含糊延期。
- **独立行动**：午后催蒋按早晨纸条回话，要求看拆下的湿板已清出及停用分闸仍挂标记；先问今晚旅馆能否续和换线人员何时上门。蒋若只有联系中，她选择再续一夜旅馆，把票据拍给蒋，并约次日明确反馈；床垫待现场干燥后另核。给可可带干衣、课本，安排正常上学与自己当班。
- **代价、变化与下一步**：继续垫付旅馆、通勤和照顾孩子的成本；六零三局部修缮有进展但她仍无回家日期。下一步等专业换线与可用电确认，追一周退租、旅馆费和床垫损失，不因九楼多出空间改变决定。
