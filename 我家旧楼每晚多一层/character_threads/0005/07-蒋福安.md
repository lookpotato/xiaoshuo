# 蒋福安｜第 5 章私线

- **故事日与时刻、地点**：第 3 天午前至傍晚，六零三、楼梯及电话联系换线人员处。
- **起点与个人目标**：早晨已带拆板师傅来，书面承诺拆板清运由自己付、当天联系换线人员。要把湿板运出并尽快封板，但田小雨要的是可回家的时间和费用准话。
- **已知与未知**：知道管漏已止、湿线仍不能送电，板工不负责换线，母女今晚续旅馆。拆开前不知道板后损害范围；不知道二楼灯座夜里会冒烟，也不知道九楼将出现。他没有因七楼存在而减少修六零三的义务。
- **误解、阻力与底线**：他原以为拆完板可先封上，让房间看起来能用；周寻和田指出线仍潮、未换且不能封死待查部位，迫使他改变顺序。他不能私自送电或保证未定的复住日期。
- **独立行动**：支付板工当日费用，督促湿板分批从单楼梯搬下，避免和二楼灯具梯同时占转角；拆后拍下暴露的湿线与损坏处，约换线人员上门查看并向田小雨回报确切约时或如实说明未约成。先把不能住和旅馆续住写清，床垫待看，不把退租承诺写成已付款。
- **代价、变化与下一步**：承担拆运费用与延误带来的旅馆协商压力，不能立刻封板省事。下一步等换线人员处理并确认线路可恢复，才谈封板和入住；与田核租金、旅馆票及床垫。
