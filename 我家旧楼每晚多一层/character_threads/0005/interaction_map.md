# 第 5 章人物交织表

主视角：周寻。故事第 3 天，承接二零二九点以后的追问，跨过当夜 23:47。表中时刻为编排锚点；郭的头伤处置以她持有的医院告知为准，不在私线里补诊断。23:47 前最高八楼，之后九楼真实存在，楼外可见。

| 09:40 左右，二零二桌前 | 郭冬梅要求刘桂芳解释为何保管郭玉兰收条，并拿打不开的旧地址追问这纸究竟替谁留着。刘说出郭玉兰怕交走唯一凭据而托她暂存，也承认后来怕牵出二零二问题、未主动交还。郭的追问改变刘继续避谈的计划。陈姐只核对已见的署名和号码，不代任何人回答旧事。 | 周寻若仍在门外，能听到当事人实际说出口的部分；若他为让路离开，只能在返回后从郭、刘或陈姐得到说明，不能用旁白先写刘心里的惧怕。 | 底档如何把同号写到二零二原表、旧址为何打不开仍未知。刘受托经过在她说出前只属于刘的记忆，读者也尚未知。郭未因此原谅刘。 |
| 约 10:00，二零二 | 陈姐征询郭同意后拍黄纸正反面、号码和交接，刘亲手把原件递给郭，答应日后本人作证。郭将原件收进自己的文件袋。郭拒绝继续让别人保管，迫使刘改用照片、居住事实和证言应对二零二核查；刘的交还使郭能自主决定带纸离开。 | 若周寻在门边，可见原件从刘到郭，听见双方承诺与未和解的语气；他不能从交纸推定旧表已改或八楼归属。 | 原表仍写“已退出”，执行页只是暂停按此处置。陈姐后续追底档，照片不能自动替代原件。刘与郭的关系变化会在下一章继续。 |
| 10:00—12:00，街道值班点、旅舍前台及二零二电话 | 街道值班同事独自核实柳北里东巷 18 号便民旅舍一层 103 室、前台钥匙、本人证件与街道登记短信、当晚费用由街道临时住宿经费结算；将地址、房号、入住办法和时限发给陈姐。陈姐把确实能进门的信息交给郭，郭自行决定入住；她要求拿到短信，而不接一句“正在安排”。 | 周寻可听陈姐回报或看郭得到的短信，但无法直接看见值班同事逐个电话核实。看到郭持材料下楼，不能由此说她已经入住。 | 值班同事的电话行动是主角未见的有效行动；前台实际入住回执须后来确认。续住尚待另核，临时房不是安置房。 |
| 午后，六零三至楼门单梯 | 蒋福安付拆板清运费、让湿板分批下楼，想尽快封板；周寻指出暴露的湿线仍须停用、待换线人员处理，也与蒋错开二楼维修梯。田小雨来电或到场先问今晚住哪、换线何时来，改变蒋“先封板”的顺序；蒋给出如实约时或未约成的回话。田决定母女续住旅馆，把票据留存。 | 周寻可见湿板搬出、停用标记、田与蒋在现场所说的话；若田只电话催蒋，须由蒋转述或让周寻听到通话，不能播报田在医院的心思。 | 板拆除不等于可送电、可复住；床垫、退租、旅馆费仍待结。田的续住使可可不必夜里回危险房间。 |
| 放学后至傍晚，六零三门口／旅馆 | 可可挑干书与衣物，听母亲明确今晚仍住旅馆；她把仍潮的一册留着通风。蒋得到旅馆票据，不能再把拆板当作租户已能回家的证明。郭到临时旅舍办理入住，陈姐或值班同事等待前台回执。 | 周寻若在六零三可见可可的小动作；郭入住若已离镜，只能通过她报平安或前台回执被告知。 | 郭不在 23:47 楼内，田母女也不在楼内；她们不能直接目击九楼平台或二楼灯冒烟。各自的住宿只解决当晚，后续费用与旧址仍发酵。 |
| 傍晚至 23:40，二楼灯座、二零二及楼梯 | 二楼公共灯换泡后仍闪，周寻复查，停止把故障当灯泡问题，标出灯座待修并向刘取公共总闸钥匙。刘交钥匙、说明闸位，另把收条交接及自己证言写在记事纸上。唐曼看通道，要求维修梯和清运已撤离单梯；老胡把外孙物品留在自家，不占转角。 | 周寻能亲见灯闪、自己的试查、刘交钥匙、梯子撤走及转角空出；不能未经告知说刘独自在屋里怎样整理证据。 | 刘失去原件后的记录习惯属于离镜动作，可在后续以纸张或口述出现。二楼灯座内部原因未明，九楼线路与之是否相关更未明。 |
| 23:47，楼外与六至九楼交界 | 新台阶与九楼公用晾晒平台真实出现。楼外老胡和其他住户亲眼看见增加的楼体，老胡报出变化并拦住要进楼门的人。楼内唐曼挡住往九楼上行者，记录平台与人数；周寻看见新层与仍亮的灯。老胡的楼外阻挡减少门口拥挤，唐曼的限流改变围观者上楼计划。 | 周寻可亲见楼内新台阶，或听见老胡从楼外喊出外观变化；外部共同目击可由楼门声音与事后视频进入他的视角。 | 九楼是公共晾晒平台，不因此开放使用；新层灯的供电来源待查。郭与田母女此刻均无直接目击。 |
| 23:47 后紧接，二楼灯座至楼门 | 刚换泡仍不稳的二楼公共灯座冒烟，通行者往下退。周寻立即提醒避开烟与灯座、切断旧楼公共照明，用手电和口令组织沿单梯下撤。唐曼放弃围观核查，守九楼上行口并协助清点下行；刘带钥匙和手电离开二零二，招呼行动慢的二楼邻居；老胡让开楼门并确认外孙。烟改变所有人的优先次序。 | 周寻能见烟、闸被切、梯间变暗、唐曼和刘可见的动作；若有人在他视线外扶邻居，须由声音、到达楼门的人或之后转述体现。 | 九楼灯若仍亮，只能记录为观察，不能认作二楼冒烟的原因或证明新电路安全。消防、照明复查、是否有人滞留和可否复电由下一章紧接，刘不能留在二零二等天亮。 |

## 汇总边界与继续发酵

- **互相改动**：郭坚持取回原件，刘改为亲自作证；刘交纸使郭能带母亲凭据去独立住处。田追问复住时间使蒋停止急于封板，蒋如实说明未换线使田续住旅馆。二楼烟又迫使唐曼从限制参观转为疏散配合、刘从守屋转为帮助邻居。
- **主角未见的有效行动**：值班同事核旅舍钥匙及费用、郭到店实际办入住、刘在交纸后单独整理自己的证言。进入正文时分别经确认短信、入住回执、刘后来拿出的纸进入周寻视野；没有传递就保持未知。
- **下一章债务**：二楼烟源与灯座处置、断灯后的单梯照明和住户清点、九楼限流及供电核查必须立即接续；二零二原表底档、郭旧址打不开、郭临时住宿续住与田家修线费用继续追查。不能让暂停处置变成原表更正，也不能让九楼出现回头改写郭的独立选择。
