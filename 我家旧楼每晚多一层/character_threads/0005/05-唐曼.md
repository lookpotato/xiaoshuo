# 唐曼｜第 5 章私线

- **故事日与时刻、地点**：第 3 天九点后离开二零二核表现场，白天核七八楼通行；23:47 前后在六至九楼交界及楼梯。
- **起点与个人目标**：已记二零二实际住人与执行页暂停，也限制八楼进入。她要保持单梯可供必要人员通行，记录新层现场，而不把未勘查的九楼开放给围观住户。
- **已知与未知**：知道郭从八楼获救、刘住二零二、原表未改、同号收条署名郭玉兰；刘受托原因在她听见刘说前未知。她不知道九楼会是什么、其电源与旧楼公共照明是否相连，也不知道二楼灯座内部状态，除非周寻报告。周寻白天的维修发现不能自动进她的记录。
- **误解、阻力与底线**：有人会以九楼平台“只是晾晒”要求上去看；她过去贴的八楼限制未必让人自觉停步。她不能凭目测签新楼层安全，也不能越过现场消防处置判断烟源。
- **独立行动**：核看黄纸交接不代郭作决定，继续保管自己的测量与通行记录。白天记下湿板清运及二楼维修梯可能造成的单梯缩窄，要求错峰。23:47亲见新台阶与九楼公用晾晒平台，拦住要上行的人，记录外部目击与新层仍亮的可见事实；听到下方冒烟，改让楼梯通道优先服务下撤，向周寻确认旧楼公共照明已切，不据此推断新层供电来源。
- **代价、变化与下一步**：限流会被住户抱怨挡着新空间；她须为现场记录和下一步限制负责。下一步与到场人员交接九楼出入口、人数和通道宽度，复核是否有人仍在上层，参与夜间照明和撤离处置。
