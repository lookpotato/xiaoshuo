# 第 5 章末人物状态回写

时间基准：故事第 3 天，23:47 后九楼已出现，二楼公共灯座冒烟，旧楼公共照明已断。下列“结尾地点”以人物在正文中最后可见、可闻或经消息确认的位置为准；离镜后的私线安排标为**读者未见**，不当作已发生事实。

## 周寻

- **结尾时间地点**：第 3 天 23:47 后，在六号楼楼门口，持手电数陆续出来的人；唐曼仍在楼梯上。
- **身体与资源**：未写受伤；工具包内扣着刘桂芳交的公共总闸钥匙，手机有闸位、灯座和九楼照片，面试改期消息仍未回复。二楼灯座贴有“待修，勿按开关”，维修梯已收进维修间；旧楼公共照明由他拉闸断开。
- **知识**：听见刘说明郭玉兰托存收条及自己多年沉默的缘故，见郭持原件离开；见六零三湿板拆出、线皮起泡且分闸仍停用。换灯泡后灯仍闪，灯座有黑痕、接头松动；23:47 亲见新台阶、九楼平台及亮灯，随后听见二楼冒烟并闻到焦味。不知二楼故障根因、九楼灯供电来源、楼内是否已清空。
- **关系与承诺**：替郭清开下楼路，为板工让出单梯；向蒋福安说明湿线不能合闸、不能先封板；向唐曼发灯座照片，向楼外拨消防电话的人报楼号、烟点和断电情况。刘借给他的钥匙须归还。未替街道或房东承诺房屋安全。
- **秘密与下一步**：没有正文可证的个人秘密；面试改期未回复是尚未处理的私人压力。继续与唐曼清点下撤人数，向到场人员交接烟点、闸位和九楼仍亮的观察，未经检查不复电。

## 郭冬梅

- **结尾时间地点**：第 3 天晚上，经发给陈姐的短信确认已经进入柳北里东巷十八号便民旅舍一层一零三室；23:47 时是否仍在房内，正文未再核实。
- **身体与资源**：额角有敷料，持医院单子、打不开旧址的钥匙和地址纸；郭玉兰收条原件由刘桂芳亲手交给她，平放在文件袋塑料夹页里。她收到街道登记短信，凭本人证件和短信到前台领钥匙；当晚房费由街道临时住宿经费结算，续住另核。具体诊断**读者未见**。
- **知识**：听刘说郭玉兰搬走前怕交出唯一凭据，托刘把收条暂放铁盒；刘因担心二零二登记受牵连，拖多年未查、未交还。知道陈姐会追底档，仍不知原表错录过程、旧址打不开的原因和八楼成因；没有正文证据表明她得知夜间九楼与灯座险情。
- **关系与承诺**：准刘留照片，自己拿原件；明确不接受“替我收着”的说法，未表示原谅。她逐行核住宿信息、要求短信转到自己手机，亲自前往并报已进屋。医院要求她回去复看，复看的时间和完成情况**读者未见**。
- **秘密与下一步**：绿门内受伤经过、医院评估及旧址锁的问题仍未揭开；先保管原件、按医院要求复看，再与陈姐核旧址和底档，续住须另行落实。

## 刘桂芳

- **结尾时间地点**：第 3 天 23:47 后，最后可见于二楼通往楼下的楼梯，拉着走得慢的邻居下撤；是否已到楼外，正文未写。
- **身体与资源**：未写受伤；随身拿手电和自家钥匙，二零二铁盒仍放在桌上；把公共总闸钥匙交给周寻并嘱咐归还。收条原件已交郭，陈姐拍了正反面；刘本人是否已收到照片，正文未写。她把交接时间抄入零钱本，压在铁盒下面。
- **知识**：当众说明郭玉兰当年托她暂存收条，自己因二零二登记疑虑沉默多年；知道执行页仅暂停按“已退出”处置，原表未更正。见二楼新灯泡又闪，告诉周寻旧灯雨天曾犯毛病；看过郭报进屋的短信截图。知道二楼有人喊冒烟、楼里正在撤人；正文未写她亲见九楼，也不知烟源。
- **关系与承诺**：答应陈姐追底档时本人到场说清楚；郭拿回原件但未原谅她。刘把手电放门边备夜用，险情中离开二零二，敲门催慢行邻居穿鞋、替其关灶并拉着下楼。公共总闸钥匙借给周寻，仍待归还。
- **秘密与下一步**：受托与沉默缘由已向郭、陈姐说出，旧表同号来历仍未知。先确认邻居及自己撤到安全处，再凭居住记录、交接记录、照片和本人证言追二零二底档；她取得照片的具体过程**读者未见**。

## 陈姐

- **结尾时间地点**：第 3 天晚上，最后以短信向周寻转告郭已进门，并附郭的报平安截图；发送时身在何处，正文未写。
- **身体与资源**：未写受伤；有二零二原表、记录本、黄纸正反面与凭据号照片、交接时间记录、住宿确认和郭报进屋的短信。原件归郭，不在陈姐手中。

- **秘密与下一步**：无正文可证的个人秘密；继续追查凭据号为何出现在二零二原表、旧址为何打不开，并向刘、郭分别回报。实际查档动作和结果**读者未见**。

## 唐曼

- **结尾时间地点**：第 3 天 23:47 后，在六号楼楼梯上持手电带人下撤，向楼门口的周寻报八楼口尚有两人正下来、九楼没人上去；是否已下到楼外，正文未写。
- **身体与资源**：未写受伤；有巡查本、测量带、手电及七八楼限行纸。白天在二楼转角阻止下一捆湿板提前靠墙，夜里记楼梯人数并持续清点。
- **知识**：收过周寻的灯座照片及待修消息；亲见 23:47 新台阶与九楼平台，听见二楼灯处有人喊冒烟，见旧楼照明断后楼梯变暗而九楼灯仍亮。不知九楼灯与旧楼线路的关系，也没有九楼安全结论。

## 田小雨

- **结尾时间地点**：第 3 天傍晚，最后可见于六零三与可可拿东西、临走同蒋福安谈旅馆票；此后是否已回到旅馆，正文未写。

- **知识**：从蒋福安免提得知拆板钱已付、换线人员说明天能来但具体时间要次日八点才回话；知道今晚不能住六零三，可可的一本练习册仍潮。未见夜间九楼或二楼烟。

## 蒋福安

- **结尾时间地点**：第 3 天傍晚，最后可见于六零三门口，同田小雨谈旅馆票；夜间去处未写。

- **秘密与下一步**：无正文可证的个人秘密；等换线师傅回确切时刻，安排处理并在安全确认后再补板；继续与田核租金、票据和床垫。
