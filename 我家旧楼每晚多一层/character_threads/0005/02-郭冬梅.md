# 郭冬梅｜第 5 章私线

- **故事日与时刻、地点**：第 3 天九点以后在二零二；午后从六号楼到街道协调的临时旅舍。23:47 不在六号楼内。
- **起点与个人目标**：额角贴敷料，手里有医院单子、旧地址纸和打不开旧门的钥匙；正当面问刘桂芳黄纸为何一直在她手中。她要听到可核对的经过，亲自保管母亲郭玉兰的原件，并有今晚能真正进门的房间。
- **已知与未知**：认出母亲署名和旧住址，知道收条凭据号与二零二原表末四位相同、旧地址钥匙打不开门；陈姐已为她联络临时住宿。她此前不知道刘受母亲所托，也不知道刘后来因二零二风险沉默；读者同样未获此答复。她不知底档如何错录、旧锁为何打不开、八楼为何会把她困在绿门后。医院单子可由她持有，但在未读出内容前，旁人不能替她确认伤情。
- **误解、阻力与底线**：她会怀疑刘把母亲的纸拿来护自己的房，这个怀疑由多年未交还和眼前原表矛盾支撑，不能被一句“当年为你好”抹平。头伤、路程和当晚住宿使她无力无限等待。她不借住八楼或二零二，不让陈姐或刘替她决定原件归属。
- **独立行动**：追问刘受托的具体情形和为何多年不找她，拿旧地址纸反问“这张纸究竟替谁留着”。在陈姐拍下原件正反面、号码与交接时刻后接过收条，放进自己文件袋；不承诺原谅，也同意刘日后以照片及本人证言说明二零二异议。对临时旅舍的地址、房号、前台留钥匙、证件要求和今晚谁付费逐项问清，收到确认后自己选择前往；抵达后保留入住回执或向陈姐报“进门了”。
- **代价、变化与下一步**：拿回原件也接过防潮、保管及后续出示的责任；住旅舍仅解今晚之急，母亲旧址和八楼仍无解释。她与刘的关系由旧邻称呼转成要对方公开作证，下一步先休息、按医院告知处理头伤，再与陈姐核旧址和底档，不因刘交纸就恢复信任。
