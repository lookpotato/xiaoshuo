# 板工｜第11章私线

- **故事日与时刻、地点／起点**：第6天上午接蒋福安消息后，在六零三床架边短时复看；第5天下午已拆受潮横木、量净空，把尺寸交蒋和田拍下。是否有合尺寸木料送到须本场核实。
- **个人目标与底线**：按实量尺寸确认木料与可安装范围，把剩余潮处留给复查；不把一根新横木说成完整可睡床位，也不代换线师傅、房屋安全人员判整屋可住。
- **已知与未知**：知道旧横木内里腐坏、墙边湿印扩出半掌、旧垫已清走；不知道蒋是否买齐木料和新垫，也不知道十一楼门内情形。读者知道田要争当夜住处，板工只从现场问答得知这件工序对她很急。
- **误解与阻力**：蒋希望材料一到即可宣布结束，田希望知道何时有床可睡；尺寸、湿痕与新垫缺口使板工不能给两人想要的即刻答案。
- **独立行动**：先核送到的木料是否合尺寸；合适才在可施工部位安装，不合适就明确退换，绝不把“在路上”写成装好。指出墙边仍敞开待复查之处，让蒋和田各拍清；说明床垫不在他的工序内，床架即便补了横木也不能让孩子直接睡。必要时另约复查或待料时段。
- **代价、本场变化与下一步**：不能一次收完封板的活，须配合复查再跑一趟；他的实物判断打断蒋用施工进度逼退旅舍的说法。下一步等合材与潮处核验结果，才继续后续安装和封板。
