# 周寻｜第11章私线

- **故事日与时刻、地点／起点**：第6天上午在一楼维修间、二楼暗角及楼门，短时随田小雨和唐曼到十一楼；下午仍需把工作灯还给旧楼通行。第10章末唐曼叫他照住二楼暗角，是否已接到新查线进展尚无正文展示。
- **个人目标与底线**：让受控上行有可靠照脚光，也让楼里慢行住户仍可经过二楼；把实际摸到、看见的情况说准。他不合公共照明旧闸、不擅接十一楼电、不替房屋安全人员下承重或入住结论，也不代田替可可作决定。
- **已知与未知**：知道六零三室内受损支路已换、湿横木和旧垫昨日拆走，二楼公共旧线仍待检查复测；昨夜他是否亲看十一楼门牌正文未写，至少不能先知道屋内。读者与田知道名字，周若得知须由唐曼出示原图或现场看见；他不知蒋今天料是否真到、可可是否获告。
- **误解与阻力**：住户易把维修工的“锁能扣上、台阶能走”听成“整层安全”；工作灯用于上楼后，二楼暗角暂少一束光，他得顾及等待通行的人。自己也会被儿童床与干净书桌打动，但不能把感受变成技术结论。
- **独立行动**：先在一楼检查工作灯剩余电量与备用手电，同楼门值守约好普通住户先过或暂等的短窗口；上楼时把光落在旧梯踏步边和新旧交界，记录经过的真实台阶数与暗角。到门前仅试自己被允许试的锁舌、看门框与可见照明，不碰未知线路或宣称整层承载可靠；将“可见”“未查”分别告诉唐曼和田。下楼后把灯送回二楼通行位置，继续追公共线查修准信并按曾向刘桂芳承诺的方式告知她。
- **代价、本场变化与下一步**：短时查验占去接活与照灯资源，他须承受“看过还不能住”的追问。下一步核二楼旧线更换、复测的实际时刻，向刘回告；若六零三床架有需要，只在板工职责范围外做自己能做的协助。
