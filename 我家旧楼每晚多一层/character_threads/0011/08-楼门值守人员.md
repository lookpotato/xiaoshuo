# 楼门值守人员｜第11章私线

- **故事日与时刻、地点／起点**：第6天上午到放学后在六号楼楼门和值守桌；第5夜他拦住增层后想冲进去的人，十一楼只曾由探路者抵门口。
- **个人目标与底线**：保证单梯可供原住户进出，并在唐曼指定的短窗口让获准成人查十一楼；不把大人上去看房等同新层开放，也不让放学后的可可尾随。
- **已知与未知**：知道二楼旧公共灯断、十一楼门牌照片及限行可由唐曼交接获知；不知道十一楼屋内、六零三床位或旅舍付款，不能向围观者报“孩子的新房”。读者若随田上楼看见床，值守者留楼门，仍只能从下楼者正式回报知道结果。
- **误解与阻力**：同一入口有住户回家、短查上行和好奇围观；临时拦人会遭催促，但完全锁门又会妨碍旧楼日常通行。
- **独立行动**：先让已有住户过二楼暗角，核唐曼准入人数与灯具，记田、唐、周的进出时刻；在他们上行时解释普通住户仍按原路线进出、十一楼限行，拦住尾随者。人回来后确认全员下行并恢复工作灯给二楼通行；放学后可可在门外指楼时，不因她是门牌姓名就开门，若田申请仅到门口，交回唐曼决定。
- **代价、本场变化与下一步**：须承担等待与抱怨、更新出入记录；名字上门牌的孩子亲自到场使限行解释更难。下一步保持十一楼限制并向下一班值守交接，等待唐曼对儿童门口短看另作决定。
