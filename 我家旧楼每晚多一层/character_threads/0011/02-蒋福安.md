# 蒋福安｜第11章私线

- **故事日与时刻、地点／起点**：第6天早晨在联系木料与床具的电话两端，送学后至下午在六零三与田小雨对质，付款时可在她面前联系旅舍。第5夜他只说木料明早给信、床垫再问；尚无已到料或新垫的正文证据。
- **个人目标与底线**：尽快把六零三恢复成能收租的屋，减少连续旅舍支出；至少拿出可核的换木进度和下一步施工安排。他可以谈成本与时间，不能把十一楼门牌据为六零三替代房源，也不能封住未复查的潮处。
- **已知与未知**：亲见旧湿木拆出、墙边湿印和旧垫被运走，持板工实量尺寸与第5夜付款记录，知道田不肯预先退旅舍。他在第10章末没有被展示获知“田可可”门牌；本章须从唐曼、田或可见记录获知，不能开口就精确报出十一楼屋内有床。读者先前已见门牌，却也不知道屋内；蒋更不知道安全核验结论。
- **误解与阻力**：他容易把横木送达、装上等同于床能睡，或把十一楼现成布置当成解决旅舍账的捷径。田的现场照片、板工的施工边界、缺失的新床垫以及唐曼的限行，会逐项拆掉这套说法。前两晚票据与一周退租仍压着，他怕这一晚又形成单独账。
- **独立行动**：在田到场前主动催按尺寸配木与新垫，把供货答复、能到场的板工时段分别记清；只将实际送到的东西称为“到了”。在六零三让板工核横木可否安装及潮处是否仍敞着，向田提出等装木便退房；听到十一楼有房间后试探能否先用一夜，被唐曼的限行和田的拒住改变计划。田指出无可睡床位后，改为当面核旅舍原房是否可续、第6夜金额与付款渠道，支付并让前台直接确认，保留回执；旧票和退租另核。
- **代价、本场变化与下一步**：再付一夜房费与修床支出，短期收不到六零三恢复居住的结果；无法以孩子名下新房替自己履约。下一步催新床垫、配合潮处复查及封板时机，逐笔核旧票与一周退租，不能从这次付款推定旧账已清。
