# 本书写法

- 都市生活先有温度和具体秩序：晚班人进门、楼道里谁在充电、漏水时先关哪只阀。奇观破坏这些秩序，人物才有真实反应。
- 旁白贴着周寻；能用两三句直接介绍住户关系和场所用途。进入新楼层时让人看清空间，不把关键坐标藏成谜语。
- 句子自然，熟人说话会省略、抢话和顾面子。刘桂芳先管安全与邻里，田小雨先护女儿和工作，周寻先看能否修、由谁决定。
- 奇观可以让人惊喜，也让人立刻想到电费、门锁、楼梯和房租。不要全员只会恐慌，更不要全员立刻接受。
- 悬念留在楼的来历和选择住户的原因；眼下能否站稳、能否住、做了什么试验必须说清。
- `echo-v1` 档案中针对旧书的林默、唐栀、七号、声音和产品化经验仅属于旧作品。本书保留它的人物关系、旧物触发事件与自然中文叙事能力，不移植人物、设备或剧情。
