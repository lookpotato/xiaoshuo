# 本书写法

- 都市生活先有温度和具体秩序：晚班人进门、楼道里谁在充电、漏水时先关哪只阀。奇观破坏这些秩序，人物才有真实反应。
- 旁白贴着周寻；能用两三句直接介绍住户关系和场所用途。进入新楼层时让人看清空间，不把关键坐标藏成谜语。
- 句子自然，熟人说话会省略、抢话和顾面子。刘桂芳先管安全与邻里，田小雨先护女儿和工作，周寻先看能否修、由谁决定。
- 奇观可以让人惊喜，也让人立刻想到电费、门锁、楼梯和房租。不要全员只会恐慌，更不要全员立刻接受。
- 第 3 章起，新增楼层先破坏一种人物已经确信的日常经验，让读者与人物一同感到未知逼近；再写人物怎样利用、逃避或掩盖它。费用、清册、维修和安全程序只能放大压力，不能连续几章代替楼层本身成为主事件。
- 恐惧来自可见、可触摸却解释不通的具体细节和后果，不靠无来源的怪声、突然跳出的怪物或旁白宣布“诡异”。每层至少留下一个暂时无法解释、又会影响下一步行动的事实；部分查清后仍要改变人物对楼的判断。
- 23:47 的增层是读者期待的时刻，不把它写成报数。跨过这一刻须兑现新层及其影响；一夜可以跨数章，不要求每章结尾机械增层。
- 507 旧案的早期线索只能作为人物在新楼层亲手碰到、能够留证的旧痕迹出现。第 3—9 章不让任何人直接解释“507局”或用旧卷宗替代现场恐惧。
- 悬念留在楼的来历和选择住户的原因；眼下能否站稳、能否住、做了什么试验必须说清。
- 新楼层出现不能只换来一轮参观、拍照和次日核验；本章要有当晚非处理不可的具体问题，人物作出选择并付出看得见的代价。每次险情要由既有设施、人物诉求或已出现的异象引发，不凭空安排事故。
- `echo-v1` 档案中针对旧书的林默、唐栀、七号、声音和产品化经验仅属于旧作品。本书保留它的人物关系、旧物触发事件与自然中文叙事能力，不移植人物、设备或剧情。
