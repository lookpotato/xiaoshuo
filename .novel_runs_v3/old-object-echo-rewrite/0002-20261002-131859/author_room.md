# 作者房间

九点多，唐栀本来只想把书还回去。她今晚还有一件没做完的事：趁阅览室搬迁前，把剩下的借阅册、台灯位置和几张没人愿意认领的旧照片核一遍，免得东西一装箱，往后连“这本书从哪张桌子回来的”都说不清。她把《夜航故事》带去林默那里，是因为书角开了，又因为修复台已经封箱，并不是要把孟阿婆丈夫留下的痕迹交给一个机器研究。书在她手里时，她还在替孟阿婆守着一条很窄的路：书可以修，来处可以留档，声音却不能因为好奇就重新回到人群里。

林默则准备关店。他得把录音和七号的离线日志分开存好，给七号换电池，明天还要接一个旧音箱的活。异常让这些小事全往后挪了。他带着两年前演示事故留下的旧经验进来：当时所有人都催他重放、放大、找源头，没人问那句话是不是愿意被留下。他现在嘴上说“不拆、不翻、不外放”，手却还是会去看时间、波形和那四十六秒空白；查设备是他能抓住的东西，人的犹豫和一位亡者的声音不是。七号也没有能力替他做决定，它只剩一点电，能不能再走几步都说不准，低电停机会让林默更焦躁，因为他连异常是否可重复都保不住。

孟阿婆在阅览室等书，不是等一场解释。她要先摸到书角，确认封面没有被拆、页边没有被翻乱，再把书放回自己手里。搬迁已经把她熟悉的桌椅挪得不像原来的样子，她能留住的东西不多，所以她会先盯着书和唐栀的手，不会先接林默的技术说法。她还得锁门、清点最后一批文件夹，回去给自己留饭；她不是为了给年轻人提供线索才守到这么晚。她真正害怕的也不是机器会不会出错，而是有人拿一句像她老伴的声音逼她承认、比较，最后把她不肯公开的那部分日子变成别人茶余饭后的“证据”。

如果林默没有跟来，唐栀会把书还掉，顺手把台灯和归还桌的位置记进搬迁清单，再问孟阿婆要不要把那条手写线单独拍进留档。孟阿婆会拿书、看书脊，催她别再站着，之后照旧检查门锁。林默若留在修理间，他会把录音复制两份，盯着那块日志空白，可能因为不甘心又给七号接一次电。这三个人各自都有下一步，谁都不是为了配合主角才来到现场；真正把他们拉到一起的，是唐栀听见了不该出现的话，却不能替孟阿婆决定这句话该不该继续存在。

现场里，唐栀想把归还办成一件干净的事，孟阿婆想把书和丈夫的声音从查案里分开，林默想把事情推进到一个可以复核的现实线索。林默想留下来，孟阿婆会先拖住他，要求他离书远一点；唐栀既想让他别越线，又知道如果把人直接赶走，四十六秒的空白只会变成他一个人在店里反复猜。她保护的是孟阿婆的选择、书页上的来处，以及阅览室搬迁后仍能被核对的事实。林默保护的是记录不被自己改写，却很容易把“保护记录”做成“继续碰别人的东西”。

大家心里明白而不会当面说破的是：唐栀已经后悔把书送进修理间，却不能承认自己也想知道那句话从哪来；孟阿婆知道唐栀没有恶意，可她仍会在唐栀伸手时多看一眼，因为熟人也可能在好心里替她做决定；林默知道自己不是单纯在修机器，他其实在躲两年前那个没问过“能不能留下声音”的自己。孟阿婆不会说“我不想再失去一次”，她只会先问书有没有被翻。唐栀不会说“我不完全信你”，她会把书抱紧、把林默的手从页边移开。林默也不会说害怕重演事故，他会低头核时间，等别人先给他一个可以动手的范围。

事情会从交还开始变形。孟阿婆先检查书，唐栀解释修复，林默站在边上，七号停机后像一块没有用处的冷铁。林默若直接问声音像不像老人，场面就会立刻关上；唐栀会把书拿回去，孟阿婆会让他们走。于是他只能从不碰书的地方下手：问闭馆前后谁动过归还桌，看看台灯底座有没有被挪过，核对搬迁中还没装箱的晚间登记。孟阿婆不会一次把旧事全倒出来，她可能先纠正他把时间记错，或坚持先把文件夹按编号归位；这些看似拖延的动作，实际是在确认他能不能只做被允许的那一步。唐栀会在旁边收拾桌面、压平书角，必要时直接把林默递出去的手挡回去，也会替他指出一处不该被忽略的灯痕，因为她不愿让“守边界”变成什么都不查。

最后真正被办成的，不是声源确认，而是一次有条件的查证。孟阿婆收回书，明确不许翻页、不许外放丈夫的声音，却允许林默查阅览室的晚间使用记录和现场留档。这个许可不是她突然信任了机器，而是她用自己能承受的范围把事情拽回手里。林默拿到的线索应当很具体：闭馆后有人把《夜航故事》放到台灯下，灯不是自己开的，登记纸写到一半被擦掉，文件夹编号和九月十六日的位置还能对上；孟阿婆锁门后回来时，门没开，灯却亮着，墙钟停在九点二十分。它足够把异常从修理间推回阅览室，却不够指认任何一个人。

章末之后，孟阿婆不再只是等书的人。她知道这件事会继续，但继续的范围由她说了算；她会把书放在自己身边，也会重新想起那晚的灯。唐栀完成归还，却欠孟阿婆一次更完整的说明，也不再能把林默的异常当成修书途中偶发的插曲；她会保留监督，自己去整理晚间记录。林默没有得到想要的答案，反而多了一笔关系上的债：下一步先核对进入阅览室的人和值班记录，不能先追着某个声音相像的人问话。七号仍然低电停机，原声没有被播放，这个克制本身成了三人暂时共同守住的东西；而台灯、擦掉一半的登记和九点二十分，已经把他们从“机器出了什么问题”推向“有人曾在闭馆后把这本书带到灯下”。
