# 作者房间：先活一遍，再决定怎么写

这一章开始时，林默并没有等一件怪事上门。他在临川靠修旧音箱、小机器人和别人嫌麻烦的小故障过日子，眼前更实在的事是把桌上那只修到一半的音箱交出去，别让下个月的房租再往后拖。他的工作台不大，旧语音板、螺丝盒和一盏不太亮的台灯挤在一起，七号占掉其中一小块地方。七号平时只负责提醒、播放和在桌面上走两步，电池也只够撑半小时，林默把它留下不是因为它有多聪明，而是因为那次演示事故之后，他还没有把它真正拆掉。两年前那个无人认领的声音像一笔没有对账的旧欠款，平时压在心里，只有设备突然卡顿时才露出一点边角。

唐栀这天本来要在社区阅览室清点搬迁的书。她还有一串事情排着：哪些书要送回原主人，哪些书要补拍书脊，哪些纸箱不能压在潮墙边。旧《夜航故事》不该占用她的下午，它只是一本要修补、要送还的旧书，书里夹着孟阿婆丈夫留下的手写字，唐栀答应过会尽量原样收好。她来找林默，是因为书脊和内页的损坏已经不是胶水能糊住的，且孟阿婆催得很急。她没有把这件事包装成“发现异常”，也不打算让林默先替她查出一个故事；她要的是书能好好回到人手里，阅览室的留档也别在搬迁前断掉。

孟阿婆进场前也有自己的安排。她不是来给年轻人提供线索的老人，手里还有买菜、吃药和收拾旧房子的事。她要拿回书，越快越好，尤其不愿意让丈夫的字被人当成新鲜事传来传去。她知道唐栀做事仔细，所以才肯把书交出去；这份信任里也带着一点防备——修书可以，别替她解释丈夫，更别把夹在书里的东西拿去给别人听。她未必会一开始把这些顾虑说全，往往只会盯着书角有没有压平、线有没有散开，再决定自己还要不要站在门口多留一会儿。

唐栀想把事情办成，孟阿婆想把事情尽快收回去，林默则想先把书修好、把异常挡在门内。三个人的目标并不冲突，却没有一件能只靠一个人完成。唐栀在没有林默帮忙时会先把书包好、记下破损位置，再去找孟阿婆确认归还时间；孟阿婆若等不到消息，会直接来取，或者把“算了，先还我”放在修复之前。林默则会先检查能不能修，顺手给每个零件编号，把人的催促归进“待处理”。正是这些各自合理的动作把他们撞到一起：唐栀抱书进门时已经准备好只谈修复，孟阿婆随后找来时已经准备好不再多谈，林默却让七号接近书页，想确认异常是不是设备串音。

七号没有能力替谁破解往事。它只是被林默当作一个可移动的拾音和播放出口，短腿落在桌面上会咔嗒响，单眼灯从待机色变成工作色。真正先改变局面的，是它借着书页和附近设备说出一句不在离线日志里的、像是在叫林默童年称呼的话。林默的第一反应不是相信书，也不是把声音放给唐栀听，而是按住书，拔掉一根线，再去看七号还剩多少电。他会把技术动作当作挡板，因为承认自己听见了，就意味着两年前那件没查清的事又回来了；可他也不能把这一次推给“误报”，因为那句话碰到了一个只有旧关系里的人才会知道的地方。

唐栀最先保护的不是秘密，而是孟阿婆对这本书的处置权。她会在林默想继续操作时把书拿回自己手里，先确认有没有把纸页磨坏，再看他到底想查什么。她和林默太熟，知道他一紧张就开始报设备状态，也知道他不是故意轻慢人，所以不会立刻把他赶走；但这份熟悉也让她不愿替他圆场。她心里明白，林默怕的未必只是声音来源，他更怕再次成为那个“能让机器说出不该说的话、却说不清为什么”的人。林默心里也明白，唐栀把书抱紧并不只是在护纸，她是在防止他把一个活人的旧日关系变成可供测试的材料。两个人都不会在此刻把这层话说透。

孟阿婆真正担心的事情，可能比声音真假更简单：书还会不会完整地回到自己手里，丈夫留下的字会不会被陌生人碰过、传过。她未必知道七号的异常，也未必想知道。她看见年轻人围着书停下来，就会把“先还我”放在任何查证前面。林默若执意继续，场面不会突然变成争吵，而会先变成一连串小小的推诿：唐栀说先让阿婆看看书，林默说只差一个记录，孟阿婆伸手去拿书包；每个人都在做自己认为负责的事，却都把另一个人的重点往后推。误会也会从这里长出来——孟阿婆可能以为林默想留书，唐栀可能以为林默又要把事情关进设备里，林默则会把她们的阻拦误判成不愿意面对事实。

最后能暂时办成的，不是查出回声从哪里来，而是把书留下，停止外放，保存一次不完整但可复核的设备记录。这个决定会让唐栀多欠孟阿婆一次解释，也让她不得不重新安排阅览室的归还顺序；孟阿婆没有得到立刻拿书的结果，却至少知道书没有被拿去公开播放，她会带着不完全的放心离开，之后还会回来要一个说法。林默得到了一点阶段性的胜利：声音确实没有出现在现有日志里，不能简单归为原本的预设语音；代价是他不能再把它当成自己的私下测试，书的去留和声音是否继续出现都要让唐栀、孟阿婆参与决定。唐栀与他的旧默契也发生了变化，她仍然会帮他查，但不会再默认“让林默先拿去看看”就是最稳妥的办法。

章末留下的不是一个凭空出现的谜名，而是一个被本章行动逼出来的难题：书暂时留在林默的工作台，七号的电量正在往下掉，离线记录里仍没有那句声音；可那句话已经被三个人听见过，且其中至少有一个人不希望它再被播放。接下来他们要查的，不只是它从哪里来，还包括谁有权让它继续说，以及这本书究竟还能不能按原计划归还。
