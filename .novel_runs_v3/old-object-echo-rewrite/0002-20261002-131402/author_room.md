# 作者房间

这一晚对林默来说，本来不只是一件旧书的事。他的修理铺还有一只拆到一半的旧音箱，明早要交货，桌上的胶水也得清掉，免得沾到别人的零件。可七号在书边说出的两句话把这些琐事全压到了后面。七号已经只剩低电，录音和日志又各自缺了一块，他最想做的是把四十六秒的空白钉在某个可复核的地方，证明自己没有再次把误听当成答案。他带着两年前演示事故留下的欠账进来：那时所有人都催他把声音放大、重播、解释，只有他自己后来才发现，没人问过那句话能不能被留下。于是他这次会本能地抱住记录和设备，却不愿承认自己其实也怕再听见一次。

唐栀在离开修理铺前，本来还要把阅览室最后一批待搬的书按编号装箱，给几个没来得及还书的人留便条，再把《夜航故事》送到孟阿婆手里。她不是临时来替林默跑腿，她得把搬迁前的归还和留档做完，这是她对阅览室、对那些借书人，也对孟阿婆的责任。她把书带去修复间已经借了一次林默的地方，书在他那里听见了不该听见的声音，哪怕书页没被翻动，信任也已经有了细缝。她一面需要林默帮她把书角压好，一面又知道不能让他的查证欲顺势接管这件事。她真正想保住的不是一件异常物证，而是孟阿婆仍能决定丈夫留下的东西要不要被别人听见。

孟阿婆来阅览室，并不是专门等一个谜底。她得先把自己的书拿回去，回家还要收拾搬迁后暂放的几箱东西，钥匙也不能在外头耽搁太久。她知道书里夹过老伴的手写线，也知道别人一听见像老人的声音，就会忍不住追问那是不是他。她过去已经替老伴保管了太多东西，没兴趣再替一段声音向陌生人证明身份。她带进现场的不是好奇，而是很具体的防备：先看封面和书角有没有被碰坏，先确认书还属于她，再决定有没有必要听唐栀把事情说完。她会把难过压回一件眼前的事，反复确认书有没有被动过，因为只要书还在手里，别人就不能替她安排这段旧日子。

三个人相遇时，表面上只有一件交接：唐栀把书送回去，孟阿婆收书，林默在旁边抱着一台已经没电的机器人。真正互相拉扯的是三种不同的时间表。唐栀赶着闭馆和搬迁，想把书还完就走；孟阿婆想把事情缩回自己的掌心，不愿让归还变成当众辨认亡夫声音的场面；林默知道如果这时离开，书和阅览室里的痕迹就会一起被打包，他想趁现场还没变动，查一查有没有不需要碰书、不需要播放原声的来处。谁都不是来等主角解决问题的：唐栀已经准备好把书抱走，孟阿婆已经在心里排好了检查封面、收钥匙、离开的顺序，林默也只能在他们的动作之间争取一个位置。

事情会先被办事的细节拖住。孟阿婆检查书角时，唐栀不能替她回答林默有没有播放；林默看见她的手一直压着封面，就知道自己不能伸手。七号的停机让他少了一件可以当场复测的工具，录音笔里那点声音反而更像一笔会惹麻烦的欠账。孟阿婆听见异常的来龙去脉后，最先防的不是林默会拆书，而是他会把模糊的相似强行定成身份，再拿去给别人听。唐栀会把每一次林默想靠近桌面、台灯或登记册的动作拦慢一点；不是不信他会修东西，而是不信他能在听见答案之前忍住。

大家心里明白却不会当面说透的，是这次归还已经不可能像普通归还那样干净地结束了。孟阿婆知道唐栀把书带去修理间，是因为她信任唐栀，也知道这份信任不能无限借给林默。唐栀知道林默并非只想满足好奇，他是在躲两年前那场事故，可她不愿用他的旧伤替他争取权限。林默知道孟阿婆拒绝的可能不只是播放，而是拒绝任何人从丈夫的遗物里替她做结论；他也知道自己一旦只强调还要继续查，就会再次把人的顾虑压成设备条件。三个人都不会把这些话完整说出来，只会通过收书、按住书面、把机器人放远、指向哪一摞登记册来表达。

场面因此会从归还变成一次受限制的查证。唐栀先想结束，孟阿婆也会顺着这个方向走；但当她听到七号说过的内容，或者看见林默只拿出时间和记录、不要求重播时，事情不会简单地被赶走。她可以允许他查看阅览室留下的晚间记录，却不允许翻书、外放原声，更不允许把她丈夫的声音交给第三个人辨认。这个许可不是她突然相信了回声，而是她宁愿让一次有边界的查看发生，也不愿让林默在没有她的情况下继续猜。她仍然会把书收回自己手里，并把查证范围收窄到桌灯、值班和借阅留下的痕迹。

阅览室正在搬迁，纸张、台灯和文件夹都不在原来的位置，查找不会像打开数据库那样顺畅。有人把晚间登记纸擦掉了一半，文件夹却还留着一个能和九月十六日对上的编号；闭馆后的桌面有被灯照过的痕迹，墙上的钟停在九点二十分。林默会把这些先当成需要核对的事实，不把它们拼成声源姓名。孟阿婆会补出一个她不愿意主动讲的生活细节：她锁门后曾回来过，门没有开，灯却亮着。这个细节让现场多出一个具体的晚间时段，也让她不再只是被动交线索的人——她开始决定哪些旧事可以放到桌面上，哪些仍然留在自己那里。

本章结束时，真正改变的不是谁终于听懂了书里的声音，而是三个人对这件事的站位变了。书被孟阿婆拿回，页和原声都没有被侵犯；她拒绝公开丈夫的声音，却给出一次只查阅现场和记录的许可，从此这件事不再是林默私下保存的一段异常。唐栀完成了归还，却没有把责任交给林默，她会留下来监督第一次查证，和他之间那种可以互相损两句的熟悉里，多了一条必须认真遵守的边界。林默没有得到答案，反而得到一项更难的工作：先核对晚间进出和登记，再决定是否有资格继续问。他的生活里添了一笔不能靠修理解决的关系债，孟阿婆的生活则被迫在搬迁前多留一晚的灯影和一个停在九点二十分的钟。下一步追的是阅览室里那次闭馆后的使用记录，不是书自己突然知道了谁的名字。
