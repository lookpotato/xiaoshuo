# 作者房间：先活一遍，再决定怎么写

作品：旧物回声事务所（新生成链）；章节：2。

这一章真正的起点不是林默昨晚听见了第二句“左边”，而是唐栀答应过孟阿婆，明天下午四点以前把《夜航故事》送回去。她第二天一早还得去社区阅览室清点最后一批书，搬迁的人手不够，登记卡和借阅袋又对不上。有人把几本没有盖章的书混进了待搬的纸箱，她得蹲在地上重新分，不能因为林默那边多听见一句话，就把阅览室的事情全搁下。她会照常给孟阿婆打电话，告诉她书脊已经在修，但不会把“书可能发出声音”当成热闹讲给对方听。她知道老人最怕的不是书坏，是别人拿她丈夫留下的东西做文章。唐栀想把书修到能翻、能拿走，最好连林默都没有机会把它变成一件需要围观的怪事。

孟阿婆那边也不是等着剧情上门。她会把布袋找出来，把家里原本放在窗台上的一块旧抹布换掉，腾出地方放书；她还要去菜市场，买不买菜取决于唐栀什么时候送还。她答应过老伴，阅览室搬走前要把这本书拿回家，这个约定拖了太多年，已经不是一件可以让年轻人替她安排的事。她心里知道唐栀办事稳，却不愿再欠一个“先放你那里”的人情。她听出唐栀话里有没说完的部分，却不会逼着一个熟悉的晚辈当场解释。她会先问书脊还能不能翻、夹页有没有被碰，再问什么时候送来。若林默把“异常”放在她之前，她会先把书要回去，因为一旦由别人决定什么时候播放、给谁听，这本书就又不属于她了。

林默昨晚没有真正睡好。他把扬声器接口拔掉，录音笔里的两段波形导进旧笔记本，反复对照七号的电量、动作和日志时间。能确认的只有：声音出现时，七号没有正常播放记录；不能确认的是，声音究竟从七号喇叭、音箱后腔的铜线，还是书页开口附近的空气里出来。他想把这几件事拆开，一件一件测，可他的工具和时间都不够，七号的电池也只剩三成上下。两年前演示事故之后，他已经习惯在别人问“是不是它说的”之前先找一条能挡住自己的技术边界。可这一次，挡住他的不是数据，而是唐栀留下的时间：明天下午四点前书必须回去。他若一早把书送回去，异常可能断掉；他若留着书继续测，就等于又把别人的东西扣在自己手里。

他本来还要修完客户那只旧音箱。客户中午来取，修不好就得退钱，退钱倒不算大事，麻烦的是这个月的房租和七号的电池都靠这些小活往下撑。林默会先把音箱后腔里滚进去的螺丝取出来，再看那段被压扁的铜线是不是被七号磁吸脚带动过。这个动作本来只是为了排除串音，却会让他发现铜线上沾着一层很细的纸纤维。那不是证据，只够让他暂时不敢把书装回布包。他会给唐栀发一条尽量短的消息，说明书还没有动夹页，但不会在消息里写“它又说话了”。他怕字一落下去，事情就从两个人之间的维修变成了必须解释的事故；更怕唐栀看见后立刻来取书，而他还没来得及确认自己昨晚究竟听到了什么。

七号在没有人指挥的时候，不会老老实实躺在桌上等复测。它的电量不够走很远，外接扬声器又被林默拔了，只能在桌面上做几步短距离移动。它会避开那个被捏过的脑袋，绕到书和音箱之间，单眼灯在黄、红之间变化。它没有办法判断孟阿婆是谁，也不懂唐栀为什么总把书往自己怀里收；它只会重复储存过的词，偶尔把刚听见的声节接错地方。林默如果把它当成一个播放器，它会在最该安静的时候发出动静；如果把它当成一个需要照看的故障物，它又会因为电量下降被迫停在半路。这种限制会让它参与现场，却不能替林默找到答案。

唐栀和孟阿婆真正碰面前，各自都在保护一件具体的东西。唐栀护的是阅览室最后一点秩序，也是孟阿婆不想被人议论的脸面；她不愿让老人看见自己其实也在怀疑林默会不会像两年前那样，先把异常留下，再把归还往后推。孟阿婆护的是一句不必由年轻人替她解释的话。她的丈夫已经不在了，书里夹着他的字，这件事她可以自己说，也可以不说；但她不愿意先听见一个声音，再被问“是不是他”。林默护的是查清来源的机会，底下还压着一层更私人的东西：他想证明这次不是两年前那种无从负责的失控，可他不愿承认自己其实已经把“证明”放在了“还回去”前面。

所以场景里不会有谁单纯负责推动、谁单纯负责拖延。唐栀想把事情办成，她需要林默交出一个能拿走的书，却会因为看见书脊里新的纸纤维而短暂同意让他再看一眼；这不是信任恢复，而是她也怕把一件可能伤到别人的东西原样送回去。林默想拖住书，至少拖到能分开设备和书的声源，可每一次拖延都会让唐栀更像是在替他看管证据。孟阿婆到场后会把两人的拉扯往回掰：先要书，不听完整复测；等她发现林默没有播放，而是把录音笔和接口都推远，才会留下几分钟自己看夹页。

这几个人心里明白、却不会当面说尽的，是唐栀并不完全相信林默能在碰到旧事故时守住分寸；林默知道唐栀若真不信，昨晚就会把书拿走，却不敢把这点余地当成原谅。孟阿婆知道唐栀瞒了她一点东西，也知道瞒的原因不是恶意，而是年轻人怕老人受惊；她不会因此立刻责怪唐栀，却会在林默提到“声音”时把手伸过去，要求先确认书在自己手里。还有一件更难说的：那句带着气音的回应听起来像一个在世的人年轻时说话的尾音，唐栀也许已经从阅览室的晚间借阅登记里猜到是谁，但她不想在没有对方允许的情况下替他把名字说出来；孟阿婆则可能早就知道，只是不愿让死人的旧物替活人作证。

场面会从办修复变成办交接。林默先用最熟悉的办法，把书放在台灯下，拆开七号的电池接口，想证明没有设备就不会再有声音；唐栀在旁边整理搬迁清单，时不时把书的位置往自己这边挪，逼他每次伸手前都先看她。第一次复测可能只得到喇叭里的电流噪声，林默因此松一口气，误以为可以把书还回去。可当唐栀合上书准备装袋，夹页里又漏出一个被压扁的短音，像有人在很远的地方应了一声。它不完整，也不指向明确的人，反而让三个人的判断都变坏：林默更想拆，唐栀更想合上，孟阿婆却可能从音节里听出一个生活中熟悉的停顿。

误会会从这里长出来。林默为了留住现场，可能把录音笔放在书边，动作太快，孟阿婆以为他又要替她播放；唐栀会先把书抽走，而不是解释林默的意图。林默被这一下顶住，脱口而出的技术判断会显得像推责，随后他必须把电池、接口和录音笔一件件推到桌边，证明自己没有在暗中继续让书说话。孟阿婆不会因为他解释清楚就立刻放心，她会问唐栀为什么不先告诉她，唐栀也不会把责任全推给林默，因为她确实答应过先把书修好再说。三人之间的冲突不是谁揭开了一个大秘密，而是谁在没有恶意的情况下替别人多做了一步决定。

最后能办成的具体事情，是孟阿婆把书带走，至少把“是否归还”从林默手里拿回来；但书脊不会彻底修好，林默也不会得到声音来处的答案。他会交出一份没有加工过的短录音，先由孟阿婆决定留不留，不再自行播放、不发给别人。唐栀会把阅览室晚间借阅登记的一页复印件留下，不是为了让林默顺着名字追人，而是因为那页记录本来就是她搬迁留档的一部分。她会把“有人在晚上用过这本书”告诉孟阿婆，却把那个可能仍在世的人的名字停在半句之外，等老人自己决定要不要继续。

本章结束时，林默真正失去的是把书再留一晚的资格，也失去了一点“只要我查清就能替所有人负责”的自信；他得到的是一次边界更清楚的工作方式：先让物主拿回东西，再谈异常能不能继续查。唐栀仍然会把书交给孟阿婆，但她和林默之间那笔旧账没有结清，反而变成了新的合作条件——以后再碰别人的东西，林默得让她在场。孟阿婆的生活会被打乱半天，她原本只想取书回家，最后却要决定一段声音是否值得听第二遍；她不一定原谅谁，但她重新拿回了决定权。

更深的改变落在七号身上。它没有被证明有意识，也没有替任何人说出答案，可它在断开扬声器、日志没有新增记录的情况下留下了另一段无法归档的回应。林默会把它从桌面机器人改成暂时封存的故障物，不再把它带去客户面前；这会影响他的生计，也会让唐栀第一次看见他确实愿意为别人的边界牺牲一点效率。章末留下的问题不该是“七号到底是不是活了”，而是那段声音为什么会在一本旧书和一台有旧事故的机器之间出现，以及当声音牵涉到一个还活着的人时，谁有权让它再说一次。
