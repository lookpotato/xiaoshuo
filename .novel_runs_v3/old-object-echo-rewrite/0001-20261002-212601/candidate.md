# 这书叫了他一声

十月的临川还没有真正凉下来，修理铺卷帘门只拉了一半，风从门缝里钻进来，把工作台上的螺丝盒吹得轻轻响。

林默用镊子夹住一根脱焊的线，烙铁头刚碰上去，门外有人敲了两下。

“有人吗？”

“门没锁。”

唐栀侧身进来，怀里抱着一只旧布包。她先把鞋底在门口蹭了蹭，才把布包放到离烙铁最远的那块桌面上。

林默没抬头：“你又把阅览室的东西搬出来了？”

“这回是人家的东西。”

她解开布包，露出一本灰蓝色的旧书。《夜航故事》的封面起了毛，右下角被水泡过，书脊裂开一道能塞进指甲的缝。里面夹着几张借阅卡，边角叠得很整齐。

“补书脊，压平，明天还给孟阿婆。”唐栀把书往他手边推了推，“别拆页。”

“我什么时候拆过你的书？”

“上回你说只是看看，最后把护封和正文分开晾了一晚上。”

“那是护封自己粘住的。”

“所以这回我盯着。”

她说完就在工作台旁边的折叠椅上坐下，顺手把一摞废电路板往旁边挪了挪。林默看了她一眼，没再争，戴上棉手套，把书翻到扉页。纸张发黄，靠近书脊的地方有一道很浅的铅笔线，像有人写到一半又停了。

“孟阿婆催得挺急。”林默说。

“阅览室下周搬。她借这本书三个月了，今天特意过去拿，发现书脊坏了。”唐栀把手机扣在膝盖上，“她没骂人，只说先还她。”

林默抬眼：“那你还带来我这儿？”

“我说给你补好再送。你要是今天弄不完，我自己拿胶带缠。”

“别用胶带。”

“所以才来找你。”

林默手上没停，把书页按平，取出一条窄窄的补书纸。修理铺里没有专门的压书板，他拿两块擦干净的音箱外壳垫在两边，压住书脊，动作比修喇叭慢了许多。

桌角的七号忽然往后退了一寸。

它只有巴掌大，方脑袋上亮着一只黄灯，两只磁吸脚在铁桌面上咔嗒咔嗒地挪。平时它只负责报时、提醒林默换电池，或者在找不到螺丝时发出一声不太讨喜的提示音。今天早上林默给它换了块旧电池，按计划还能工作二十分钟。

唐栀低头看它：“它撞到什么了？”

“没撞。”

七号停在书边，单眼灯闪了两下。林默伸手把它拨开，继续压书脊。烙铁架旁的指示灯突然亮起，七号的喇叭里先是一阵沙沙的底噪，接着蹦出一句短短的话。

“阿默。”

林默的手停在半空。

唐栀也没动。她看着七号，过了一会儿才问：“它叫你？”

“预设词里没有这个。”

七号的黄灯转成红色，脚下的磁铁吸住桌面，发出一声轻响。

林默把书放下，先拔掉烙铁，再关掉桌边的小音箱。他做这些事时很快，像有人在他身后数秒。唐栀没有拦，只把那本书往自己这边收了半寸。

“你别碰它。”林默说。

“我没碰。”

“书也先别翻。”

“我在等你说为什么。”

林默已经蹲到桌下，手电照进电源排插。七号用的是独立电池，外接音箱没有通电，桌上的录音笔也没开。他拔下七号背后的数据线，拔得太急，线头碰掉了旁边一颗螺丝。

唐栀弯腰把螺丝捡起来，放到他掌心：“先拿好。”

林默接过来，手指在螺丝上顿了一下。“刚才那句，不是它原来的提示。”

“我听见了。”

“可能是串音。”

“你这儿没有开着的设备。”

林默没接这句，已经把七号翻了过来。

唐栀看着他把七号翻过来，拧下底板上的两枚螺丝。“查多久？”

“十分钟。”

“书脊呢？”

“半小时。”

“那你先说哪个能按时交。”

林默抬头，像没想到她会在这时候问这个。他看了一眼桌上的旧书。补书纸已经对齐，胶还没压实；书页摊着，里面那道铅笔线露出半截，后面压着一小块深色的纸角。

“书明天给孟阿婆。”他说。

“你刚才说半小时。”

“今晚弄完。”

“她明早来拿。”

“我送过去。”

唐栀这才把书推回去，却没松手。“别拿它碰书。”

“我没说要测书。”

“书在这儿，你就会测。”

林默看着她的手。她的拇指压在封面那道起毛的边上，指甲里还留着修复纸的白屑。布包被她按得很稳，一点要松手的意思也没有。

“我只动七号。”

“书放在我看得见的地方。”

“行。”

“别拆页。”

“知道。”

唐栀的手还压着布包，没有松开：“刚才那句，别留录音。”

林默没立刻答应。他把七号重新放平，打开外壳，检查电池卡扣。电池电压比刚换上时低了一格，离线日志还在，最近一条记录是上午十一点十七分的“更换电池”。没有播放记录，也没有语音输入。那句提示前该有的文件索引，连个空位都没留下。

他点开日志，又听了一遍刚才的录音缓存。七号只留下了半秒杂音，真正的声音像从缓存里擦过去，什么也没存住。

“你听清楚了吗？”唐栀问。

“清楚。”

“那就算听清楚了。”

林默皱眉：“这还不能算证据。”

“我没说是证据。”她看向那本书，“别让它再说第二遍。”

门外传来三轮车刹车的声音。唐栀拿起手机看了一眼，站起来，把书重新包好。她的动作很慢，先把书脊托住，再把布包的结打在侧面，像怕结头硌到封面。

“孟阿婆还在等你回话。”她说，“我告诉她明早拿。”

“你告诉她书脊还在补，别说别的。”

唐栀抬头看他。

“她问起来呢？”

林默望着桌上的七号。红灯已经灭了，只剩一只没有亮的黑眼睛对着他。

“等我查到再说。”

“你最好查到。”

她抱起书，走到门口又停了一下：“阿默。”

林默的肩膀绷住。

唐栀却没有重复那句声音，只说：“胶别沾到字。”

“不会。”

“你上次也这么说。”

门帘落下一半，唐栀的脚步声沿着旧街慢慢远了。林默等到声音听不见，才把桌边的外接设备一件件断开。他找出一块还有余电的备用电池，装进七号，打开离线记录。

七号的黄灯亮了一下。

林默没有按播放键，只把那本《夜航故事》放到它面前，书脊朝外，封面压着一张干净的白纸。随后他坐回去，拿起螺丝刀。

“叫一次不算。”他对着没有反应的七号说。

螺丝刀刚碰到底板，七号忽然偏过脑袋。

这一次，喇叭里没有声音。桌上的书页却自己翻过一页，停在那道铅笔线下面。

纸页上露出一行被压淡的字：

阿默，别把灯关了。

林默的手指从螺丝刀上松开。

七号的电池还剩十九分钟。
