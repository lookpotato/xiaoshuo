# 作者房间：先活一遍，再决定怎么写

第一章开始时，谁都不是专程来寻找怪事的。

林默在临川靠修旧音箱和小型机器人过日子。他本来要把工作台上那只七号的左磁吸脚重新压紧，再把唐栀送来的旧《夜航故事》补好书脊、压平卷角，按约定交还。这样的活不值得惊动任何人：看裂口，换胶，等干，记下哪一页已经脆得不能再翻。林默愿意把事情做成一件能验收的物品，书能不能合上，螺丝会不会松，喇叭有没有杂音，都比“你当时为什么那么说”容易处理。

唐栀来到这里，也不是为了把一个异常交给林默。阅览室快搬了，她得在搬迁前把书架上的旧书清点、修补、归还，尤其是孟阿婆借走又托她送修的这一本。她还要留住阅览室的借阅痕迹，不能等地方清空以后，大家只记得一堆纸箱。孟阿婆已经催过几次，只说先把书还回来，别拿她丈夫留下的东西做热闹。唐栀答应了，却没有把这句话完整转告林默：她知道林默一听见“声音”就会把手伸向设备，也知道这件事一旦被他说成技术问题，书和人的来处就会被他一起拆开。

孟阿婆本来要做的是一件很小、也很硬的事：在阅览室搬走前拿回自己的书，确认夹在书里的手写字没有被弄坏，然后回家。她不想成为线索提供者，不想坐下来讲丈夫生前的事，更不想有人为了证明旧物会说话，替她决定哪些记忆可以公开。她年轻时已经看过太多人把别人的难过说成故事，到了这个年纪，她只愿意为书的归还负责。她把书交给唐栀，是因为信得过这个会把书角压平的人；这份信任并不自动延伸到林默的工作台，更不延伸到七号的喇叭。

七号则没有“今天要处理什么”的生活。它被林默放在桌边，电池只够连续工作约半小时，原本的任务是播提示、听一句短指令，或者在林默找不到螺丝时发出烦人的提示音。它两年前曾在公开演示里播出过一段无人认领的声音，项目因此停掉。林默把它留下来，一半因为舍不得，一半因为不肯承认那次演示已经没有可追的东西。七号并不知道这层旧账，只会在被搬动、被碰到脑袋或接收到熟悉物件的声响时，按现有程序和那点说不清的残留作出反应。

真正相遇前，唐栀会先在阅览室里做自己的事。她把待还的书从纸箱边挑出来，发现《夜航故事》的书脊还需要补一道，便拿布包好，避开孟阿婆伸来接书的手，先说送去林默那里很快就好。孟阿婆不愿再等，却看见封面边缘有新压出的折痕，最后只把手收回去，让唐栀当晚带回来。她没有追问唐栀为什么一定要找林默，也没有说自己听见过什么；她只盯着书被放进袋子的方向。唐栀明白这是催促，也是警告。

林默在工作台前会先修书，不会先查七号。直到书页被翻到某个位置，七号突然叫出一声不属于预设提示的称呼，还是林默童年才有人这么叫过的称呼，他的手才停下来。这个声音首先改变的不是世界观，而是交接的顺序：书不能按原计划归还，七号也不能继续开着喇叭工作。林默会把书留在桌面，拔掉外接声音设备，检查电源、离线日志和七号最近的播放记录。他的第一反应是把异常压回可测量的范围里，因为两年前那次演示留下的失败经验告诉他，未经确认的声音一旦传出去，解释权就不在自己手里了。

唐栀会想把书拿走。她来这里的目标仍然是修补和归还，不是配合林默复测。林默留书，在她看来既可能是必要的检查，也可能是他又一次把别人的东西扣成自己的实验材料。两人的旧关系让她能直接把手伸过去，也让这一下更容易变成冲突：她知道林默不是故意冒犯，却不愿意用熟人的宽容替他越过孟阿婆的意思。林默则把她的催促听成对设备的否定，把“先还书”误会成“这只是一段录音，别查了”。他说得越短，越像在挡人；等发现唐栀已经把书袋拎到门边，才意识到自己保护的是一条证据边界，同时也把她推到了门外。

大家心里明白却不会当面说的是：唐栀怕林默重新陷进两年前的演示事故，怕他拿修理一件物品的方式去追一个可能伤到活人的声音；林默怕唐栀把书取走以后，异常再也没有第二次出现，自己会永远不知道当年漏掉了什么；孟阿婆怕的不是书说话，而是丈夫的声音被陌生人借走；七号没有可确认的害怕，但它被人捏住脑袋提起来时会立刻断掉动作，像一件不肯配合的旧工具。

场面会从办事变成推诿，再从推诿变成一次很窄的相互让步。林默可以不把声音放出去，只在原地断电、换一块有残余电量的电池，观察七号是否还会重复那句话；唐栀可以不把书带走，但要求书始终在她看得见的地方，不能拆页，不能让七号继续碰它。这个决定不会证明回声是真的，只会把一个可复核的事实留下来：七号的离线日志里没有那句声音，断开原有播放链以后，书页附近仍可能出现一次无法立刻归入录音的响应。电池会因此耗掉，修书的交付时间会被拖到第二天，孟阿婆也会等不到原定的归还。

第一章结束时，林默得到的不是谜底，而是一个他不得不承担的保管责任：书暂时留在自己手里，不能再把它当普通维修件。唐栀没有因此彻底站到他这边，她会带着阅览室的搬迁清单离开，决定第二天亲自来拿书，也开始独自追查这本书在阅览室被谁、在什么时间翻过。孟阿婆会因为迟迟没拿到书而更不放心，她与唐栀之间那点原本稳固的信任出现一道细缝。七号则消耗掉一部分本就不多的电量，留下第二次响应前的停顿和一条不完整日志；林默第一次不得不承认，修好设备并不等于有资格替书里的人说话。

这样，本章真正改变的是交接关系。书没有归还，异常没有公开，林默和唐栀也没有把旧账说穿，但他们从各自的生活轨道上被拽偏了一点：唐栀要同时守住书和孟阿婆的意愿，林默要在查清声音之前先学会不把声音占为己有。下一章的压力不是“七号还能不能再说一句”，而是孟阿婆会亲自来把书拿回去；到那时，任何一次播放都不再只是林默的测试。
