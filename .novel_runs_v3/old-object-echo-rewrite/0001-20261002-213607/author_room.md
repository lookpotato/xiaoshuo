# 第一章作者房间

这一章开始时，林默并没有在等一件怪事。他在临川靠修旧音箱、小型机器人和别人嫌麻烦的零碎活过日子，桌上还有一只拆到一半的音箱，客户催着要拿回去。七号也只是他手边一个尚未收好的旧项目：电池还能撑半小时左右，走路会咔嗒响，平时只负责提示、播放和保存一点离线日志。林默本来要先把音箱的杂音找出来，再处理唐栀托他修的那本旧书。他把这种顺序看得很实际，能测的先测，不能测的先放着；这既是他的谋生办法，也是他躲开两年前那场演示事故的办法。只要问题还可以叫作接触不良、串音或日志缺口，就不用立刻承认那段无人认领的声音还在跟着他。

唐栀进门之前，也有一串必须做完的事。社区阅览室快搬了，她得把剩下的书按来源留档，把能送还的送回去，把夹在书里的纸片、借阅痕迹和书角的伤处处理好。那本《夜航故事》不是她专门替林默找来的神秘物件，只是她从阅览室带出来、答应替孟阿婆修补后归还的旧书。孟阿婆已经催过一次，搬迁工人又在等着清出书架，唐栀没有时间把每件不对劲都交给林默慢慢研究。她来找他，是因为书页边的开口和书脊的损伤确实需要他的旧设备配合检查，也是因为她知道林默一旦听见异常，可能先把东西扣下来，忘了物主正在等。

孟阿婆这时不在林默的工作台前，却并没有把自己交给这件事的主线。她可能在家里收拾一个要搬走的抽屉，给老伴留下的手写字条换个不容易受潮的地方，或者只是在阅览室门口等唐栀把书送回去。她要的不是一个关于亡夫的热闹故事，也不是替谁证明旧日发生过什么。她只想先拿回自己的书，别让别人为了好奇把里面的东西放出来。这个要求看起来简单，却会成为现场最硬的边界：她没有义务因为七号说了一句话，就把自己的记忆、丈夫的字迹和书曾经经过谁的手交给林默。

七号没有真正的“计划”，但它有被人反复使用出来的习惯。林默平时会让它在桌边报状态、听短指令，偶尔捏着它的方脑袋把它从线路板旁边挪开；它也记得一些用过的词，却不懂这些词为什么会在某个时刻伤到人。没有林默介入时，七号只会按原先的提示程序巡走、等待电量下降，或者在唐栀把书放到桌上时被震动和声音触发。它不是主动来揭密的角色，恰恰因为它只会在旧习惯、设备残留和书的异常交错时吐出一句不该出现的话，才使所有人都必须为这句回应负责。

现场里，唐栀想把事情办成：书要修到能安全翻阅，归还不能再拖，阅览室的搬迁也不能被林默的好奇心卡住。林默想把事情拖住，至少拖到他确认声音不是七号日志里的预设内容；他会把书留在工作台上，先看喇叭、线路、电量和离线记录，而不是让那句话传到门外。孟阿婆若到场，想拖住的是播放和追问，她会把归还这件事往前推，把解释往后压。七号保护不了谁，但林默会本能地保护它不被当成证人，也保护自己不再被那场旧演示钉死；唐栀则会保护书的来处和孟阿婆不愿被公开的部分。三种保护会互相顶住，谁都不完全是为了查真相。

大家心里明白却不会当面说全的，是林默不只是想修书。他听见异常时，真正害怕的不是设备坏掉，而是两年前那段声音可能从未离开；唐栀看得出来，却不会在第一次碰面就拿这件旧事逼他承认。林默也知道唐栀把书带来不只是求技术帮忙，她还在赶阅览室搬迁、替别人守住体面，可他会把这份催促听成对检查的干扰。孟阿婆若说“先把书还我”，那句话背后不是不关心发生过什么，而是不愿让自己的丈夫被一段不知从哪来的声音替她重新解释。她们不会把这些心事排成一张清单，只会在拿书、挡手、关掉播放或少回答一句时露出边界。

事情会先以办事的样子推进。唐栀把书放下，先检查书脊和夹页，林默先做能复现的操作；七号在无人期待它回答时说出童年称呼，或者说出只属于林默旧生活的短句。林默第一反应会伸手按停、拔掉外接声源、翻日志，动作比解释快；唐栀会先把书从他手边拿开，确认他有没有继续碰里面的夹页。两个人因此产生一次并不漂亮的冲突：林默觉得她妨碍排查，唐栀觉得他已经把孟阿婆的东西当成实验材料。随后林默会发现日志里没有这句，电量、扬声器和离线状态又让“只是程序播放”变得不够稳妥。这个发现不能直接证明回声是真的，只能逼他承认现有的方便答案不够用了。

误会会从这里自然变形。林默以为把书暂时留下是在避免伤害，唐栀听见的却可能是他又一次把别人的东西扣在自己手里；唐栀坚持尽快归还，林默又会误解成她不在乎声音到底从哪里来。孟阿婆随后真正赶来或通过唐栀催要书时，现场的优先级会被她改掉：不是先听七号说完，而是先确认书还能不能拿走、谁碰过它、是否已经被播放。林默若为了证明设备异常再次启动七号，代价就是越过物主尚未同意的边界；他最后更可能关掉播放、保存一份未经加工的异常记录，并把书暂时留在可说明的检查状态，而不是把声音传出去。办事没有彻底办成，至少避免了最坏的那一步。

本章结束时，改变必须落在生活里。唐栀不能再把林默当成一个修好东西就会按时归还的老朋友，她会把归还和检查拆开，今后自己掌握书什么时候回到孟阿婆手里。林默也不能把“先查设备”当作对所有人的合理解释，他欠唐栀一次道歉，欠孟阿婆一个由她决定的归还时限，还欠自己一个更严的复测。七号的电量会被这次异常消耗掉一截，日志里留下一个无法对应预设语音的时间点；它没有给出答案，却让林默不得不把书留在桌上。

于是第一章留下的不是“这本书会说话”的结论，而是一项具体而麻烦的新生活：书还没有归还，声音也没有公开，林默和唐栀之间原本熟练的互相帮忙被划出了一条细缝。更深的问题从这条细缝里长出来——那句话究竟来自书曾经听过的什么，还是来自某个被人动过的设备记录；在答案查清以前，谁有权让它再说一次。
