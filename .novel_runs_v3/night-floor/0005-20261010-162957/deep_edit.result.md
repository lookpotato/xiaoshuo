# 第 5 章 四点以前

周寻把梯子靠在二楼墙上，先拧下灯罩里的两颗螺丝。刘桂芳在下面扶着梯脚，手里还拎着一把空心菜。菜贩给她塞的塑料袋太薄，一截菜梗从袋底戳出来，水滴在周寻鞋面上。

“你扶一边就行，”周寻说，“先把菜拿回去。”

“拿回去还得下来。你那梯子站得比你稳？”

灯泡是新的，接线处却有一段胶布发硬，翘起了角。周寻关了楼梯灯那路闸，拿测电笔碰过，才去拆线。刘桂芳见灯灭了，抬头看一眼手机。屏幕亮着，三点十二分。

“陈姐说四点前打。”她说。

“上午不是发照片来了？”

“那张是叫他们先别赶我。写错我的那张哪儿来的，还没说呢。”

周寻把旧胶布卷进掌心，没接话。隔着一层楼，六零三拆板的声音停了，换成师傅拖动木板的摩擦声。他一会儿还得上去看断开的回路，灯线弄好以前，谁下楼都得扶着墙。

楼梯口传来箱轮的响动。老胡的外孙从上面下来，箱子比早晨扁了些，轮子还是在每级台阶上磕。老胡跟在后面，手往拉杆上伸了两回，年轻人都没松。

“往左边靠靠。”刘桂芳把菜贴在腿边，腾出扶手，“灯断了，脚下慢点。”

老胡先扶住梯子另一只脚，让年轻人过去。外孙说了声谢谢，老胡问：“面试还行？”

“叫我等电话。”

“那晚上……”

“晚上回来拿充电器。”年轻人把箱子提过最后两级，没说住不住。老胡也不追，下去替他推开那扇总要卡一下的大门。门在他们身后合拢，刘桂芳才松开扶梯的手，拿菜袋朝梯子指了指：“你快下来，我手都麻了。”

“已经好了。”周寻把灯罩装回去，下来合闸。刘桂芳试着拍了两下手，灯没亮，脸色一沉。周寻按了开关，灯亮起来：“声控头还要换，线先接牢了。今晚走这段，按开关。”

他把拆下的旧胶布塞进工具袋，手机就响了。六零三换线师傅说，板子下面那段线已经发黑，今天先不通电；明早能带新线来，下午接完还得测，今晚肯定住不了。周寻让他把这话发进三人群。电话刚挂，田小雨的消息跟着进来：蒋福安说床垫晾晾或许能用。

“他看过床垫没有？”刘桂芳问。

“小雨叫他去看了。”周寻打完字，把手机揣回去，“我上去一趟。”

“去吧。我自己会接电话。”

周寻走了两级又回头。刘桂芳以为他还要嘱咐什么，他却只把梯子挪到墙边，给人让出整条楼梯。

三点半，唐曼拎着卷尺从上面下来。她的裤腿蹭了墙灰，手里那张现场记录纸折出几道印。她在二楼停下，要量这一段楼梯净宽，刘桂芳替她扶住卷尺一头。

“你们那个表，跟陈姐拿的不是一张吧？”刘桂芳问。

“不是。这张记楼梯和门。早上您开门那一笔，我补在昨夜的记录后头了。”

楼上有人听见“开门”，隔着栏杆问：“二零二不是改过来了吗？”

刘桂芳松了卷尺。唐曼先把尺子收住，免得弹到人，才说：“执行组那页写了暂停。原来那张还在查。”

那人哦了一声，又问八楼能不能看。唐曼把卷尺横放在手心：“七楼以上还限行。您要下楼，先过。”那人本来站着听热闹，见她真让路，只好扶栏杆往下走。

刘桂芳等脚步远了才说：“你说得比我清楚。我一张嘴，人家就当我怕腾房。”

唐曼把数写下，笔尖停了一下：“我也只能说我记过的。”

刘桂芳替她托着记录纸，等她写完才松手。回屋后，她把菜浸进盆里，摘掉黄叶，手机放在水池上方的干台面。水龙头关了几次，她才听清铃响。三点四十六分。

陈姐那边有汽车喇叭声。她说刚送完另一家的材料，回街道翻了登记流转簿。

“原表呢？”刘桂芳问。

“没在街道。簿上有移交区档案保管室的箱号，还有日期。那边今天受理调阅了，明天下午才给查阅时间。”

刘桂芳拿起零钱本，翻到空白页：“箱号你慢点说。”

陈姐念了一遍。刘桂芳写到一半，笔尖被菜汁洇过的纸绊住。她抽一张干纸垫着，让陈姐把后几个数字重念，又记下移交日期。

“写错的那个人，簿上有名字没有？”

“我手边找到一张转抄登记。二零二那行就是‘已退出’，签名太潦草，我现在认不准是谁写的。得等原表调出来对。”

刘桂芳把笔搁在本子上：“那明天查的时候，他们手里那张还算不算暂停？”

“上午给您的那页有签字，没撤。”陈姐那边静了静，像是翻纸，“我刚又跟执行组核了一次，今天的交接记录里也写了二零二现居异议。明天原表查到哪一步，我再告诉您该找谁更正。”

“别光告诉我。”刘桂芳说，“他们下周来，手里拿哪张，你也得问。”

电话那边安静了一下。陈姐说：“这句我记下。现在我不能跟您说，所有副本都改了。”

“我也没叫你现在说。”刘桂芳看着盆里浮着的黄叶，“箱号，还有你刚问执行组的时间，发我一条。我照着留。”

陈姐应了。挂断后消息很快到了，末尾还有“明日调阅后回复”。刘桂芳把回执从零钱本里抽出来，压在那页新记的箱号上。铁盒就在桌边，她看见盒盖没扣紧，伸手扣好，没翻里头的纸。

楼上又响起脚步。周寻下来时胳膊上沾着木屑。刘桂芳朝楼上看了一眼：“小雨她们今晚还是回不来？”

“回不来。蒋福安看过床垫了，今晚再付一晚旅馆费。明天线换完、测完，再谈回屋。”

“小雨肯了？”

“她在群里说，测完给她看结果。”周寻把工具袋往肩上提了提，“陈姐电话来了？”

“来了。”刘桂芳把手机递给他，只让他看箱号那条，“我这个字写得像不像八？”

周寻对着短信看了看，在她写的那个数字旁轻轻补了一笔。她把手机拿回来，没让他往上翻聊天记录。

“灯晚上还会灭吗？”她问。

“接头不会再松。声控头我明天换，今晚过这段按开关。”

刘桂芳从零钱本里数出两个硬币，放在他工具袋边：“灯泡的钱还差你两块。别又说下回。”

周寻把钱收了。楼下大门一响，老胡独自回来，手里多了一卷透明胶带。他把转角处那张松开的“请勿堆物”纸重新贴平，贴完站了一会儿，才往自己屋里走。

刘桂芳端着菜盆回厨房，手机仍放在能听见铃声的地方。她关水时，二楼的灯没有立刻亮；她摸到开关按下去，楼梯从脚边亮到上一层。
