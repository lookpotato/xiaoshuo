# 图片专用 Chrome 配置与使用

## 这套功能做什么

番茄管理系统写到需要配图的新实体时，会让 `browser_image_worker.py` 打开一个独立的 Google Chrome：把提示词发送给网页生图服务，下载原图到该书自己的 `images/` 目录，然后交回 Codex 做设定一致性和构图验收。

浏览器只负责可替代的“生成图片”；Codex 继续负责读取本地正文、编写精确提示词、肉眼验图、修正错误和维护目录。任何一步不合格都不会降低验收标准，也不会自动改用 Codex `imagegen`。

## 首次配置

1. 安装项目依赖（已经安装可跳过）：

   ```powershell
   python -m pip install -r requirements.txt
   python -m playwright install chromium
   ```

2. 启动图片专用 Chrome：

   ```powershell
   python xiaoshuo --setup-image-browser
   ```

   默认 `proxy_mode` 为 `system`，脚本会自动读取 Windows“设置 → 网络和 Internet → 代理”里的当前用户代理并传给图片专用 Chrome。例如系统代理为 `127.0.0.1:7890` 时，无须再手工填写。

3. 在弹出的 Chrome 中，由你本人登录具有 Plus 会员的 ChatGPT 账号。看到 ChatGPT 首页可以正常发送消息的输入框后保持页面不动；脚本确认控件可用后会保存登录会话并关闭窗口。

4. 自检：

   ```powershell
   python xiaoshuo --check-image-browser
   ```

登录资料只保存在 `%LOCALAPPDATA%\xiaoshuo\image-chatgpt-chrome-profile-v1`，不进入 Git，也不读取或提交密码、Cookie、验证码。它与番茄后台专用 Chrome 完全分开。

配置完成后，仍然使用原来的更新命令：

```powershell
python xiaoshuo 4 --book free-sky
```


## 网页变化后的调整

网页地址、输入框选择器、发送按钮文字和下载按钮文字都在根目录的 `image_browser_config.json` 中。ChatGPT 网页改版后若提示“未找到输入框”或“未找到下载按钮”，先运行自检并按新页面文字修改对应数组，不要通过降低图片质量、跳过核验或启用 Codex 图片后备来绕过。

若你的代理没有写进 Windows 系统代理，可将 `proxy_mode` 改为 `manual`，并把 `proxy_server` 填成类似 `http://127.0.0.1:7890`；要明确直连则使用 `direct`。不要在配置中保存带用户名、密码或 Token 的代理地址。

遇到登录失效、验证码、风控或政策提示时，系统会安全停止。处理完网页提示后重新运行初始化命令，再用原任务的恢复机制继续。
