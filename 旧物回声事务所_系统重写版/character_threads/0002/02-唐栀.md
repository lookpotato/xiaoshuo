# 唐栀私线

- 起点状态：答应孟阿婆先还书，书角已经用固定带压好；昨晚亲耳听见七号叫出林默童年称呼。
- 当前地点：阅览室清点现场，在林默与孟阿婆之间护着书。
- 独立目标：让书完整回到孟阿婆手里，并留下不伤人的夜间使用记录，保存阅览室搬迁前的来处。
- 误解：担心林默一看见缺项就会立刻把书当证物；她判断他会把“核查”越做越深。
- 底线：不翻书、不播放原声、不把亡夫字迹和在世者牵连到公开谈论里。
- 行动：抢先抱走书，挡住林默的手；在清点中从归还箱、台灯插座和标签拼出闭馆后取阅痕迹；向孟阿婆说明只查登记，不放声音。
- 代价：暂时不告诉林默自己在标签背面发现的借阅者首字母，换取孟阿婆同意查册；承担继续整理阅览室的时间压力。
- 下一步：把登记页交给林默，先私下核对首字母对应的人，再决定是否告知。
