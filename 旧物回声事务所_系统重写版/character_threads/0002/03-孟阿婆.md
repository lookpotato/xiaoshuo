# 孟阿婆

- 起点状态：在搬迁中的阅览室等书归还，只关心书角是否修好、书页有没有被动过。
- 当前地点：阅览室归还桌，周围有打包的书箱、旧台灯和晚间登记册。
- 私人目标：拿回未被翻动和播放的旧书，守住不公开丈夫声音的决定。
- 知道与不知道：知道唐栀带书去修过；从唐栀处听见七号说了“小默”和“灯底下，别找”；不知道声音是否像丈夫，也不愿确认。
- 误解：最初把林默的出现理解为又一个想听热闹的人；听到他不播放的承诺后，才把他当成受约束的查修者。
- 阻力与底线：阅览室即将搬迁，书与登记记录都要收好；绝不允许公开丈夫声音，也不允许别人用“像不像”逼她作判断。
- 准备行动：验书、拒绝播放；听完林默实际记录后，决定是否允许查看闭馆后的使用记录。
- 代价：承认书确实曾在闭馆后被带到灯下，等于让旧事多一条可追查的入口。
- 本场后变化：授权一次不翻页、不外放的有限查证，书仍由自己收回保管。
- 离场后动向：保留书，整理晚间登记册，准备决定是否接触对应使用者。
