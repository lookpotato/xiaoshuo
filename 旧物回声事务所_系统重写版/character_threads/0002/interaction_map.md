# 交织记录

1. 林默带录音笔和停机的七号赶到阅览室，想先看书和现场；唐栀从后门出来，直接把书抱离归还箱，改变了他的第一步。
2. 孟阿婆到场后伸手取书，并明确拒绝播放；她的拒绝把“核查证据”从原声复测改成取得许可后的记录核对。
3. 唐栀清点搬迁物品时发现归还箱底的夜间借阅标签，林默看见她把标签压在掌下但没有抢；她的选择保住了登记，也让林默只能询问而不能自行翻查。
4. 林默指出两次回声相隔四十六秒，孟阿婆反问“你要查的是书，还是听见书的人”，迫使他把技术判断和声音归属分开。
5. 唐栀用台灯插座、门锁记录和登记册拼出：书曾在闭馆后被取阅，时间落在两次异常前后；这改变了孟阿婆对“书自己保存录音”的担忧，也没有确认声音身份。
6. 林默拔掉七号播放线，只拍下缺失记录和标签首字母，把原声与七号留在身上；代价是失去当场复测，结果是书安全归还、调查转向夜间使用者。
7. 主角未看见：唐栀把首字母先记在自己的修复单背面，准备核对后再交；孟阿婆把书中手写短线夹回内页。下一章会继续发酵的是“夜间使用者是谁，以及为何留下会触发林默童年称呼的片段”。
