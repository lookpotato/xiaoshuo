# 交织记录

1. 修理间门口，唐栀把“先还书”置于林默的复测冲动之前；林默失去当场播放的机会，跟着她去见孟阿婆。
2. 阅览室门口，孟阿婆先检查书角和封面，再明确拒绝播放丈夫的声音；唐栀的保护从替她挡设备变成让她本人说边界，林默只能改口承诺不碰原声。
3. 孟阿婆允许核对灯、登记和旧播放器时间，林默因此获得有限证据；代价是原声留在设备中，唐栀只拿走去声时间线，双方没有获得声源身份。
4. 纸面登记与旧设备痕迹相邻，显示旧书曾在闭馆后被使用；记录牵涉一个仍在世的常来者，唐栀阻止林默用相似音色指认，林默保留不确定性。
5. 回修理间，七号导出时延迟并留下无指令启动痕迹，随后低电量停机；林默放弃拆机，唐栀接受继续合作但要求共享内容不含原声，下一步转向七号声道和日志。
