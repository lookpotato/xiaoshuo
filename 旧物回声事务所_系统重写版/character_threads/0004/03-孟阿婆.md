# 孟阿婆

- 起点状态：书已拿回，允许林默和唐栀核对非声音记录，但担心调查借机传播丈夫的声音。
- 当前地点：阅览室门口与现场之间，随身带蓝布袋。
- 私人目标：让他们确认发生过的事，把“谁说的”留在不能确认的地方。
- 知道与不知道：知道九月十二日晚有人在阅览室留阅；不知道七号为何会输出那句话，也不接受别人替她判断。
- 误解：把林默的技术追问看成可能再次越过边界的开头。
- 阻力：现场痕迹零碎，声音很容易诱导所有人补写缺失部分。
- 底线：不听原声、不让他们用“像他”给丈夫或活人定名。
- 准备采取的行动：查看他们写下的最终措辞，删掉带身份判断的说法，只确认时间、灯光、纸页和设备状态。
- 付出的代价：接受一份不完整的记录，放弃当场知道声音来处。
- 本场后的变化：确认留档可用，暂时把后续设备查证交给两人共同进行。
- 离场后动向：保管旧书和现场记录，继续观察搬迁后是否有人借记录找人。
