# V3 作者房间生成链

V3 是一次独立的新生成链，不是 V2 的规则扩充，也不覆盖旧作品正文。

## 核心变化

旧流程把大量正确经验放在“写作前要求”和“写作后检查”里，容易生成符合规则但没有生活的正文。V3 把中心换成作者房间：先让人物带着自己的生活、关系债、现实目标和未说出口的顾虑进入场景，再让办事、帮忙、推诿、误会和冲突推动故事。

V3 不要求正文填人物属性表，也不规定中国人必须使用某种句式。它只在生成前提供有限的生活判断，在生成后做一次深层编辑和中国读者读感检查。

## 阶段

1. `author_room`：从作品资料、人物状态、反馈和研究资料中形成这一章的生活判断。
2. `draft`：在新鲜上下文中写正文，不读取读者审稿规则。
3. `deep_edit`：检查人物是否真的在生活和办事，清除作者说明书感，不做表面口语替换。此阶段只读候选稿并返回完整修订稿，程序校验后一次性替换，避免同一文件的多段补丁冲突。
4. `reader`：由陌生中国读者检查现场可信度、关系和对白，不补设定。

这几个阶段是上下文隔离，不是正文结构。正文仍然可以自由发现节奏、顺序和对白。

## 参考文本原则

好小说用于观察人物如何生活、关系如何变化、信息如何从行动里露出；失败小说用于记录翻译腔、功能化人物、过度解释和关系失真。只保存研究结论和自写场景经验，不复制受版权保护的原文，不让某一个作者变成模仿模板。

统一工作台可在系统设置中选择 V2 或 V3；当前默认 V3。V3 的读者检查通过后归档本地章节，暂不上传平台。
