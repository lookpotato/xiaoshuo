# 番茄发布流程（未启用）

本书目前没有独立番茄作品绑定，禁止执行任何浏览器发布操作。

启用前必须同时满足：

1. 用户已在番茄创建《此天任我行》。
2. `publish_config.md` 已填写本书独立 URL、book_id 与 chapter_or_publish_id。
3. 页面作品名与本地书名核验一致。
4. `manager_config.json` 的 mode 已由用户授权改为 `write_then_upload`。
5. 是否直接提交严格服从 `submit_publish`。

启用后沿用根项目固定上传门槛；验证码、登录失效、风控、政策警告或陌生确认框必须停止。
