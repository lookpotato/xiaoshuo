# 第31章 北门只收四号

北侧废热管自己热起来时，段野正把旧铁板压到担架下面。热气带着煤油和药味冒出来，刚够暖过地底人的脚趾。

“这不是回光返照。”老崔用肩膀顶住阀杆，“有水在走。”

段野抬头。修理站北墙后那条旧回水线，就是把热井的水送回炉底的管子。二十年前它给谁续过命没人说得清。它发热，说明城里有人开阀。

“进城。”段野说。

林小满拍了两下黑掉的腕甲：“进个锤子，门都让人切了。四号识别片在你手里，城防闻着味儿就来。”

老崔从湿衣服里摸出薄铁片。上面只剩一个“4”，这是旧时代认维修员的四号识别片，不是钥匙，能让北门旧核验认出维修通路。

“那就走维修通路。”段野把识别片塞进衣襟，“魏平呢？”

“在这儿。”阿图尔拖着伤腿把魏平从门边拽起来。魏平胸口的血已浸透半件衣服，还在往北墙看。

“他想等城防来收。”阿图尔说，“我不让。”

“你先把自己拽直。”白露伸手按住他的膝弯，“腿别撑。撑断了，没人给你换一条。”

阿图尔皱眉：“门要开。”

“你坐下。”

他没立刻坐，视线落到白露手里的空药盒上。白露把他推到墙边：“更不准你浪费血。”

阿图尔终于靠下去：“我想进城，不是留在这里等死。”

她把地底人和管内幸存者放在最里面，把最后一块没湿透的布撕成两半压住他们的腿。

“五个人走，热不够。”她看着段野，“谁掉温，我先停队，不看编号。”

魏平笑了：“北门不会让五个未登记人员进去。”

苏青禾从他袖口里抽走湿交接片。纸上的字泡得只剩几道黑线。

“魏先生，您说得很对。”她把纸贴在他胸口，“您跟我们走。门卫若问，您解释四号回水线为什么无调度单也升温。”

魏平脸色一沉：“你拿一张烂纸——”

“不是烂纸。是您刚才亲口说过的反灌风险。”苏青禾看着他，“声音没了，嘴还在。您可以继续说。”

“我没确认。”

“好。我会把‘没确认’也记上。”

段野听见北墙里传来咚的一声。不是敲击，是管子受热后的闷响，黑水开始往上冒。

“老崔，阀能不能关？”

“能。”老崔看着阀杆，“关了，北边那帮人今晚没热。不开，水再涨一尺，咱们全得泡。”

“你选。”

老崔的手指蹭过阀杆上的旧焊痕。他以前见过这道缝，二十年前北线塌炉那会儿，阀门就是从这里被焊死的。

“不关。”他说，“水往城里走，至少有人能摸到热。”

白露抬眼：“那我们怎么过？”

“从北门。俺给这条管留个小口，水不冲站，热还在走。”

老崔把半截扁铁塞进阀座。扁铁一压，热水从接口喷出，浇在他左手上，扳手也掉进水里。

“老崔！”林小满扑过去。

“别碰！”老崔一声吼，“这口气还没稳。”

林小满收住脚，转而把担架轮子往门口推：“那我推人。你要是敢昏，我就把你也绑上去。”

段野把黑锅旁边仅剩的两升废油泼在旧焊车履带轴上。黑锅没燃料不能启动，可履带还能被拖着转。五副担架挂上拖架，阿图尔用废铁钩扣住最后一副。

“这一壶油，原本够黑锅挪三百米。”段野说。

“那就别让它打滑。”

门外传来城防扩音：“404修理站，交出未登记人员与四号识别片，北门准许单人核验。”

阿图尔撑着墙站起来：“单人进去，其他人留外面。”

段野把识别片拍在自己胸口：“他们只收一个编号。”

林小满抢道：“那就让四号先进去。人不是编号，片子是。”

段野看她：“片子进去了，谁给咱们开门？”

“我来。”她蹲下拆开旧拖架的卡扣，“识别片给城防，冷线从管底绕过去。林秋那边还会有一口气，够我找门里的接点。”

“腕甲没电了。”白露说。

“手没废。”林小满把烫伤的手指插进管道外壳裂缝，“莫慌。”

段野一把抓住她：“你要是把手卡里，咱们得拖六个人。”

她瞪他：“所以你别松。松了才真拖不动。”

苏青禾把识别片从段野手里拿走，递给魏平：“魏先生，您走前面。”

魏平没接：“我受伤了。”

“您还能说话，暂时不影响核验。”苏青禾仍旧客气，“进去以后我会把您交给城务厅。账不会漏。”

魏平盯着她，忽然抬脚踢向地上的拖架。

阿图尔比他更快，身体撞过来，把他压在泥水里。旧腿刚止住的血又开了。

“别动我的人。”阿图尔咬着牙，“你可以坏，但不要在我面前坏。”

魏平挣扎：“你们知道四号后面是什么吗？是回收井！里面的人出来，北荒要少三天热！”

“少三天，还是你们想扣三天？”苏青禾问。

魏平闭嘴。

段野抓住拖架前端往北门挪。废油只让履带转了半圈，铁轮便卡住。林小满从管壁抠出细铜线，绕到拖架轴上，借热水震动推开卡死的轮齿。

“往左！”她喊，“左边那块砖，别压线！”

段野改了半步。拖架擦过砖角，五副担架一起晃动。管内幸存者伸手压住地底人的肩，没让他的腿撞上铁栏。

“四号。”地底人忽然开口。

他把手按在胸前，指了指识别片，又指向北门。

“你要先进？”段野问。

地底人摇头，指向后方被水泥封住的地面。

“后头还有人。”管内幸存者喘着说。

段野回头看修理站。北墙裂口张着，热水正往城里钻。全开会被水压掏空；关上，北区的人今晚就冻在门外。

“先把四号送进城。”段野说。

林小满抬头：“段哥？”

“识别片进城，不等于人进去。”他把铁片塞进苏青禾掌心，“苏姐，你拿这个，进门先把核验拖住。阿图尔，守住魏平。白露，你带伤员贴右墙。老崔——”

“俺留管。”

“留得住？”

“中。”老崔用烫伤的手重新按住扁铁，“门开之前，水不进站。”

北门的旧核验灯亮了。苏青禾举起四号识别片，城防的切割臂随即停住。

“维修员四号，报姓名。”门内传出机械女声。

苏青禾看了眼段野，把识别片贴上铁门。

“四号不报姓名。”她说，“报欠账。”

铁门里响起一串老旧齿轮声。门缝开了拳头宽，冷风和热气同时冲出来。

门内的屏幕闪过一行红字：四号已入城，后方回水人员不得放行。

林小满手下的铜线猛地绷紧。管道深处，林秋终于挤出一声极轻的气音。

“小满……别进门。”

“姐？”林小满抬头。

北门里面，贴着门缝的热气里，传来第二个女人的敲门声。

两短。

一长。

和林秋一模一样。

老崔按住阀杆的手开始发抖：“这不是她。”

段野看见门内地面上，正有一串湿脚印从核验台往北侧走。脚印没有人跟着，却一只一只往前落。

“门里有人。”白露说。

苏青禾把识别片卡进门缝：“现在不是四号进不进去的问题了。”

她回头看向段野：“是四号放进来的，究竟哪一个。”
