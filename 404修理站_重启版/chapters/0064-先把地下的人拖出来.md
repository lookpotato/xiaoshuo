# 第64章 先把地下的人拖出来

地底那一下敲击，贴着404修理站的炉脚又响了一遍。

三下，停一下。

段野蹲在院门废墟边，先看黑锅。断履带绷在机甲底盘上，油已经不流了；再看白露搭的热槽，水面只剩一层薄汽。秦砚、米沙和泵底证人的手腕泡在里面，谁的指头都没动。

“先回站。”段野捏紧交接片，“人要是冻死在门口，咱查出他祖宗也白搭。”

“门没了，黑锅也走不了。”老崔说。

“那就拖。站又不是长腿，不能自己跑。”

阿图尔已经把黑锅驾驶舱里的座椅锁销掰了出来。那是一枚拇指粗的旧钢销，原本卡着座椅，防止机甲撞击时把驾驶员甩出去。现在他把钢销穿进断履带，给黑锅临时做了拖钩。

“你拆这个，下一撞我会飞。”

“那就不要撞。”

“你说得轻巧。”林小满抢过话，蹲在炉脚旁，“段哥，下面又响了。不是从阀井传来的，锅炉间在跟它对。”

她把腕甲翻开，里面只剩一块裂掉的铜片。林秋的回波已经断了，可她没扔。她从废表里撬出一粒米大的电池，夹在铜片两端。

“莫慌，就亮一下。”

电池烧红，铜片发出细响。炉脚下的敲击立刻偏向锅炉间。

“看见没？它听见电了。”林小满咬牙拔掉电池，“现在没了。”

“听见电，不等于听见你姐。”白露按住米沙胸口，“别把这俩混一块儿。”

林小满瞪她，嘴唇动了动，没顶回去。

苏青禾把焦黑纸角塞进一只扁铁盒。盒子本来装螺丝，里面铺着最后一小片干燥纸。她用半枚维修章的尖角把纸压平，纸上那个“守成”和箭头露出来。

“段野，证据不能跟着热气走。”

“能不能先说人话？”

“意思是，您别把它攥在手心里。您手一出汗，剩下的字也没了。”

段野把手收回来：“行，您这账房骂人挺省材料。”

“谢谢。夸奖我记账。”

老崔没笑。他把最后一段扁铁塞进院墙裂缝，弯成一个能拆的三角撑架。

“锅炉间地板下面有旧检修口。俺以前见过。”

段野转头：“以前啥时候？”

“二十年前。”

“你咋不早说？”

“你也没早问。”

老崔把撑架往下一砸，地板铁皮裂开。热汽从缝里顶上来，带着一股陈油和湿铁味。下面不是空洞，像有东西贴着铁板呼吸。

白露立刻把热槽边的最后一个药瓶塞拔出来，塞进裂开的分流口。热水总算不往雪里漏。

“我只撑五分钟。”她说，“五分钟后，伤员先凉，还是下面的人先凉，你们自己选。”

“不用选。”段野把黑锅拖钩扣上地板吊环，“一起拖出来。”

阿图尔拽住履带，左腿刚发力便一软。米沙在热槽旁敲了三下，停一下，又敲了一下。

“不是三短一长。”他喘着说，“他多敲了一下。”

“地下人在改口。”苏青禾说。

“不是。”米沙抬眼，“他在问我们，站里还有没有人记得第四班。”

段野没听懂：“Q-17不是交接号吗？”

“Q是班组，17是这一轮交接。第四班是人。”米沙胸口又渗出血，“以前我哥——”

阿图尔一把捂住他的嘴：“不要说编号。”

“我没说。”

“你刚才已经说了。”

“那是你听见了。”

两人僵住。阿图尔松手，把自己的围巾压到米沙伤口上。那围巾原本裹在驾驶环外，沾着黑油，拆下来后，驾驶环的金属边立刻裂开。

“兄弟，撑住。”他说，“编号不会跑，人会。”

段野听见锅炉间里传来一声拖铁声。

不是敲击，是有人在里面拖东西。

“老崔，撑架能不能拆？”

“能。”

“那就给我顶住。”

老崔把肩膀压上扁铁：“中，俺来。门开了别焊，听见没？”

“听见了。”

段野左手拧动吊环。黑锅的残架被一点点拉直，断履带和地板吊环同时发出尖响。阿图尔咬住牙拖，血从裤脚滴进油冰里。黑锅终于往前挪了一寸。

地下的东西也往后退了一寸。

“它在躲！”林小满扑到裂缝边，“段野，别硬拖！这下面连着热管，扯断了，锅炉间先灌汽！”

她把废表外壳贴到铁板上，听了一下：“右边。右边有空腔，左边是管。往右拽！”

“阿图尔，听她的！”

“我听见。”

他改了方向。黑锅残架擦着地板，终于把铁皮撬开半扇。

一只戴旧阀钩的手从下面伸出来，指甲缝里全是黑油。那只手没抓段野，先摸到吊环，再摸了摸断履带。

“他在验东西。”苏青禾低声说。

维克多从门外走进来，手里只剩半截回传箱。他把最后一枚身份芯片拔出来，插进锅炉间旁边的旧线盒。这个旧线盒是旧中继盒，只负责把地下声音接到别处，不负责供热；芯片一进去，远处炮声立刻从404北墙偏向旧水仓。

“我只能断它一次。”维克多说，“之后总局会知道是我。”

苏青禾看了他一眼：“您终于说了句不用核对的实话。”

“我一直很诚实。”

“那您以前的账，回头慢慢算。”

铁皮下的人突然敲了两下。

林小满脸色变了：“不是三短一长。他让我们停。”

段野没停，手指已经伸进缝里：“人就在底下，停啥？”

那只手猛地扣住他的手腕。

热汽炸开，段野右肩像被铁钳咬住，整个人跪下。地下人借着这一拽，把一张薄薄的名单拖到缝边。纸上只有四个位置，前三个被黑油抹掉，第四个还空着。

米沙看了一眼，呼吸突然乱了：“回炉不是口令。”

“那是啥？”段野问。

地下人终于开口，声音贴着铁板，沙得像在油桶里泡过。

“是名单。”

他把名单往外推，最后一格慢慢浮出一行编号。

Q-17，第四班：404-零。

段野盯着那个“零”，手腕上的血顺着名单边缘往下滴。

锅炉间深处，另一个人轻轻敲了一下。

不是求援。

像有人在站里，已经替他们报了班。
