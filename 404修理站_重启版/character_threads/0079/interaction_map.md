# 交织表

1. 段野压住落笔槽，替签人改接第二笔逼他松手；苏青禾反插第二见证铁板，迫使对方的接线顺序露出，结果是“先写伤员”的路线被卡住，但铁板再折一角。
2. 阿图尔用旧驾驶齿片卡住无人维修车，米沙用敲击纠正他的站位；车轮不再拖门，却把底部回压顶进侧门，结果队伍获得低位总闸位置，也失去半齿和一段绳。
3. 林小满沿铜线反追一短一长的声音，白露把伤员移到担架扣组成的隔热位；林小满烧断借声分叉，白露的担架扣熔断，结果林秋名字暂未落笔，秦砚固定重新松开。
4. 老崔把检修架改成可拆撑，秦砚用两短敲击报出回压反冲；段野据此只关落笔支线、不关北区热阀，结果北区热灯恢复一排，主炉转写“原始维修人”。
5. 老四指出回水口并承认自己曾守过闸，替签人遗落半张旧维修单；队伍拿到“林秋-北线旧水仓”的残码，但替签人沿回水口逃走。
