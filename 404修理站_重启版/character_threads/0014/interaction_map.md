# 第14章人物交织表

1. 炮口锁定救援廊时，阿图尔拆下白色机甲膝部反光片制造假热源，把炮口引向门外；结果识别柱过载，队伍得到四分钟搬运窗口，但阿图尔左腿彻底失去支撑。
2. 段野想用最后门楔继续顶门，老崔却拆走门楔和医疗桌脚改造低压热车，迫使段野从“守门”改成“拖人”；结果热车能动，门框失去最后承重，炮击一来全员必须撤。
3. 白露拒绝先搬门内女人，先按伤情把三名伤员固定在热车上；门内女人因此误判她会舍弃自己，反而截断魏平递出的假坐标并交出真正方向针。
4. 林小满要拔热源芯追姐姐，门内女人按住她；苏青绫则把魏平的回执接进残铜扣，逼出“旧中继站在东侧”的口供。林小满改用单向追踪，魏平的错误楼层触发反向定位，暴露城防集结点。
5. 段野拖车离开时让魏平留下，苏青绫烧掉最后回执副本换取四分钟；魏平失去可辩解的原始记录，只能带着错误坐标回城，三号城旧中继站成为双方同时奔向的地点。
