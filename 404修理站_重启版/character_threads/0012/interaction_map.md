# 交织表

1. 门外炮口锁定热源芯，阿图尔先卸下白色机甲肩甲塞进门框，再钻入盲区扳偏炮管；炮弹没有打穿救援廊，却让他的旧身份暴露给魏平。段野因此获得短暂操作时间，白露趁机把伤员往炉侧安全位移。
2. 魏平趁炮击撬动红灯线，想把芯的信号送出；苏青禾把铜扣接入线路，回执反向记录魏平的强制回收指令。魏平失去解释权，苏青禾的铜扣和名单证据同时损毁。
3. 门内女人压住备用热源芯，拒绝林小满拔取；林小满没有抢芯，改用最后铜夹接旧中继线，热源短脉冲转去门外识别系统，城防机甲短时失明。她救了门内人和伤员，却让姐姐信号再次中断。
4. 老崔拆回收阀，段野用旧工牌顶住炉座，白露用残余金属固定门内女人；旁路把热量送进救援廊，三名伤员脱离濒死状态，但旧炉保护层裂开，众人必须追查中继线落点。

## 可见结果与后续

- 可见：城防未能夺芯，炮击暂退，救援廊获得短时热量；阿图尔身份暴露，魏平的强制回收指令留在红灯回执里。
- 不可见：门内女人知道姐姐神经印记已接入三号城旧中继线；段野和读者只从她交出的烧焦线路判断出这一方向。
