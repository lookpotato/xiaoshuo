# 交织记录

1. 林小满先听出蓝灯线路中“少两拍”的声音，段野因此没有让她冲入门内；她把铜线转接到锁线，门叶弹开，迫使老崔改撑回水侧，伤员通道得以保留。
2. 阿图尔用断齿卡住替签人的蓝带，替签人无法继续独自压杆；段野借这个停顿进入检修沟，双方从争夺签字转为争夺手动杆和铁盒。
3. 白露选择先拖秦砚过门，米沙抓住担架脚，老四同时抓回水柄；三人的动作互相补住热压空档，秦砚没有在搏斗时掉压，但米沙和阿图尔伤势加重。
4. 苏青禾打开铁盒，林小满把“未登记”线头送回空槽；落笔槽暂时失去可写的接班人，替签人的假账被打断，蓝灯红线却暴露缺齿车辆已出仓。
5. 替签人逃向门深处，段野将他拖回并保留其作为路线证人；林秋真节拍随车辆远去，队伍的下一步从找门内落点改为追查主炉外侧车辆。
