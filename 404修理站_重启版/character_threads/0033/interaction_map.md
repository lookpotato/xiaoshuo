# 第33章 interaction_map

1. 段野用左肩顶住北门，苏青禾把拒收记录接入扩音器；门内复核被迫延长到两分钟，但城防锁定了队伍位置。
2. 魏平被阿图尔推到井控杆前，魏平开启下层门却暗写回收指令；苏青禾截下记录，阿图尔因此失去继续站立的力气。
3. 林小满拆冷管铜片给井灯供电，湿脚印停在下层门前；管内幸存者刮出导流槽，队伍确认井下女人不是回声而是活人。
4. 老崔放出最后热水冲开井门密封，白露拆保温管把伤员分到热风口；阀座裂开、热量耗尽，伤员获得一次下井机会。
5. 地底人用四号口令回敲，井下女人伸手抓住绳端；段野带人拖她上来，却发现她的胸牌被系统标成“候补维修员”，并听见林秋信号来自城内回收井。
