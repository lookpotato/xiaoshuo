# 第44章交互图

1. 阿图尔抠出墙灯后的弟弟编号载体→苏青禾用纸灰对照侧壁刻度，确认编号是转运标签而非活体定位→阿图尔从追弟弟改为追转运方向，队伍失去一条直达判断。
2. 秦砚指出热闸侧门和泄压口→老崔按旧经验卡住轨舌，却发现结构改过→段野接手泄压杆，老崔承认记忆不全，热水暂未灌轨但残钢报废。
3. 林小满反接焦黑线头与第四号点名线→黑牌停止逐人上报，林秋残线留下人工台后方坐标→林小满掌心裂开，段野无法再靠黑牌判断安全路线。
4. 白露拆滑板侧板固定秦砚→秦砚被迫停止指路并短暂昏厥→人工台虽被打开，医疗优先级与证据优先级发生冲突。
5. 罗沉用残余手印打开侧门并说出“先写人名再补理由”→苏青禾发现人工台上已有提前写好的名单→段野抢下钥匙但发现第一行是林秋，热闸开始向城内泄压。

读者未见行动：城下值守端已将点名结果同步给维克多；维克多尚未现身，人工台的预填名单来自更早的人工接管。
