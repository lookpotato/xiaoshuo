# 第25章交织行动图

1. 段野追第四下敲击，管内人先扣住泄压杆不让众人靠近；白露把伤员往回拖，段野因此必须在救人和取证之间先拆掉阀门卡齿。
2. 林小满把冷备份线贴到管壁，听见林秋只回两短一长；她误判声音来自管内，管内人的第三次敲击却改了她的判断，冷备份线因此冻裂，林秋暂时失联。
3. 魏平偷扯黑标签遮追踪灯，阿图尔抢走标签压进积水里，换来一段黑暗；魏平被迫交出城防备用灯，却暗中记下了管内人的旧称。
4. 炉下男人趁黑摸泄压杆逼停队伍，老崔用焊枪残柄敲出阀盒位置；苏青禾用熔损 V-07 黄铜牌刮开封蜡，取出交接记录片，牌子再损一角。
5. 段野用断扳手卡住回弹齿，白露拆内衬给管内人止血并带出伤员；管内人交出记录片后获救，老崔听见自己的旧称，承认旧交接不止段守成一人，责任链继续追向修理站内部。
