# 第5章 状态回写

- 段野：阀井夹层出口；右手新伤、体力透支；黑锅承力骨架拆空；救出三人但得知父亲可能与北线救援签字有关；与老崔从争执转为共同扛门；承诺查明旧账；下一步带队守住红线并追查签字记录。
- 林小满：阀井控制台；动力匣剩余电量耗尽，姐姐神经印记沉默但未确认消失；掌握“北线旧热站下层”的半截坐标；与段野争吵仍在但开始主动交付判断；下一步拆匣读取坐标。
- 阿图尔：下层平台；左腿旧伤恶化，持有被水泡开的半张记录；确认七号救援组与弟弟编号相关；不再把魏平当作单纯执行员；下一步逼问并寻找弟弟线索。
- 老崔：阀井门口；焊枪喷嘴报废，左手裂伤；确认旧焊缝属于人为封存；与段野共同打开夹层；下一步寻找替代喷嘴并面对当年封门责任。
- 白露：临时救护点；唯一抗冻针用掉，止血带库存减少；确认第三人仍有意识；公开要求按伤情而非评级救治；下一步建立伤员和药品公开账。
- 魏平：阀井下层被压制；执行记录受损，旧记录残页被阿图尔夺走；过载线圈失效；认为第三人的身份可成为反制筹码；下一步利用旧签字追责段野一行。
