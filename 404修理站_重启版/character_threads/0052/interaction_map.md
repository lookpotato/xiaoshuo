# 第52章交织行动

1. 白露先按伤员需求定下“两桶，先给秦砚”，段野据此把取水量锁死；阿图尔仍想进监察车找弟弟记录，白露拦住他的伤腿，迫使他把取水和活命排在发讯息前。
2. 罗沉主动摸进监察车接线盒，触发红线并把压力推向融雪塔；维克多及时识别城防定位，段野改为先卸右侧压力，老崔借林小满的薄铁松阀，避免第三阀把水和人一起喷出。
3. 林小满认出一短两长是姐姐“别开第三阀”的警告，改变了段野原本的排压选择；阿图尔把最后电池给泵点火，老崔据水声找到回水锁，林小满再贴灯线显出“魏平”，让罗沉不得不说出旧焊责任。
4. 苏青禾带罗沉查原始记录，监察车自燃时罗沉先拖她离开并喊她抢账纸；她保住红色编号，维克多用失效监察牌读出“主端三号热站”，证据因此从罗沉口供变成可核对的调度记录。
5. 城防机甲逼近后，段野、老崔、林小满和阿图尔共同压住阀杆与门轨，白露接住净水；泵恢复、两桶水到手，但阿图尔失去电池、林小满掌心出血、罗沉背部受伤，维克多确认主端仍在召回资源。
