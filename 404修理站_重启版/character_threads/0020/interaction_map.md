# 交织行动图

1. 城防机甲从东侧检修井压入时，阿图尔把反光片折向承重柱，机甲撞偏；段野因此获得一条九秒撤退缝隙，但阿图尔失去最后的反光片。
2. 白露把暖槽余热分进三只金属水壶，保住重伤员；老崔随即拆护片做挡板，牺牲后墙承重，把这条热路变成撤退通道。
3. 林小满用冷启动电容给主线打脉冲，林秋以两短一长回应并烧掉端口；林小满拿到北侧定位，却失去黑锅下一次启动能力。
4. 苏青禾公开魏平的东侧口供，魏平咬断识别扣触发封锁；炉下男人夺走半截铁扣，迫使段野放弃修理站后门，队伍改走废热站。
5. 段野拒绝用伤员换路，消耗一枚电池芯制造热幕并带人撤出；炉下男人因此暂时承认他没有重走段守成的路，却把名单最后一页藏处设为下一场冲突。
