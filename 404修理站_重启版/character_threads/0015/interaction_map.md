# 交织记录

1. 段野把热车前端顶进窄门，老崔却拆下回压阀弹簧改做撬杆；段野因此放弃单独硬顶，老崔获得开锁角度，门没有被焊死，结果会影响回站后的热管维修。
2. 林小满把烧裂铜扣接入压力表，苏青禾借回压重复魏平的路线口供；魏平拔线失败，反而让西侧城防听见矛盾口令，这个行动未被段野完整看见，但结果固定了证据。
3. 阿图尔离开热车后制造假活体脉冲，城防炮口被引向空井；白露趁窗口把三名伤员先送过门，阿图尔的行动改变了白露的撤离顺序，代价是旧机甲拖架报废。
4. 门内女人用血按住自毁锁并说出段守成维修口令前半句，段野因此允许老崔继续拆锁；门开了，但女人失血加重且段野听见“段守成”仍在旧线中的回声。
