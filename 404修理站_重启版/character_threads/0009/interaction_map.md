# 0009 人物交织记录

1. 段野用黑锅残架顶住院门，魏平却对门外报出“站内资产”；苏青禾截住回收凭证，要求他写清交付对象。魏平的措辞被固定成证据，门外机甲暂时不能合法进院，但他获得了靠近旧收货台的机会。
2. 白露把医疗桌蓄热板拆下压在胸伤者身上，主动夺走站内热量；老崔因此不能用蓄热板稳定旧热管，只能拆站门承重片做管夹。伤员保住一轮清醒，院门结构却更脆，段野被迫在守门和供热之间重新分配人手。
3. 林小满用最后一只小电容给动力匣做短脉冲，姐姐信号从“仓”跳出“七码门”；她没有等段野安排，直接把信号接到旧维修台。魏平听见关键词后试图靠近，阿图尔从外墙把他逼回收货台。
4. 阿图尔滚下七号车车轴撞断门外机甲履带，门外炮口失去贴门角度；代价是最后可用轴承报废，且他的弟弟编号前两位出现在残机甲识别板上。这个发现把他的私人追查和修理站旧检修口绑在一起。
5. 老崔刮开旧焊缝，露出“崔/七码”的双重焊印；他承认自己不是唯一签字者。段野决定开门，苏青禾把半张名单撕下一角写拒收联，保住责任链却损失名单证据；魏平则趁所有人看向焊印时摸向门锁。
6. 白露以“伤员先醒、再谈交付”压住争执，三名伤员短暂恢复意识；门外回收队被迫撤到热管射程外，但旧热管只撑过一轮。第七码门内传出第二次敲击，且敲击节奏和林小满姐姐信号一致，形成下一章的公开危机。
