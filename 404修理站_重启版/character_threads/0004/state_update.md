# 第4章 状态回写

- 段野：用黑锅残余骨架顶住阀井铁栅，接受分工后带队进入下层；黑锅彻底失去移动能力，右臂旧伤加重；下一步核对下层名单。
- 林小满：用动力匣追踪回路并改接阀井照明，动力匣电量下降、姐姐信号只剩半句；下一步查姐姐与下层人员的关系。
- 阿图尔：从魏平处夺到被水汽浸坏的另一半记录，左腿彻底无法承重；下一步依据残缺编号寻找弟弟。
- 老崔：拆掉第二道旧焊封，确认旧焊缝内有救援标记；焊枪喷嘴报废，消耗一壶净水，左手出血加重；下一步辨认标记来源。
- 魏平：备用旁路和控制台被过载蒸汽破坏，封锁失效，记录受潮；退路受阻，仍试图销毁旧资产记录。
- 资源变化：消耗两截焊条、一壶净水、动力匣部分电量和黑锅最后承力结构；获得两名幸存者、半张受损识别记录和一条旧救援标记。
- 关系变化：段野把承重点交给老崔和林小满；阿图尔不再把魏平当普通执行员；老崔的旧罪从猜测变成可触摸的焊缝证据。
