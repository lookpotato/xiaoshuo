# 第32章 interaction_map

1. 苏青禾把四号识别片贴进核验槽，门内只显示“后方回水人员不得放行”；她立刻把红字接入扩音器，迫使门内值守从机械拒收变成公开回应，魏平的反咬计划被迫提前。
2. 魏平抢扩音器时踢翻拖架，阿图尔用伤腿压住他，废铁钩因此折断；阿图尔失血加重，但伤员没有滑入冷水，白露得以拆担架支门。
3. 老崔缩小回水阀口，热水压力下降，段野才有时间顶住门缝；阀座漏水后门缝变窄，林小满只能用灼伤的手从底部接线，接出第二声音不是单纯回声而是活人。
4. 地底人拒绝单独核验并敲门，管内幸存者刮开门槛冻泥露出脚印起点；段野据此把“门里有人”改成可验证的现场事实，决定让整支队伍暂留门口。
5. 段野承受门轴回弹，拿自己的伤势换来门缝不闭；苏青禾录下门内值守承认“只收四号”，北门被迫给出三分钟人工复核窗口，下一步指向北侧医疗井。
