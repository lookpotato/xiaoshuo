# 第92章人物交织表

1. 段野把林秋旧钥匙插进四号回水门的缺槽，周栓先按住闸片不让门开；苏青禾从钥匙磨痕认出门不是“接班”入口而是热量分配口，迫使周栓说出门后有人被回水压困。结果：段野改为先救人再核对，开门目标从抢线索变成抢出活体。
2. 阿图尔独自用裂开的弟弟驾驶扣卡住缺齿车轮，老崔拆车护板做第二承重点；车没有被主炉拖回，但退路只剩一人侧身通过。结果：阿图尔守住车辆，老崔失去护板，二人的撤退计划互相绑定。
3. 林小满把残铜线贴进门缝，故意回错一拍；主炉立刻复制错误节拍，林秋只回一次短原声指向名单撕裂处。结果：林小满确认声音不是身份凭证，获得门内证据位置，但原声线路再损。
4. 白露把秦砚热位拆成两段，米沙推动担架顶住车轮并按两下停顿报压；秦砚停止让热，周栓被拖到热位边。结果：三名伤员和周栓都撑过开门，代价是热槽再降一格。
5. 段野进入门后撕下错误“接班人”名单，苏青禾用半片读写片压住现场字段；主炉转而点名段野，门后真正接班人的手从阀箱里伸出但没有露脸。结果：本章完成开门救人和保住原声的小胜负，下一章必须核对新证人身份与段野被点名的责任。
