# 交织行动图

1. 白露先将伤员压到右墙、要求开通风缝，改变段野原本守门的优先级；段野因此命令林小满先停炉，并亲自处理回压阀。
2. 林小满拆姐姐线路接排烟风机，造成姐姐信号中断，却让老崔看见风机缺转子；老崔拆下唯一密封圈，风机恢复，三名伤员暂时脱离浓烟。
3. 阿图尔用识别板引炮口，炮口换角度后他用最后一发子弹打掉照明灯并以伤腿卡门；门框因此没有立即塌下，但他失去最后弹药。
4. 魏平寻找墙沟信号线，苏青禾用铜扣封沟、扯出红灯线并将其缠到魏平手腕；魏平被迫承认第二签字人仍活着，却引来门内女人打断供词。
5. 门内女人警告不要触碰备用热源芯，门外扩音器随即要求回收旧热源；所有人的目标从“逃出炉烟”交织为“在炮击中保住热源芯和门内的人”。
