# 交织记录

1. 白露先按脉并把伤员留在冷地，迫使段野承认必须先恢复局部热源；老崔因此砸开检修盖，铜管成为新的资源通道。
2. 林小满从敲击判断林秋在地下，拒绝段野把她留在上面；她接入主线，方向针和铜线的消耗改成双手灼伤与旧炉登记风险。
3. 阿图尔在外侧放置识别灯制造六分钟盲区，魏平因此无法立刻引城防入站；阿图尔转回门边，守住撤退口但失去最后机甲误导机会。
4. 苏青禾夺下魏平的手动确认片并放入蓝光，旧炉听见魏平名字，反过来把“确认”变成全队被点名的威胁；苏青禾保住证据却引发登记。
5. 门内女人主动进入地下炉，林秋才把主线交给林小满；段野获得行动方向，却发现炉下还有多人，地面热量恢复同时带来城防围站。
