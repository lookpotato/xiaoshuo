# 第 0072 章交互地图

1. 段野带着红灯刻片回到404空门，门内用他的声音催开门；白露以伤员体温给出三分钟期限，段野不能再靠个人硬扛，必须先让老崔隔开热路。
2. 老崔拆黑锅最后护板卡住门槛，秦砚用三短一长敲出回压变化；门被卡在半开，热屋保住细热路，但黑锅失去护板，撤退能力再降。
3. 门内女人复现原始节拍，林小满发现门内回声少一拍；苏青禾把交接牌垫在门槛，要求三个人分别留下触碰痕迹，借声片上露出城防蓝漆与半个维修编号。
4. 米沙用旧驾驶节拍拦住阿图尔追门，阿图尔停下并改拉段野；老四在热屋听出门内没有真正伤员的喘法，确认“接班人已进城”是人借线，不是泵房自动回写。
5. 段野用红灯刻片刮断借声支线，林小满烧掉最后绝缘皮完成短路；门内声音断掉，城内旧管却留下林秋的一短一长，指向三号城而非泵房。
