# 第36章交织记录

1. 地底人坚持指出锅炉下回水口，白露因此改变伤员分配，把他和罗沉先拖到暖地；地底人的后方诉求未被解决，白露获得了可控的救治窗口。
2. 老崔拆掉自己以前封过的螺帽，段野递扳手并承担顶壳动作；压力壳送出热量，但裂口倒灌，老崔的旧责任从口头变成眼前故障。
3. 魏平试拉放压杆，苏青禾撞开并把钢片卡入门底；魏平想控制记录的计划反而让城防锁定“内部优先对象”，苏青禾的公开策略制造了新的门压。
4. 林小满接入护腕薄铜，听见林秋“主井入口在站里”的残句；她坚持追问导致铜片烧断，段野改为逼罗沉翻图，二人的目标从追信号转成保住站内选择权。
5. 阿图尔本想让地底人留在暖地，门外切割启动后却拖着伤腿顶短梁；段野让他接壳口，压力壳暂时撑住但短梁和阿图尔的腿同时失去余量。
6. 罗沉被旧图背面的“在站长名下”逼到交出部分信息，却仍捏住最后一页；林秋的警告在门闩断裂前落地，下一步所有人都要面对签字与否。

## 权力与关系核对

- 段野与林小满：临时站长对动力手，但共同救过林秋线；此刻段野有现场决策权，林小满藏着最怕失去的姐姐信号。
- 段野与罗沉：救命者与旧案知情人，段野占行动权，罗沉掌握证据；罗沉以最后一页保命。
- 苏青禾与魏平：账房审记录人，魏平有城防制度权但被押；苏青禾公开施压，魏平想藏“回收完成”的责任。
- 白露与地底人：军医对伤员，白露掌握净水和移动资格；地底人藏着地下仍有活人的判断。
- 阿图尔与魏平：看押者对被押者，阿图尔有身体控制权；魏平藏着反咬计划。
