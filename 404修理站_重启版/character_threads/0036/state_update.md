# 第36章状态回写

- 站内最低热源通过旧回水口恢复，锅水滚开一泡，伤员暂时转到暖地；城防仍在门外。
- 旧压力壳裂穿并倒灌，黑锅残架短梁和一截担架铁条弯裂；门闩断裂，404失去第一道防线。
- 林小满被系统标为内部优先对象，林秋信号只留下“主井入口在站里”和“别让段野签字”。
- 苏青禾的钢片公开了魏平口供，但城防因此完成站内目标确认。

- 段野右肩进一步受压，决定先守站、再核验罗沉最后一页；林小满与他的决策关系变紧，仍互相隐瞒关键信息。
- 白露耗掉半桶净水的大部分，伤员获得短时暖地；阿图尔左腿失力，仍负责魏平与锅炉间。
- 老崔旧封管责任被重新指向，罗沉的最后一页被段野逼到即将公开；地底人获得回水口带路资格。
- 魏平失去控制盒和谈判主动权，准备趁门破反咬；苏青禾证据被磨损但公开动作已不可收回。
