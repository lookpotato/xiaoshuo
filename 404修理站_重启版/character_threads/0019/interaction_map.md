# 第19章人物交织表

1. 段野先用父亲铁扣撬第六舱旧焊缝，门内男人反向锁闸，结果炉压冲回，段野被顶伤但确认舱门不是普通仓门；这条阻拦没有被段野看见的动机是防止全名单登记。
2. 林小满把林秋主线分接到“旁路”（不经过旧炉登记端的临时线路），林秋因此失去主炉屏蔽；第六灯由红转蓝，救出窗口出现，但林秋的位置暴露给城防。
3. 老崔把最后两片焊片换成三路暖槽，白露据此让三名伤员继续取暖；热量保住，焊接资源清零，白露却必须耗掉最后净水清洗门内女人的伤口。
4. 阿图尔用识别灯制造假热源拖住城防，再把魏平的口供接入扩音孔；魏平为自保吐出第二入口，城防因此提前破门，苏青禾获得可追责的录音却失去隐蔽身份。
5. 门内女人以血压住手动闸，炉下男人趁机打开半扇舱门；段野选择先拉活人、后问段守成，改变了炉下男人对他的判断，也让“段守成未回收”责任链进入公开回播。

## 未被主视角看见的后果

- 林秋切断登记端后，旧炉不再替她屏蔽第六舱，城防能沿蓝灯追踪。
- 魏平供出的第二入口不是逃生路，而是城防机甲进站的短路口；下一章会迫使队伍在伤员撤离与名单取证之间再做选择。
