# 第35章交织记录

1. 段野决定回站，白露拆医疗桌蓄热壳垫住最重伤员，结果拖架得以过雪坡，但404站内医疗桌失去保温；白露的行动迫使段野把“先救人”放在追主井之前。
2. 地底人拒绝独走，沿废热沟寻找同伴留下的痕迹，管内幸存者辨出回站门底旧焊号并指出隐藏插口；两人的坚持让队伍改变路线，找到可用的短热路，代价是二人伤势恶化。
3. 阿图尔押魏平撤离，魏平用假口令触发城防频道，苏青禾把这次反应记录在钢片上；魏平没有被主角看见的发送动作继续发酵，苏青禾确认公开账目比求城防复核更有效。
4. 罗沉交出泡烂主井旧图却藏住最后一页，林小满发现图上标出的不是入口而是回站地下接头；她停止追问林秋，先用护腕金属片保护证据，关系从催逼转为共同保管。
5. 老崔撬废热支管，断阀扁铁折断，热路只给三分钟；回站门开后，扩音器报出“404修理站确认”，队伍赢得活人进站，却失去隐蔽和最后一段热量。
