# 第58章交织表

1. 段野重新拔泄压栓制造短窗口，老崔拆下旧支架改焊可脱开撑脚；结果泵底窄缝扩大，段野和阿图尔都获得一次进退机会，但老崔的工具和骨架钢耗尽。
2. 阿图尔先拖米沙，米沙用驾驶环敲出三短一长；林小满据此改接真热线，低热回到救护位，却让自己的腕甲线索再损一层。
3. 白露根据米沙的呼吸把唯一抗冻针给他，同时让秦砚留在人工保温位；苏青禾听见后把录音盒接入回执孔，公开留下“先救活人”的现场声。
4. 维克多打开旧冷却沟偏转炮口，炮控暂时失效；他失去回总局的退路，城防机甲却把责任锁定到他的识别记录上。
5. 段野钻回窄缝托出泵底证人，证人指出老崔认得旧焊缝；老崔被迫承认这不是普通维修事故，下一章的追问从段守成的签字转向当年谁下的焊接命令。
