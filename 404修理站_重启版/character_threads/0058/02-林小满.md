# 林小满

- 起点状态：腕甲残片已裂，真热线暂时断开，秦砚的热量在掉。
- 当前地点：主泵旁的黑霜管线处。
- 独立目标：让热站保留最低供热，同时不让回写节拍重启。
- 知道与不知道：知道黑线的节拍和假线位置；不知道泵底人是否在利用她的线路引导主泵。
- 误解：以为截断回写就能保护所有人，低估了断热对秦砚和北区的即时伤害。
- 底线：不烧掉姐姐留下的线索，不拿秦砚的命换一条漂亮证据。
- 行动：拆下黑锅备用铜片，改接真线并用自身短接稳定节拍。
- 代价：消耗备用铜片和自身腕部灼伤，动力核心线索再少一层保护。
- 本场变化与下一步：暂时恢复低热，但听见泵底仍有第二个节拍；下一步追查节拍来源。
