# 白露

- 起点状态：秦砚和米沙都在胸部受压，手边只有一支抗冻针和少量布料。
- 当前地点：检修门内侧的临时救护位。
- 独立目标：让两名伤员都活过主泵回压，不替任何制度挑一个“更值得救”的人。
- 知道与不知道：知道米沙肺部更危险，知道抗冻针只能给一人；不知道秦砚能撑到何时。
- 误解：一度以为先救米沙会让秦砚失去窗口，后来根据呼吸声重新判断。
- 底线：不把一名伤员说成另一名的代价。
- 行动：先用压迫固定稳住秦砚，再把唯一抗冻针给米沙，最后用热水袋残温分开保温。
- 代价：抗冻针耗尽，秦砚只能靠人工保温，医疗余量归零。
- 本场变化与下一步：米沙脱离危险但秦砚更虚弱；下一步必须找到稳定热源和药品。
