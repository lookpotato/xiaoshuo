# 交互地图

1. 段野拒绝回应窄道里的模仿声音；林小满同时压住动力线，结果主炉不能用段野的节拍继续诱导，林秋的真实节拍只剩一次可辨认回应。
2. 白露关死漏热阀保住伤员，秦砚与米沙改用敲击报压，结果窄道仍有一次热窗，但箱内人和伤员都被迫进入同一转移倒计时。
3. 阿图尔用弟弟旧驾驶扣卡住缺齿车，窄道手因此没有被车轮拖走；驾驶扣裂开，阿图尔失去最后一件弟弟遗物，却获得冷铁上的交付字段。
4. 苏青禾拼合读写片，段野用掌血拒绝段守成补录；系统显示“交付对象”却缺现场签收，窄道手确认他们不是来替死人落笔的人。
5. 老崔用肩顶住门框给段野争时间，短楔和焊点同时到极限；门边只剩一回承力，所有人必须跟着窄道手决定下一步。
