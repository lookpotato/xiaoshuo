# 第39章人物交织

1. 段野要把旧铅牌当开槽确认时，秦砚扣住他的手腕，林小满据此改用黄铜环接炉灯；段野的机械方案被秦砚的生存底线改变，炉灯成为活人证据而非开门钥匙。

2. 阿图尔从门口拖回回收频道盒并压住魏平，苏青禾借频道盒逼魏平和罗沉说话；阿图尔的防守让苏青禾获得公开取证窗口，苏青禾的播报又迫使城防暂缓切割。

3. 地底人发现回水旁通在动，老崔认出那是自己旧日封过的口子，段野用弯裂铁条压死旁通；地底人的警告改变撬槽顺序，老崔的旧焊口被重新启动，代价是暖气窗口缩短。

4. 秦砚逼问罗沉，魏平趁机宣称秦砚只是被确认者，反而把罗沉推到公开记录前；罗沉承认手印，城防黑板刷新“第二确认人：罗沉”，队伍暂时保住秦砚却失去罗沉的隐蔽。

5. 林小满用铭牌磨痕点亮炉灯，秦砚的脸和“救援交接”刻字显形；灯灭前，林秋的断续路径暴露，地底深处落下第四下敲击，城防切割臂重新启动。
