# 第 0071 章交互地图

1. 段野要压住泵房门，白露从热屋喊停并把最后保温物分给伤员；段野被迫把“救热”从个人硬扛改成可撤的短窗口，白露因此耗尽医疗余量。
2. 门内女人用第四班节拍开内门，林小满发现节拍少一拍并截住假声；女人暴露自己曾替人报班，林小满得到林秋原声不是完整喊话而是节拍验证的线索。
3. 苏青禾把原始交接牌压在红灯下，老四咬出牙套里的半枚阀片；牌与阀片的编号错位，迫使段野承认“班号”和“人名”是两本账。
4. 阿图尔用残拖钩进入内沟回敲，米沙在热屋回应三短一长；泵房回声没有直接回米沙，却留下同样节拍，阿图尔选择先拉出内沟活人，旧伤撕裂。
5. 老崔拆掉锈阀并用废轴承做可拆阀座，秦砚敲出第三次回压；热水改道回墙，热屋获得一轮热，但北侧泵房暴露第二个低位阀。
6. 段野拒绝红灯刻出的“接班人”，让苏青禾公开念出错位编号；红灯停止继续刻写，却在泵房深处亮出一张旧值班表，钩住下一章的真正接班人。
