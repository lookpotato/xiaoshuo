# 交织记录

1. 段野用黑锅最后撑杆顶住后门，老崔拒绝硬撬，改用废热车回压管反冲阀芯；段野因此把承力交给老崔，门获得一条可控窄口，黑锅残架彻底失去支撑件。
2. 阿图尔把报废识别线接到旧货车厢，引开城防炮口；白露利用这轮窗口先送重伤员，阿图尔没有被段野看见，但他的假信号改变了队伍的进入顺序。
3. 林小满用裂方向针接入低压端，苏青禾把魏平的声音压进旧扩音回路；魏平故意报错编号，错误反而被记录，站内回声成为追责证据，林秋信号转入地下旧炉。
4. 门内女人用血压住感应片并放出“维修员最后”的旧口令，段野选择先让伤员进门；她保住了林秋线路，却让自己的身份暴露到“当年在站内”的程度。
5. 白露耗尽最后净水维持伤员清醒，老崔因此必须在窄口开启后立刻停回压；门虽被打开，主炉仍未恢复，下一章所有人都受制于断热倒计时。
