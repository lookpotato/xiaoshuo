# 第37章交织记录

1. 城防要求段野签字确认林小满，段野拒绝并转向罗沉；罗沉交出最后一页，暴露“本人确认”与“段守成”两条条件，段野因此把目标从守门改为找替代开法。
2. 阿图尔用铁桶和裸铜线拖住破门，魏平被迫成为门口障碍；苏青禾借这个位置核对“回收完成”，魏平失去改写口供的空间，但门口防线因此只剩一轮。
3. 林小满坚持接通炉灯，白露阻止她徒手碰线后仍让她使用护腕残壳；林秋残声没有完成确认，细铜线却让槽内男声被听见，林小满的救姐目标转成辨认声音。
4. 老崔指出槽盖左边第二道焊缝，地底人先撞槽确认里面有回应；两人的旧伤和旧焊错同时付出，槽盖裂开但没有打开。
5. 罗沉听见槽内人点名后退开，魏平抓住“已经替你确认”施压；段野握住旧铅牌没有落下，签字问题从门外命令变成槽内活人的主动确认。
