# 第51章交织行动

1. 维克多胸前监察牌先敲三下，秦砚判断节拍不属于炉底回声；段野因此不拆牌，改逼维克多自己查看背线，维克多第一次承认身份正在被越权命令借用。
2. 林小满拆应急灯电池接入听音线，林秋把求救节拍改成警告；秦砚听出两套节拍，林小满的判断被改变，避免接通会烧毁神经印记的回路。
3. 阿图尔占用最后一次通讯窗口发送弟弟编号，城防切割臂随即重新锁门；他的发送迫使段野把拆牌证据交给苏青禾保管，队伍失去撤退信号但保住编号。
4. 白露拆保温棉护住秦砚和阿图尔，罗沉离开炉底取融雪水；罗沉错过断牌现场，却带回银焊屑，苏青禾据此把后补焊责任指向总局监察车。
5. 老崔挑开监察牌背壳，维克多拔掉保险线；牌内敲击停止，维克多的远程权限同时熄灭。队伍赢得“命令非维克多下达”的证词，却暴露监察车曾在404接线。
