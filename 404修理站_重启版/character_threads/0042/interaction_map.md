# 第42章人物交织表

1. 段野用左膝撑住黑锅残架，拒绝先撤；白露因此把伤员绳和空药箱投入槽边，逼段野把救人顺序放在自己肩伤之前。结果：黑锅残架承力下降，秦砚获得一条可拉出的路线。
2. 林小满想重新接回林秋的声音，罗沉却按住她的手，指出热线会把北区余热抽走；她误以为罗沉要保护旧账，转而自己找热杆。结果：林小满切断回传线，保住秦砚，也失去一次直接听见林秋的机会。
3. 阿图尔把断铜线绕上切割臂，主动把三次热刃冲击引向门框；段野因此多出半步撑槽时间，但阿图尔最后的识别碎片被压扁，门外设备没有完全退去。
4. 老崔敲开第三道旧焊点，确认“维”不是纸上残字，而是当年维修监察链上的签发人；苏青禾把这句话接进残余扩音回路，逼罗沉交出完整名字。
5. 罗沉在秦砚即将没顶时说出“维克多”，并用旧手印压住反向确认片；深线短暂断开，确认室回水停止上涨，但手印和旧纸同时烧毁。
6. 读者未见的后果：门外城防频道记录到“维克多”仍在维修监察权限内，开始向第七码门下发人工接管；修理站下一步必须找到旧中继站，不能只守住门。
