# 魏平

- 起点状态：双手被缚，肩部受压，知道城防“回收完成”的口径。
- 当前地点：七号车侧面的担架边。
- 独立目标：拿回定位回执，证明七号车上的名单属于非法截留。
- 误解：以为毁掉一角名单就能让所有人的身份重新失效。
- 底线：不承认自己参与过北线旧回收，但愿意牺牲无名伤员来保住制度口径。
- 主动行动：趁炮火掩护咬断袖口里的细线，试图把残余回执发给城防。
- 代价：手腕被白露重新绑死，回执只发出半句，暴露了回收队的真正目标是名单而非车辆。
- 关系变化：被苏青禾抓住口径漏洞，第一次失去“规则解释者”的优势。
- 下一步：回站后继续声称“回收完成”合法，同时寻找能证明段守成已被转运的证据。
