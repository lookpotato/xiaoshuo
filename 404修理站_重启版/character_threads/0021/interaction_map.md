# 第21章交织行动图

1. 炉下男人把半截铁扣送进废热站读头，触发“第七位待确认”；段野没有毁门，而是压住魏平逼问盖章流程，结果把魏平的挣扎声留进炉内记录。
2. 林小满拆旧配线寻找林秋，林秋反向打出两短一长；白露把三只水壶余热分给伤员并接入监测端，结果林秋的残句被听见，但主线被烧毁。
3. 阿图尔用魏平识别扣引开无标机甲，老崔趁外侧空档融开锈锁；两人的动作改变了撤退路线，代价是阿图尔失去识别扣、老崔失去最后一条可重复开启的热路。
4. 苏青禾把证据盒接入读头，林秋的残句与魏平口供叠在一起；炉内盖章声暴露“城务厅北侧授权”，证据盒外壳烧穿，只留下半焦时间戳片。
5. 魏平试图撞断读头，段野将他按回地面；炉下男人拔掉保险，废热站暂时断热，队伍赢得名单不再回写的短窗口，却必须在下一次热压前进城。
