# 第38章人物交织

1. 段野把旧铅牌压进维修槽，槽内男人用敲击阻止他，罗沉随后说明确认片会把人算进事故，段野因此拔牌改用黑锅残架顶槽盖；段野的误判被槽内人的动作和罗沉的迟疑改变。

2. 林小满辨出两短一长不是林秋的节拍，接炉灯传递信号；槽内男人借灯点名罗沉，迫使罗沉暴露旧关系。林小满的细铜线烧断后，灯灭和槽盖裂缝扩大，段野只能抓住露出的黄铜环，取得半块旧铭牌。

3. 老崔指出左边第二道焊缝能拆，地底人从槽底找到横梁，段野用黑锅残架承力，三人的配合让槽盖裂开一掌宽；代价是铁条断裂、地底人腿伤再裂和段野右肩出血。

4. 阿图尔用断铜线和铁桶拖住城防，苏青禾把“回收完成”刻在桶盖并压住放压杆，白露分净水维持伤员；门口暂退给队伍留下开槽时间，魏平未能发送记录，净水和医疗余量却见底。

5. 槽内男人拒绝出来，林秋在断线后重新传声并警告段野不要放他出来；城防重新举起切割臂，槽内男人与林秋的警告互相冲突，下一章必须核对第二确认人的身份和确认效力。
