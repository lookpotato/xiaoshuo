# 第 0073 章交互地图

1. 白露给出三分钟救命窗口，段野决定带伤员转入北三旧管；阿图尔由追声改为拉担架，结果队伍没有分裂。
2. 林小满从借声缺少林秋最后一拍判断北三不是诱门，苏青禾用交接牌和蓝漆残码确认旧管口存在现行回写；两人的判断共同改变行动方向。
3. 老崔用断钢管撑门、阀片堵孔，段野压住检修盖；热压被导入旧管，代价是老崔左手彻底失力、段野掌心二次裂开。
4. 检修盖下的人扣住残拖钩，阿图尔反向拉住拖钩，白露命令关盖保伤员；沟内人松手滑入旧管，队伍获得半枚城防维修扣牌。
5. 林小满烧断最后绝缘皮，段野和苏青禾保住“林——”残码；林秋原声补出第三拍并说出“拿我名字进城的人”，钩子从追接班人转为追冒名者。
