# 第22章交织行动图

1. 老崔先拆旧回压杆，北侧值守员随即关掉识别灯；老崔改用肩顶井门，段野被迫压住魏平，队伍获得四分钟开门缝，但退路只剩一次。
2. 阿图尔用半焦时间戳片反射错误目标，值守员为自保报出“四号转运口，七”；魏平借机报错编号，反而让错误口供被扩音记录。
3. 白露把伤员监测线接入旧扩音口，林小满沿同一支路接入中继；林秋因此说出完整拒签声音，但中继线烧毁，姊妹之间失去连续通讯。
4. 苏青禾逼值守员重复“第二次确认”的提前时间，并把声音压进证据盒残壳；炉下男人指出第二道焊缝，证实旧井不是自然封死，改变队伍对段守成的判断。
5. 段野顶住回落井门，让伤员先过；他保住了林秋声音和半段责任证据，却放弃撕裂名单另一角，井底中继室的盖章者仍未现身。
