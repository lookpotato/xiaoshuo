# 魏平

- 起点状态：胸伤、被绑，回收凭证解释权被苏青禾压住。
- 当前地点：医疗桌旁，靠近第七码门。
- 私人目标：逼修理站交出三名伤员，并让任何门内证据看起来像私闯造成的事故。
- 知道与不知道：知道第七码门曾是北线救援队最后撤入处；不知道门后是否还有活人。
- 误解：认为段野会为了父亲旧案失控，从而给他制造私刑记录。
- 阻力：双手被绑、回执被按手印、炮口不听他单独指挥。
- 底线：不承认“回收完成”意味着活人仍在仓内。
- 行动：趁开门前用鞋底触碰旧信号片，试图向外发出“站内已交付”假回执。
- 代价：鞋底信号片暴露，苏青禾记录了他的动作，胸伤裂开。
- 本场后变化：被迫看见门后遗留的活体登记，口头规则失去遮掩力。
- 离场后动向：寻找能证明自己只是执行命令的签字或证人。
