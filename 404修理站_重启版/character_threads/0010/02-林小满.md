# 林小满

- 起点状态：动力匣无电，掌心烫伤，姐姐信号只剩“仓”。
- 当前地点：第七码门旁的旧控制箱。
- 私人目标：用最后可用的站内脉冲听清姐姐的下一句话。
- 知道与不知道：知道短脉冲只能唤醒旧线路几秒；不知道门内是否真有姐姐的神经备份。
- 误解：把任何与姐姐相似的声音都当成姐姐主动求救。
- 阻力：没有铜线和蓄能芯，控制箱需要人工搭桥。
- 底线：不让段野替她决定是否拆掉姐姐留下的线路。
- 行动：拆下自己护腕上的导电片，给门锁提供一次脉冲，并在门开后追入信号源。
- 代价：护腕报废，旧烫伤裂开，姐姐声音仍被截断。
- 本场后变化：确认门内有人利用旧线路说话，但那人不一定是姐姐。
- 离场后动向：带着门内线路残片寻找姐姐信号的真实位置。
