# 苏青禾

- 起点状态：通行信用归零，握有半张名单和魏平的回执口供。
- 当前地点：医疗桌与第七码门之间。
- 私人目标：让魏平留下可追责的原话，并核清门内记录是否能证明活人被藏匿。
- 知道与不知道：知道旧名单的时间早于回收回执；不知道门内人是否属于名单上的两名幸存者。
- 误解：相信一份完整记录比人的口头承诺更可靠。
- 阻力：名单被炮火打湿，魏平可以咬死不认，门内线路会抹掉时间戳。
- 底线：不撕毁唯一原件，不让段野私刑处置魏平。
- 行动：用名单背面作拒收联，逼魏平在上面按手印；把门锁焊号与时间戳相互核对。
- 代价：半张名单被撕掉一角，旧章彻底失效。
- 本场后变化：获得一份能证明“仓内有人”的临时凭证，但妹妹离城账更难追回。
- 离场后动向：保管凭证，逼魏平解释谁签了最后一道封门命令。
