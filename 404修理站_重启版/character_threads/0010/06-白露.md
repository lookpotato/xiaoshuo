# 白露

- 起点状态：药品、保温层、止痛药和净水耗尽，三名伤员刚恢复意识。
- 当前地点：医疗桌旁，守着三副担架。
- 私人目标：让伤员撑过开门和炮击，不让任何人被当作交付物。
- 知道与不知道：知道老人胸伤最危险、少年已经脱水；不知道门后有没有可用热源。
- 误解：判断魏平不会真的主动伤害自己，因为他需要活着交付口供。
- 阻力：无药、无水，热管只够一轮，担架无法同时穿过窄门。
- 底线：不把治疗顺序交给评级，不拿一个伤员换另外两个。
- 行动：拆医疗桌的保温板给老人挡风，指挥伤员分批过门，并用魏平的绷带固定门槛。
- 代价：医疗桌失去保温功能，魏平的伤口重新渗血。
- 本场后变化：三名伤员进入门后，但她发现门内空气带着旧炉毒味。
- 离场后动向：先封住门后通风口，检查所有人是否吸入有害烟气。
