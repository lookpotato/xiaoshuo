# 重启版写作提示

本项目只生成《404修理站》重启版本地章节。写作前读取 shared/narrative_prose_foundation.md、shared/character_engine.md、shared/parallel_character_pipeline.md、shared/quality_scorecard.md、shared/reader_gate.md，以及本项目的 narrative_style_pack.md、story_bible.md、resource_ledger.md、character_voice_bible.md、voice_packs/ 和本章之前的正式正文。

旁白固定单一认知中心；新人必须从可见来路进入并先改变局面，道具必须先让读者知道眼下能干什么、用了会损失什么。禁止百科定义、重复初登场和用陌生名词堆叠制造伪悬念；本书旁白必须保持修理工能感到的冷、油污、故障判断和资源代价。

每章按“人物独立行动→资源冲突→现场对话→热血兑现→代价与钩子”推进。对白必须先执行 `voice_packs/colloquial_mandarin_core.md` 的普通人口语底盘，再叠加人物语言包，不能让所有人说同一种完整普通话。定稿前抽查称呼、过去经验、操作步骤和后果表达：称呼必须根据亲疏、当面或转述、求人或翻脸、年龄、职业和地域动态选择，“哥、姐、老哥、兄弟、X哥、X姐、姐姐、全名、外号或不带称呼”都可能成立，禁止机械替换；过去见闻补“以前/上回”等时间落点；操作话必须说清具体物件和位置，并把步骤与后果拆开。人物线目录必须严格使用四位章节编号，例如 `character_threads/0005/`，不得写成 `05/` 或其他形式；必须为 00-cast.md 中每个人物各写一份独立人物线文件，不能只写 cast、交织表和状态表。00-cast.md 必须用 `## 角色名单` 分节，并为每名真实人物单独写一行 `- 人物名：...`；`主要视角`、`出场人物`、`当章目标`、`当章小胜负`、`主要钩子` 等元数据不能写成角色列表项，车、锅、机甲等行动性物件放到 `## 行动物件`，不建立人物私线。不得上传、不得定时发布、不得输出章节内容到日志。
