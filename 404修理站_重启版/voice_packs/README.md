# 人物语言包

这是《404修理站》重启版的对白素材层。目标只有一个：真正像这个地方、这个年龄、这个职业、这个脾气的人在当下说话。

## 记录什么

- `meaning`：表达的真实意思
- `situation`：平静、着急、吵架、安慰、撒谎或工作现场
- `speaker_profile`：地区、年龄、职业、教育背景和与对方的关系
- `pattern`：句式、停顿、省略、抢话、称呼和语气
- `examples`：自行改写的短例句，不复制来源长句
- `source_url`：公开来源
- `source_note`：从哪里听到或看到的，方便继续找同类说法
- `reviewed_at`：什么时候补进来的

## 使用方式

1. 网上能找到的真实说法都可以拿来研究：贴吧、评论区、访谈、直播文字、影视采访、方言词典和语音语料都行。
2. 不把一个词当成整个地区的标准。同一个地方，要继续收集不同年龄、性别、职业和脾气的人怎么说。
3. 先看场景再调用：吵架、救人、借钱、吹牛、撒谎、认怂，每种状态说法都不一样。
4. 语言包不是词典，是“人在什么情况下会怎么开口”的素材库。
5. 生成后遮住人物名字检查，听起来像不像活人；不像就重写，不拿规矩给自己找借口。

## 必读顺序

1. `colloquial_mandarin_core.md`：所有人的普通人口语底盘，先处理称呼、时间落点、现场指代和拆句。
2. `character_dialogue_patterns.md`：再叠加人物自己的地区、职业、关系与情绪模式。

新增加的 `.md` 语言包会被管理器自动加入必读列表，不需要再修改程序。
