# 重启版文风规则

- 旁白必须完整执行 `shared/narrative_prose_foundation.md` 和本书 `narrative_style_pack.md`；默认采用贴近段野的第三人称限知视角。
- 新人物按“来路→先行动→关系锚→识别钉”出场；新设备按“看见→眼下用途→使用代价”解释。同一场重点新人和复杂设备原则上各不超过一个。
- 旁白词感来自修理、锅炉、废油、冻伤和欠账，不写百科定义，不用陌生名词堆悬念，不让人物重复初登场。

- 热血先于解密：先写人要救谁、谁在阻拦、失败会失去什么。
- 对白必须像现场脱口而出，允许省略、抢话、没说完、重复、损人和适量脏话。
- 每个人都有地域底色、年龄感、职业词和情绪变化；不能普通话套方言词。
- 方言服务人物，不拿地域当笑点；外国中文保持尊严和稳定语言习惯。
- 每章至少三名人物独立行动，至少消耗或获得一种资源，完成一个小胜负。
- 单章正文目标约2000—2600字；不能用设定说明凑字数。
- 不让主角替所有人总结情绪；保留误解、停顿、答非所问和具体动作。
- 普通话人物也要使用生活口语：补足“以前、上回”等时间落点和“那个、下面、完事”等现场组织词。称呼必须随关系距离和场景变化，可用“哥、姐、老哥、兄弟、X哥、X姐、全名、外号或省略”，不设置机械默认值。
- 每章定稿前执行一次口语逆翻译，把抽象步骤拆成具体物件、位置、动作、结果和人的后果。
