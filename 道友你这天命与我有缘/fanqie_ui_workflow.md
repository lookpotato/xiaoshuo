# 《道友你这天命与我有缘》番茄发布流程

本书已绑定独立番茄作品，book_id 为 `7669807761814735897`。每次上传前必须核对页面作品名与书号，不得借用《404修理站》或测试作品的链接。

## 固定步骤

1. 先在章节管理页核对目标章节是否已存在；已有草稿必须沿用原编辑地址，不重复创建。
2. 串行填写章节号、标题和纯正文；正文不得带 Markdown 标题、分隔线或 Metadata。
3. 回读标题、正文首段、末段与平台字数。正文为空、首尾不符或字数明显偏离时不得进入下一步。
4. 若本章包含唯一图片，在页面底部“作者有话说”悬停“添加”并选择“添加图文”；点击输入框左下角图片按钮，在“点击或拖拽文件到此上传”弹窗中选择本书图片，上传完成后点击“确定”。回查出现图片预览或文件名才可继续；无图章节跳过。
5. 依次执行“下一步 → 错别字提示提交（若出现）→ 仅基础检测 → 是否使用AI=是 → 定时发布”。
6. 排期默认每日 `18:30`、`20:30`。日期与时间必须通过可见选择器设置，并回读日期、时间、AI选项和定时开关。
7. 只点击一次确认发布；随后回章节管理页按章节号与标题唯一定位。显示待发布、审核中或已发布才算成功。

## 停止条件

- 登录失效、验证码、二维码、手机验证或风控。
- 政策警告、陌生确认框、作品名或 book_id 不符。
- 页面字数不刷新、正文未写入或提交结果无法核验。

遇到停止条件时写入日志并保留恢复点，不重复点击，不读取或保存 Cookie、Token、密码和验证码。
