# 重写版文风边界

- 先写人物眼前想做的事，再让设定通过使用、误用和后果显形。
- 第一章、新卷开篇或首次进入新地点时，在危险升级前用少量生活动作建立“身在何处、当地人平常怎么活、哪一条限制马上会生效、谁在执行”；随后让冲突触犯这条限制。
- 上述定向只服务读者第一次进入陌生环境，普通连续章节不得机械地先讲设定；背景信息必须同时承担人物塑造、事故伏笔或行动条件。
- 叙述贴近当前视角人物，不越界解释别人内心，不替人物总结主题。
- 对白由年龄、家庭、职业、亲疏、权力和现场目的决定；允许半句、打断、回避和答非所问。
- 陆遥的聪明写在观察、试错和选择里，不由旁白宣布；动作或对白已经证明后不再解释一遍。
- 喜剧来自正经诉求与身份、制度、生活经验的冲突。包袱落下后继续行动，不让第三个人复述笑点。
- 严肃场景允许安静和笨拙，不强行让所有人接梗。
- 常规章1900—2200字，一个主要局面变化；短段落服务连续动作，不靠碎句冒充节奏。
- 不出现评论区、读者老爷、作者、AI、提示词、生成流程或邀读者站队等出戏表达。
- 不复刻参考作品的句子、人物、专名、桥段、口头禅或可辨识表达。
