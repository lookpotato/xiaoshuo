# interaction_map
1. 祭风场：陆宁催陆遥先稳祭棚，陆遥把木鸢藏在木料后；小满偷学放线，韩照夜巡视并要求离地器物收回。陆遥与小满的隐瞒让日常限制变成事故条件。
2. 风路边：绳扣脱开，小满与木鸢被拖向镇天碑。韩照夜封正面风口并命人拉住小满；陆遥发现拉拽让拖力更快，双方救援办法直接冲突。
3. 木架上：陆遥借青羽短暂显出的风路荡入，韩照夜改为托住下方落点。陆遥在木鸢与小满之间松手，现场资源和两人关系同时改变。
4. 事故后：陆宁按承重和工期清点棚损，韩照夜按责任记下违规，陆遥承诺先收尾再寻木鸢。韩照夜没有放弃职责，陆遥也没有再把选择权全攥在手里。
- 主角未见行动：韩照夜把一段断绳压在封风牌下，避免村民再次踩入风口。
- 后续发酵：木鸢落入镇天碑后风域；韩照夜掌握陆遥姓名与违规记录。
