# 第 10 章状态回写

- 陆遥：逐段取得屋主同意后引导回风；左臂仍伤，残鸢右翼彻底断裂；取得陆沉舟木片与北坡外山道。
- 韩照夜：在父命与救灾间选择先保村；剑鞘进一步崩裂，与陆遥约定谁也不单独进入石缝。
- 陆宁：留守并反转木轮，东梁断一根但人员安全；木作铺继续停工待修。
- 商青梧：优先保住药铺井水和病人；随身水囊用于续炉，药铺井桶余量紧张。
- 刘婶：开放破墙泄风，鸡转移到祠堂，需借板补墙。
- 木料商：开放仓院，保住新板和东垛主要木料，但需核算受潮损失。
- 药童：完成报险和药铺转移，确认井桶落回。
- 结果：七处风口停止，镇天碑和石缝暂时保住；无人因回风受伤。
- 下一步：天亮召开七户议事，决定是否沿陆沉舟留下的山道进入北坡之外。
