# 《旧物回声事务所》文风

- 贴着林默的认知写：他能听见、量到、怀疑到什么才写什么；唐栀和他人行动可见，内心不能被旁白直接揭开。
- 每章让人物办成、办砸或改变一件具体事。回声是阻力或线索，不是直接给答案的超能力。
- 先写书页、螺丝、台灯开关、机器人脚步和人的手，再写技术名称。设备失败要有电量、误识别、延迟或损坏后果。
- 普通话按人物关系和职业变化。林默问短句，唐栀熟人面前抢话、对长辈留台阶，孟阿婆把难过说成「先把书还我」。七号的少量短句可以硬，但真人不得全说成系统播报。
- 人物不会把隐私、授权、用途、报酬逐项念成清单。眼前谁的东西被碰了，就先说这件事；其他边界在行动与后续谈话里露出。
- 不用「命运的齿轮」「他知道自己必须」「这意味着」等可套任何书的总结。潮汐造物铺的旧情节、人物和地点不得混入本书。
- 章末钩子来自本章改变。第一至五章保留一个阶段性问题的答案，同时开启更深的问题。
