# 《旧物回声事务所》长篇路线与试读五章

长篇拟五卷、约 300—360 章。第一卷「东西开口了」约 1—60 章，以七号与不同旧物事件建立人物、规则和事故疑点；第二卷「谁在借它们说话」约 61—130 章，出现主动复制或伪造回声的人；第三卷「有人想买下声音」约 131—210 章，陪伴产品和软件系统让隐私问题变得难以回避；第四卷「同一种声音」约 211—290 章，城市里的多件旧物开始发生相似异常，团队需分清技术污染与真正回声；第五卷「七号不答应」约 291—360 章，林默面对旧事故和控制权，不靠一场演讲解决人与物的关系。

试读五章事件线：

1. 《这书叫了他一声》：唐栀带来要修补、归还的旧书；七号异常喊林默童年称呼。林默查到离线日志没有这句。
2. 《不要替她播放》：旧书所有人孟阿婆要求收回；林默和唐栀查到书曾在阅览室晚间使用，声音牵涉在世的人，播放会造成实际伤害。
3. 《七号的嘴》：林默隔离设备复测，七号断网仍出现不同于预设语音的回应；测试揭示回声并非书里的完整录音，设备日志可被人动过。
4. 《那晚的灯》：唐栀找回阅览室的旧借阅线索，林默用台灯、纸页与目击者核对发生过的事；他承认不能凭一段声音替别人叙述旧事。
5. 《书还回去了》：孟阿婆拿回书并说清那句话的现实来处；团队得到阶段结论，七号的异常却牵出两年前演示事故。结尾给下一件旧物一个自然入口。
