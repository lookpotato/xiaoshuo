# 章节质量评分卡（100 分）

## 硬门槛

出现设定冲突、重复章节、元创作信息、未处理的平台风险、错误书号上传，直接不发布。关键解法依赖新道具却未在生效前直观说明基础用途，也直接不发布。`reader_checks/NNNN.json` 缺失、正文哈希不一致、六题任一项找不到正文证据、仍有未解释名词，或必须借助大纲才能说明前因后果时，同样只保留草稿。

“元创作信息”指 AI、提示词、自动化、后台操作、字数与生成过程等生产信息。若本书 `style_guide.md` 明确允许旁白或角色短暂称呼读者，这属于作品自身的叙事手法，不按元创作泄露处理。

Token、运行时间、模型额度与自动化成本不得成为删减剧情、减少连续性上下文或降低正文质量的理由。章节缩短必须通过拆分事件链完成。图片内容质量由网页 GPT 与完整提示词负责，不再消耗 Codex 视觉 token 二次检查；本机只承担格式、哈希、像素画幅和重复检查等机械工作。

番茄长篇的字数以章节管理页最终稳定回显为唯一平台口径；本地字符数、汉字数与 Metadata 只作预检。常规章正文目标 1900—2200 字，以约 2000 字为中心，常规硬上限 2400 字；超长内容应在阶段胜负处拆成连续短章。提交后列表未刷新、仍显示旧字数或正文为零时不得报告成功，必须进入编辑页核对正文并等待权威列表更新。

## 评分

- 连续性 15：接住上章；人物状态、物品、伤势、承诺无冲突。
- 目标与冲突 20：目标可判断；阻碍主动；至少升级一次。
- 人物 15：主角做出选择；配角有意图；对话可区分。
- 爽点与情绪 15：有铺垫、有落差、有后果，不靠降智。
- 读者因果与信息 15：只看正文即可说清承接、问题、判断依据、行动原理、结果代价；新名词有白话说明，新道具用途先行，跨章再用有情境回顾。
- 文本 10：动作清楚、段落适合手机、无明显套话和重复。
- 结尾 10：局面改变；下一章有明确必读理由。

低于 80 分必须修改；80—89 分可归档；90 分以上才可标记为标杆章节。
