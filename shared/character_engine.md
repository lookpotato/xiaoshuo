# 人物独立运行引擎

这是一条跨作品的底层写作规则。它解决的不是人物设定是否丰富，而是人物是否像一个在小说之外也会继续生活、判断和行动的人。

## 核心原则

- 每个有名字、有台词或承担戏份的人物，都必须有独立的行动因果。主角是镜头最多的人，不是其他人物行动的发动机。
- 人物模型只在幕后维护；正文仍服从当前第三人称视角。视角人物只能知道自己观察到、记得、推断出或被告知的内容，不能无依据读取他人内心。
- 其他人物不必理解主角、不必配合主角，也不必在主角离场后停止行动。他们可以误解、隐瞒、拒绝、答非所问或把局面带向自己的目标。
- 支线不是换一个视角展示设定，而是某个人的独立目标持续发展，并最终与主线产生碰撞或代价。

## 人物运行卡

核心人物和持续配角在写章前更新以下字段；临时人物至少补齐“眼前想要什么、误解什么、离场后会做什么”。

```text
当前时间与地点：
身体、资源与伤势：
此刻正在做什么：
真正想要什么：
最怕失去什么：
知道什么：
不知道什么：
误解什么：
对在场人物的真实态度：
准备采取的下一步：
绝不愿意做什么：
正在隐瞒什么：
本场结束后会改变什么：
独有的称呼、口头习惯或动作：
```

写作前先问：如果主角突然消失，这个人物接下来会做什么？如果答案是“等待主角安排”，就必须补充他的目标、阻力或私人代价。

## 场景执行

1. 列出本场所有有戏份人物各自的目标、阻力和底线。
2. 先确定他们在主角没有介入时会采取的行动，再让这些行动互相碰撞。
3. 由一个主要第三视角呈现现场，不替其他人物解释真实动机；通过动作、错答、停顿、物件和后果让读者自行判断。
4. 场景结束后更新每个人的位置、知识、关系、资源、承诺和下一步，而不是只记录主角获得了什么。

## 独立性验收

- 去掉人物姓名，只看台词和动作，能否大致分辨是谁？
- 人物是否有一句没有服务主线、但暴露其生活、偏见、习惯或关系的话？
- 是否至少有一个人物没有按主角方案行动？
- 人物的选择是否改变了别人的选择，而不是只提供信息或情绪反应？
- 本章是否有一个结果会在镜头切走后继续发酵？

## 反 AI 味写作规则

不要让所有人都拥有同样清晰、完整、礼貌和有效率的表达能力。保留答非所问、说到一半改口、错误判断、尴尬停顿、无关动作、没人接住的话和不合时宜的关注点。

人物不应直接说出自己最准确的情绪和动机。优先写他如何回避、嘴硬、重复、转移、整理东西、看向别处或做出与话语不一致的动作。

不要把“每段都有信息推进、每章都有完整闭环、每次反转都解释清楚”当作正文标准。这些只能作为后台质检项目，不能压平人物的迟疑、跑题、失误和生活残留。

## 反解释编辑

完稿后单独做一遍反解释编辑：

- 删除“他意识到、这意味着、他明白、她很害怕、他十分震惊”等替读者下结论的句子；
- 删除旁白、内心和对话对同一信息的三次重复；
- 把情绪总结改为动作、停顿、误会、错答和后果；
- 把过于完整的对话拆出不对称，让人物保留不知道、说不出或不愿承认的部分；
- 每章至少保留一处非功能性细节，但该细节必须属于某个人，而不是作者随机装饰。

反解释编辑不能破坏读者理解眼前行动所必需的因果；需要解释规则时解释规则，需要隐藏的是人物的内心，不是基础剧情。
