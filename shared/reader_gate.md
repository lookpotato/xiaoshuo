# 无大纲读者反向验收

## 为什么需要这一关

大纲中的一句关键事件不能直接膨胀成一串动作。作者知道前因、规则和人物计划，读者只看得到正文；如果中间桥梁没有落在纸面上，章节即使符合大纲也不算完成。

这道门模拟一个没有大纲、设定表、连续性账本和作者解释的首次读者。它不要求每章重讲整本书，只要求读者仅凭本章就能跟住眼前事件的来处、目标、判断、行动与后果。

## 从关键句扩写成完整场景

每个关键剧情句落笔前，先拆成以下链条：

1. 承接：上一状态怎样导致眼前场面；新到场的人或物从哪里来、为什么此刻出现。
2. 问题：现在具体哪里不对；若不处理，谁会立刻失去什么。
3. 依据：角色看见、听见、试出或回忆到什么，才有资格作出判断。
4. 判断：这些依据说明什么；若存在不确定性，要让角色承认并验证，不能把猜测写成天生常识。
5. 行动：为什么选择这个办法；规则、道具或能力怎样作用，限制是什么。
6. 结果：办法是否奏效；出现了什么可见变化，谁付出代价，局面怎样改变。

悬念可以隐藏幕后原因、最终真相和隐藏代价，但不能隐藏当前行动所需的基础因果。专有名词只能给事物命名，不能替代说明。

## 完稿后的反向阅读

先完成草稿，再停止读取 `outline.md`、人物表、世界观、连续性账本、章节计划和写作提示。只打开待定正文，以第一次接触本书的读者身份回答六题：

1. `previous_context`：眼前局面由什么先前结果引起，正文在哪里完成了必要承接？
2. `immediate_problem`：本章最急的问题和失败后果是什么？
3. `decision_basis`：人物凭哪些可见证据得出关键判断？
4. `action_logic`：方案为什么可能有效，具体怎么作用，有什么限制？
5. `result_and_cost`：最终发生了什么，谁付出什么代价，局面如何变化？
6. `reader_hook`：结尾留下的是哪个由本章结果自然产生的问题？

每题必须引用至少一句逐字存在于正文的证据。若必须借助大纲、作者脑补或设定文件才能回答，先回正文补一句承接、一次追问、一处验证或一个可见结果，然后从头重读。不要用百科段落补洞。

证据还必须出现在读者需要它的位置：前情承接和眼前问题在开篇 1200 字内落地；关键证据先于行动原理，行动原理先于结果结算；结尾钩子的证据来自正文后 35%。不能先让角色凭空行动，到后半章才倒叙补理由。

同时列出本章新出现、读者理解当前行动必须知道的专有名词。每个名词都要在首次出现后 300 字内给出白话解释和正文原句证据；`unexplained_terms` 必须清空。普通人名不必机械登记，除非身份关系会直接影响本章判断。

## 验收文件

通过后在本书 `reader_checks/NNNN.json` 写入验收记录。`narrative_sha256` 使用 `novel_reader_gate.narrative_sha256()` 计算；正文后来发生任何修改，都必须重新验收。

```json
{
  "schema_version": 1,
  "chapter_number": 54,
  "mode": "outline-blind-first-reader",
  "outline_blind": true,
  "reviewer": "codex-reader-gate",
  "status": "passed",
  "reviewed_at": "带时区的 ISO 时间",
  "revision_rounds": 1,
  "narrative_sha256": "最终正文哈希",
  "questions": {
    "previous_context": {"answer": "具体回答", "evidence": ["正文原句"]},
    "immediate_problem": {"answer": "具体回答", "evidence": ["正文原句"]},
    "decision_basis": {"answer": "具体回答", "evidence": ["正文原句"]},
    "action_logic": {"answer": "具体回答", "evidence": ["正文原句"]},
    "result_and_cost": {"answer": "具体回答", "evidence": ["正文原句"]},
    "reader_hook": {"answer": "具体回答", "evidence": ["正文原句"]}
  },
  "new_terms": [
    {
      "term": "新名词",
      "plain_explanation": "不用其他设定也能听懂的用途或含义",
      "evidence": "正文中完成解释的原句"
    }
  ],
  "unexplained_terms": []
}
```

验收文件缺失、证据不在正文、正文哈希变化、仍有未解释名词或任一题无法回答时，章节只能留在 `drafts/`，不得进入 `chapters/`、推进状态或上传。
