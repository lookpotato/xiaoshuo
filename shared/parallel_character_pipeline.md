# 并行人物线写作流水线

这是番茄小说系统的底层创作流程，适用于所有已注册和新建作品。它与每本书自己的文风、世界观和题材规则叠加，不替代单书设定。

## 总原则

最终上传的是一章小说，不是几个人物章节的拼接；但正式章节生成前，本章所有有戏份的人物都必须在幕后各自运行。主角拥有主要第三人称镜头，其他人物拥有独立的行动线、信息边界和后续影响。

## 四阶段流程

### 1. 人物私线

根据当前章节断点建立 `character_threads/章节号/`。每个有戏份的人物单独生成一份私线记录，至少包含：起点状态、当前地点、私人目标、知道与不知道、误解、阻力、底线、准备采取的行动、付出的代价、本场后的变化和离场后动向。

私线不是最终成稿，不要求每个人同样长，也不允许人物知道其他私线中的内心和秘密。主视角人物读取最近 3—5 章；重要配角读取最近 2—3 次出场；短暂配角读取最近 1—2 次出场和必要的主线状态；离场人物只读取自己的上一条动向和会影响他的公共事件。

### 2. 交织表

私线完成后建立交织表，按时间或场景列出每个人物的行动、相互影响、可见结果、不可见结果和交汇节点。必须明确：谁改变了谁的计划，谁的行动没有被主角看见，哪个结果会在下一章继续发酵。

### 3. 单视角汇总

选择本章主要第三人称视角，只把该视角能看见、听见、记得、推断或被告知的内容写入正式章节。其他私线通过痕迹、错位、物件、伤势、缺席、传话和后果进入正文；不得用“与此同时”连续播报其他人物的内心行动，不得让汇总器拥有全知视角。

最终汇总不是流水账：删掉没有改变人物选择或局面的私线片段；保留能造成误会、关系变化、资源变化、行动阻力或后续债务的片段。

### 4. 全体状态回写

汇总完成后，更新所有出场人物的时间地点、身体与资源、知识变化、关系变化、承诺、秘密暴露程度、当前目标和下一步行动。没有出现在正文中的私线结果也要记录，但标记为“读者未见/主角未知”，不能提前在正文解释。

## 私线长度与角色分级

- 主视角：完整场景私线，可包含本章主要行动和内心阻力。
- 重要配角：完整行动线，必须至少改变一个计划、关系或资源。
- 普通配角：一个行动片段，必须有目标、偏差和后果。
- 临时人物：一句到一段的轻量动向，必须避免成为纯信息播报器。

不允许为了形式让每个人都写一篇完整章节。人物是否独立，取决于他是否在主角镜头外继续做选择，而不是私线字数。

## 汇总前硬检查

- 如果主角突然离场，其他人物是否仍会继续行动？
- 是否存在至少一条主角没有看见的有效行动？
- 是否有两条人物线真正改变了彼此，而不是同时站在同一场戏里？
- 汇总正文是否只使用当前视角可获得的信息？
- 是否删掉了“与此同时”“此时另一边”“他并不知道”等全知播报式拼接？
- 是否保留了人物误解、答非所问、停顿、无关动作或不够聪明但符合经历的选择？
- 本章结束后，所有出场人物是否都拥有不同的下一步？

## 文件约定

```text
<book>/character_threads/<chapter-number>/
  00-cast.md
  01-<character>.md
  02-<character>.md
  interaction_map.md
  state_update.md
```

正式章节仍保存到 `<book>/drafts/` 和 `<book>/chapters/`；人物私线、交织表和状态回写是创作审计材料，不上传到番茄正文。
